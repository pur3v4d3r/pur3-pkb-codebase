## How to Use This File

Each section below corresponds to one generator in the **PKB Report Generator Suite v2.0**. Topics within each section are grouped by domain and selected because they benefit most from that generator's specific analytical structure. A single topic may appear in multiple sections — the generator type you choose shapes *how* the topic is explored, not just *what* is covered.

**Input format reminder:**
```
Generate a report on: [TOPIC]
Generate Report Here: [FULL_DIRECTORY_PATH]
Wiki-links/Permanent Notes List Location: [FULL_PATH_TO_WIKI_LINKS_FILE]
```
