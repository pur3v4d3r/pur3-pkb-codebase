# Self-Reflection Phase

> [!definition] **Self-Reflection Phase**
> The third phase of the cyclical model, encompassing self-judgment (comparing performance to goals and attributing outcomes causally) and self-reaction (emotional and adaptive/defensive inference responses). The output of this phase feeds directly into the next forethought cycle.
