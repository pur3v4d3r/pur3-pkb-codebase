# Cognitive Conflict

> [!definition] **Cognitive Conflict**
> The state of disequilibrium produced when new experiences cannot be assimilated into existing schemas, creating tension that motivates schema accommodation (restructuring). In educational contexts, cognitive conflict is the deliberate instructional trigger for conceptual change when existing schemas are incorrect or insufficient. See also: [[Equilibration]], [[Assimilation-and-Accommodation]].
