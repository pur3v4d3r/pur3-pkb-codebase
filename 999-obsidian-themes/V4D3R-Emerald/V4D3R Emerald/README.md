# V4D3R Emerald

> Dark theme with Emerald Green, Black, and Grey palette

## About

Color variant of **V4D3R**, generated via perceptually uniform
OKLCH hue rotation. Greys, blacks, and out-of-band colors are
preserved; semantic colors (success/warn/error) are not rotated.

- **Source hue:** 28.4°
- **Target hue:** 155.1°
- **Chroma:** preserved
- **Lightness offset:** +0.00

## Installation

Copy this directory into `.obsidian/themes/`, then enable in
**Settings → Appearance → Themes**.

Snippet variants in the sibling `snippets/` folder belong in
`.obsidian/snippets/`.
