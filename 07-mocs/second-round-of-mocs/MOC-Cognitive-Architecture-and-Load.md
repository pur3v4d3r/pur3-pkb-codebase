# 🧠 Map of Content — Cognitive Architecture & Load

> [!abstract] Domain Overview
> The cognitive architecture — working memory, long-term memory, and the interaction between them — is the substrate on which all learning, reasoning, and performance occurs. Cognitive Load Theory (CLT) is the most empirically productive framework for engineering learning materials around this architecture. This MOC integrates both.

[**Architecture-Core-Insight**:: Human cognition runs on a fundamentally asymmetric memory system: a severely capacity-limited working memory (4±1 chunks, Cowan) interfaces with a functionally unlimited long-term memory — and nearly every learning challenge can be framed as managing this asymmetry.]
