# 📋 SRL Living Learning Agenda

> [!abstract] Purpose
> This is the **physical instantiation of the [[Zimmerman's-Cyclical-SRL-Model|SRL feedback loop]]** — the node where the outputs of [[self-reflection-phase|Self-Reflection]] become the inputs of the next [[forethought-phase|Forethought Phase]]. Open this note BEFORE the Forethought template at the start of every reading session. Update it AFTER every Self-Reflection session. See [[adaptive-inference]] and [[strategic-planning]].

> [!warning] Consult Before Every Forethought Session
> The value of this document depends entirely on it being *actively consulted*, not merely maintained. If you skip reviewing this before a session, the feedback loop is structurally open.

## 🏷️ Strategy Tags Vocabulary

> *A stable vocabulary for tagging strategies in Forethought and Self-Reflection notes. Use in session notes for Dataview queryability. See [[Obsidian-Automation]].*

| Tag | Meaning | When to Use |
|-----|---------|-------------|
| `#strategy/connection-making` | Actively connecting new content to existing PKB nodes | Schema-rich reading |
| `#strategy/generative-question` | Generating questions during reading | All reading |
| `#strategy/mechanism-tracing` | Tracing causal chains and mechanisms | Mechanism-heavy texts |
| `#strategy/elaborative-interrogation` | Asking "why" and "how" questions during reading | Deep processing |
| `#strategy/self-explanation` | Explaining sections to yourself at boundaries | Dense theoretical |
| `#strategy/structural-reading` | Reading for overall structure before details | Schema-sparse |
| `#strategy/advance-organizer` | Activating prior knowledge before reading | All reading |
| `#strategy/flag-and-return` | Flagging confusion for later rather than forcing comprehension | Schema-sparse |
