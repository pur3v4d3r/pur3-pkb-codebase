# Type 2 Processing

> [!definition] **Type 2 Processing**
> Type 2 processing is a style of cognitive processing that requires working memory, deliberate engagement, and outputs that feel like judgments. It falls under [[Cognitive Architecture]], characterized by effortful reasoning and can be biased or motivated. Unlike Type 1 processing, it is not synonymous with 'rationality' or 'consciousness' in the broadest sense; rather, it is a specific mode of cognitive processing distinct from Type 1.

> [!attention] **Boundary**
> Not synonymous with 'rationality' or 'consciousness' in the broadest sense; it is a specific mode of cognitive processing distinct from Type 1 processing.

## Core Explanation

Type 2 processing involves engagement of working memory and serial execution, requiring an act of will or explicit cue. It operates deliberately and transparently to introspection, making its outputs feel like judgments. This process is depletable under sustained engagement and can be influenced by cognitive load, which fragments performance when competing demands are present.

In practice, Type 2 processing is engaged in novel computations, multi-step reasoning, hypothesis testing, and inhibition of Type 1 outputs. It functions as a permissive monitor that endorses Type 1 outputs by default, but this monitoring can fail, leading to systematic errors. The dual-process framework suggests that Type 2 processing is often necessary for accurate decision-making, especially in complex or novel situations.

Theoretical roots and conceptual nuances of Type 2 processing trace back to Wason's selection-task research, Tversky and Kahneman's heuristics-and-biases programme, Evans' heuristic-analytic theory, and Stanovich's work on individual differences in rationality. These converging streams provide an empirical foundation for the framework.

Empirically, Type 2 processing is affected by cognitive load, which can fragment performance when competing demands are present. The dual-process framework predicts that externalising mindware through knowledge management systems can enhance decision-making by surfacing relevant prior thinking at critical points.

## Mechanism

Type 2 processing engages working memory for its operations, serially processing information rather than in parallel. This requires deliberate initiation and depletes resources under sustained engagement, leading to performance degradation when cognitive load is high.

## Practical Implications

> [!example] **Application 1 — Instructional design**
> In instructional design, understanding Type 2 processing can inform the creation of learning materials that promote deliberate reasoning. For example, designing tasks that require students to engage in multi-step problem-solving rather than relying on intuitive responses can enhance their cognitive development and improve long-term retention.

> [!example] **Application 2 — Personal Knowledge Management**
> A well-designed personal knowledge management system functions as an externalised analogue of Type 2 processing, making relevant prior thinking available at decision points. This reduces the cognitive load on the individual by surfacing pertinent information and facilitating more deliberate reasoning.

> [!example] **Application 3 — AI Alignment**
> In AI alignment, modern large language models exhibit a recognisable analogue of Type 1/Type 2 processing. The autoregressive token-by-token generation operates as a fast, parallel, pattern-matching process (Type 1), while explicit chain-of-thought prompting functions as a slower, serial, deliberative supplement (Type 2). This dual-processing architecture is crucial for aligning AI systems with human values.

## Key Distinctions

> [!key-distinction] **Intrinsic vs Extraneous Load**
> Intrinsic load refers to the inherent complexity of a task, while extraneous load includes factors that interfere with working memory. Type 2 processing is more susceptible to degradation under high intrinsic and extraneous loads compared to Type 1, which operates automatically.

## Key Figures

- **Daniel Kahneman** — Kahneman proposed dual-process theory with his System 1 (Type 1) and System 2 (Type 2) framework, highlighting the distinction between automatic and deliberate cognitive processes.
- **Kevin Stanovich** — Stanovich contributed to the development of Type 2 processing by emphasizing individual differences in rationality and mindware, which determines what Type 2 can actually do when engaged.
- **John Evans** — Evans developed the heuristic-analytic theory and default-interventionist architecture, providing a framework for understanding how Type 1 and Type 2 processes interact in decision-making.

## Synthesis

Understanding Type 2 processing is crucial for comprehending human cognition and decision-making. It provides a framework for analyzing how deliberate reasoning interacts with automatic processes, offering valuable insights into cognitive biases and errors. By integrating this concept across domains such as instructional design, personal knowledge management, and AI alignment, we can enhance our ability to make informed decisions and improve cognitive performance.

The dual-process framework has significant implications for fields like psychology, education, and artificial intelligence. It challenges the notion of a clean division between rationality and error, emphasizing the complex interplay between Type 1 and Type 2 processes. This understanding is essential for developing more effective educational strategies, designing better AI systems, and improving cognitive interventions.
