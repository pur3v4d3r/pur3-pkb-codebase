# Cognitive Architecture

> [!definition] Cognitive Architecture
> [[Cognitive Architecture|Cognitive architecture]] refers to the fixed structural and functional organization of the human cognitive system — the invariant processing constraints, memory systems, and representational formats that determine how information is acquired, stored, retrieved, and applied. Unlike cognitive strategies, which are learnable and deployable, cognitive architecture represents the hardware-level constraints within which all learning must operate.
