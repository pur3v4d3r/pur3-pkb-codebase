## Core Explanation

> [!evidence] AI Alignment and Machine Learning
> **Structural principle:** Modern large language models exhibit a recognisable analogue of Type 1 / Type 2 processing — the autoregressive token-by-token generation operates as a fast, parallel, pattern-matching process, while explicit chain-of-thought prompting and the recently developed reasoning-mode architectures (deliberation tokens, reflection passes) function as a slower, serial, deliberative supplement. The default-interventionist architecture is recapitulated: the model produces a default response by pattern-matching against training data, and only when explicitly prompted to deliberate does it engage what looks like Type 2 processing. The substitution mechanism appears recognisable as well — models often answer easier questions than the ones asked, particularly when the harder question exceeds the patterns supported by training.
> **Concrete application:** Prompt engineering practices that consistently improve model output — "let's think step by step," "consider alternative answers," "first identify what's being asked" — are functional analogues of cognitive forcing functions, designed to engage the model's serial deliberation rather than allowing the autoregressive default to pass unscrutinised.
> **Boundary condition:** The analogy is structural rather than mechanistic; the underlying computational substrates are different, and care must be taken not to over-interpret the parallel.
