# Scaffold Fading Readiness Assessment

> [!definition] Scaffold Fading Readiness Assessment

## Core Explanation

> [!evidence] Scaffold Fading Readiness Assessment
> For each active scaffold in the PKB workflow, evaluate:
>
> - [ ] Do I routinely anticipate the scaffold's prompt before reading it?
> - [ ] Can I describe what the scaffold asks without looking at it?
> - [ ] Has the scaffold felt unnecessary or redundant for 3+ consecutive uses?
> - [ ] When I skip the scaffold, does my performance remain stable?
> - [ ] Can I perform the scaffolded function spontaneously in other contexts (not at my PKB)?
>
> **Scoring:** 4-5 checks → ready for fading. 2-3 checks → ready for partial fading (simplify scaffold). 0-1 checks → maintain full scaffold.
> *— [[pkb-metacognitive-scaffolding-for-study-and-planning-foundational-report-2026-04-18]]*
