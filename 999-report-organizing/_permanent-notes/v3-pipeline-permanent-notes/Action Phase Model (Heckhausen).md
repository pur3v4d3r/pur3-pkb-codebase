# Action Phase Model (Heckhausen)

> [!definition] Action Phase Model (Heckhausen)
> The theoretical framework partitioning goal pursuit into four sequential phases — predecisional deliberation, postdecisional preplanning, actional execution, and postactional evaluation — each governed by a distinct mind-set and posing different regulatory demands. Implementation intentions are situated theoretically at the boundary between the second and third phases, where preplanning produces the cognitive structures that subsequently govern enactment.
>
> **Boundary:** The Action Phase Model is a *functional* partition, not a claim that distinct neural systems implement each phase; the phases describe what the cognitive system is doing, not where in the brain it is doing it.
>
> **Report-Specific Significance:** Implementation intentions are best understood as a specific kind of preplanning that exploits the implemental mind-set's capacity to form anticipatory commitments to action.
>
> **See also:** [[intention]], [[forethought-phase]], [[cyclical-model-of-self-regulated-learning]]
