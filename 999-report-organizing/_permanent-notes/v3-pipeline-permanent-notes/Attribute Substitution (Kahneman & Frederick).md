# Attribute Substitution (Kahneman & Frederick)

> [!definition] Attribute Substitution (Kahneman & Frederick)
> A cognitive process in which the cognitive system, faced with a difficult target question that is computationally demanding for Type 2, unconsciously substitutes an easier heuristic question that can be addressed by Type 1 pattern-matching, then delivers the answer to the heuristic question as if it were the answer to the original target question. The substitution is opaque to introspection — the agent does not experience having answered a different question, only having answered the question that was asked.
>
> **Boundary:** Attribute substitution is not the same as ignorance or laziness. The substituted answer is often a sophisticated computation in its own right; the error lies in the mismatch between the question Type 1 actually answered and the question that was actually asked. The agent typically *cannot* introspect on the substitution because the entire process is Type 1.
>
> **Report-Specific Significance:** Attribute substitution is the generative mechanism of bias in the heuristics-and-biases tradition. Understanding it allows one to predict not just *that* errors will occur but *which kind* of error, in *which direction*, by *what magnitude*.
>
