## Reflections

> [!claude-insight] The Feature-Function Map as Diagnostic Tool
> The mapping of PKB features to metacognitive functions serves not only as a descriptive framework but as a **diagnostic tool**. A learner whose PKB contains extensive notes but no linking structure has externalised monitoring but not integration assessment. A learner who links extensively but never reviews has scaffolded integration monitoring but not self-reflection. A learner who creates elaborate templates but never consults them after initial creation has scaffolded forethought but disconnected it from the cyclical feedback loop. By examining which metacognitive functions one's PKB workflow currently scaffolds — and which it neglects — the learner can identify regulatory gaps with specificity and design targeted interventions.
