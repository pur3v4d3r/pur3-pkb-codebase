# david-ausubel

> [!definition] david-ausubel

> - **Definition**: David Ausubel is an educational psychologist known for his theory of meaningful learning, which emphasizes the importance of connecting new information to existing knowledge in order to facilitate deeper understanding and retention.

## Core Explanation

> [!analytical-insight] Core Explanation
> Ausubel's theory of meaningful learning posits that learners can better understand and retain new information when it is connected to their prior knowledge. This process involves subsumption, where new concepts are integrated into a learner’s existing cognitive structure.

> [!analytical-insight] Explanation 2
> In practice, this means educators should design lessons that build on students' existing knowledge, using techniques such as advance organizers to help students make connections between new and old information.

> [!analytical-insight] Explanation 3
> Key nuances include the distinction between rote learning (memorization without understanding) and meaningful learning (integration with prior knowledge). Ausubel also emphasized the importance of cognitive structure in facilitating meaningful learning.

## Practical Implications

> [!example] Application
> In education, teachers can enhance student learning by using Ausubel's principles to create lessons that build on students' existing knowledge.

> [!example] Application
> This approach can lead to more effective and efficient learning outcomes, as students are better able to understand complex concepts when they relate them to what they already know.
