# Retrieval Practice (Roediger & Karpicke, 2006)

> [!definition] Retrieval Practice (Roediger & Karpicke, 2006)
> [[Desirable Difficulties (Robert Bjork, 1994)|Retrieval practice]] is the act of deliberately recalling information from memory as a learning strategy, producing stronger and more durable memory traces than re-studying the same material. The [[Testing-Effect|testing effect]] — the finding that retrieval produces superior retention compared to re-exposure — is among the most robust findings in cognitive psychology, replicated across materials, populations, and retention intervals.
>
> **Boundary:** Retrieval practice is most effective when retrieval is effortful but successful. Failed retrieval without subsequent feedback can reinforce errors rather than correct understanding.
>
> **Report-Specific Significance:** Provides the cognitive basis for PKB review system design (Section 3) and grounds the argument that note review should demand active recall rather than passive re-reading.
>
> **See also:** [[Testing-Effect]], [[spaced-repetition]], [[Desirable Difficulties (Robert Bjork, 1994)]], [[anki]]

> [!evidence] Retrieval Practice (Roediger & Karpicke, 2006)
> [[Desirable Difficulties (Robert Bjork, 1994)|Retrieval practice]] designates the strategy of deliberately recalling information from memory rather than passively re-reading or reviewing it. The [[Testing-Effect|testing effect]] — the robust finding that retrieval attempts enhance subsequent retention more than equivalent time spent studying — demonstrates that retrieval is not merely an assessment of learning but a *learning event in itself*. Each successful retrieval strengthens the memory trace and the retrieval pathways that led to it; each unsuccessful retrieval, when followed by feedback, generates a potent encoding opportunity. The mechanism is not simply repetition but the effortful reconstruction of the target from available cues.
>
> **Boundary:** Retrieval practice is most effective when it is effortful (not trivially easy), spaced (not massed), and varied (drawing on different cues across occasions). Retrieval that is too easy — recognizing an answer on a multiple-choice test, for instance — produces weaker learning effects than retrieval that requires genuine recall.
>
> **See also:** [[testing-effect-retrieval-practice-effect]], [[Retrieval-Practice-and-the-Testing-Effect]], [[evidence-based-learning-strategies]]

> [!evidence] Retrieval Practice (Roediger & Karpicke, 2006)
> The strategy of deliberately recalling information from memory rather than passively re-reading it. The [[Testing-Effect|testing effect]] demonstrates that retrieval attempts enhance subsequent retention more than equivalent study time. The mechanism involves effortful reconstruction of the target from available cues, which strengthens both the memory trace and the retrieval pathways.
>
> **Boundary:** Most effective when effortful, spaced, and varied. Trivially easy retrieval (e.g., recognition) produces weaker effects than genuine recall.
>
> **Report-Specific Significance:** Establishes the retrieval architecture imperative (Section 4): PKM systems must incorporate deliberate retrieval mechanisms to prevent the knowledge-in-system/forgetting-in-learner dissociation.
