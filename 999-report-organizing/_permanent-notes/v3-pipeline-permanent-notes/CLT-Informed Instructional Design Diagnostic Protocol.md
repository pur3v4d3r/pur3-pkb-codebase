> [!protocol] CLT-Informed Instructional Design Diagnostic Protocol
> **Purpose:** Systematic evaluation of existing instructional materials using CLT principles.
>
> **Step 1 — Element Interactivity Assessment**
> - Identify all information elements the learner must process simultaneously
> - Count the interactions between elements (dependencies, relationships, sequences)
> - Classify: Low interactivity (elements can be learned independently) vs. High interactivity (elements must be processed together)
> - If high: Plan progressive complexity sequencing
>
> **Step 2 — Extraneous Load Scan**
> - [ ] Split attention: Are mutually referential sources physically separated?
> - [ ] Redundancy: Are multiple sources presenting identical information?
> - [ ] Transient information overload: Is spoken/animated content too fast for processing?
> - [ ] Navigational complexity: Must learners search for information rather than process it?
> - [ ] Seductive details: Do decorative elements distract from core content?
>
> **Step 3 — Expertise Calibration Check**
> - Identify the target learner's expected schema development level
> - Check for expertise reversal risk: Is instructional support calibrated to that level?
> - If designing for mixed-expertise groups: Plan adaptive or differentiated elements
>
> **Step 4 — Design Intervention Selection**
> - For each identified extraneous load source: select appropriate CLT effect principle
> - For high intrinsic load: implement worked examples → faded examples → practice sequence
> - For mixed audiences: plan expertise-adaptive scaffolding
>
> **Step 5 — Verification**
> - Review redesigned materials against original CLT analysis
> - Predict: What load type does each design change affect?
> - If prediction is unclear, the design change may be cosmetic rather than cognitive
