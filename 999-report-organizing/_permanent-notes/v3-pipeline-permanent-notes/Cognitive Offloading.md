# Cognitive Offloading

> [!definition] Cognitive Offloading
> The delegation of cognitive work from internal biological resources (working memory, long-term memory, executive function) to external artefacts (notes, diagrams, templates, checklists) that carry informational or procedural content that would otherwise need to be maintained internally.
>
> **Boundary:** Not all external tool use constitutes cognitive offloading. Offloading specifically refers to cases where the external artefact *replaces* a cognitive function, not merely *augments* it. Looking up a phone number is offloading; using a calculator to check mental arithmetic is augmentation.
>
> **Report-Specific Significance:** Cognitive offloading is identified as the primary mechanism by which PKB scaffolding reduces cognitive load during self-regulation, but is also identified as a source of developmental risk (the Cognitive Offloading Paradox).
>
> **See also:** [[Cognitive Offloading]], [[working-memory]], [[Cognitive Load Theory (CLT)]]
