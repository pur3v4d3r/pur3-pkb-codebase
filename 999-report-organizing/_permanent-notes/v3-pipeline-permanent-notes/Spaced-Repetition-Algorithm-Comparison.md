## Core Explanation

> [!analytical-insight] Core Explanation
> Paragraph 1: Foundational context and core mechanism. Spaced repetition is a learning technique that schedules the review of material at increasing intervals based on the learner's performance, aiming to enhance long-term memory retention. Different algorithms are used to determine these intervals, each with its own theoretical basis.

> [!analytical-insight] Explanation 2
> Paragraph 2: How it works or is applied in practice. These algorithms typically use heuristics and mathematical models to predict when a user will need to review material again based on their performance history. Commonly used algorithms include the Leitner system, SuperMemo's SM-2 algorithm, and the spaced repetition algorithm from Anki.

> [!analytical-insight] Explanation 3
> Paragraph 3: Key nuances, sub-variants, or theoretical roots. Each algorithm has its own strengths and weaknesses, such as the spacing density, the forgetting curve approximation, and the handling of new material versus previously learned content.
