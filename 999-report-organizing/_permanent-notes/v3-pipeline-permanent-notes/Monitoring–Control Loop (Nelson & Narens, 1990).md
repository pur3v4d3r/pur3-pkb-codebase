# Monitoring–Control Loop (Nelson & Narens, 1990)

> [!definition] Monitoring–Control Loop (Nelson & Narens, 1990)
> A two-level cognitive architecture in which an *object level* performs primary cognitive work (in reading: decoding, parsing, integration) while a *meta level* maintains a representation of the object level's state and intervenes when needed. *Monitoring* is the upward information flow from object to meta. *Control* is the downward regulatory flow from meta to object. The two flows together form a feedback loop whose stability and accuracy determine whether self-regulated cognition is possible at all.
>
> **Boundary:** This is not the same as introspection in the philosophical sense, nor is it a metaphor for conscious thought. The meta level can operate largely outside awareness, producing felt experiences (difficulty, ease, confusion) without producing the explicit verbal thought "I am monitoring."
>
> **Report-Specific Significance:** The entire architecture of strategic reading, fix-up behavior, and self-regulated comprehension is built on this loop. Without it, reading would be either a passive perceptual flow or an exhaustive deliberate process; the loop is what makes selective, on-demand cognitive intervention possible.
>
> **See also:** [[metacognitive-monitoring]], [[metacognitive-control]], [[regulation-of-cognition]], [[self-regulated-learning]]

> [!evidence] Monitoring–Control Loop (Nelson & Narens, 1990)
> The general theoretical framework distinguishing two levels of cognitive activity — the *object level*, which performs the cognitive task itself, and the *meta level*, which observes the object level and supplies regulatory control — and specifying that information flows between the levels in two directions: monitoring (object → meta) and control (meta → object). Applied to reading, the framework specifies that comprehension processes operate at the object level while metacognitive processes operate at the meta level, with monitoring providing signals about comprehension state and control providing regulatory action when monitoring detects breakdown.
>
> **Boundary:** The monitoring–control loop is a *functional* distinction, not a *structural* one; it does not posit two separate cognitive systems but rather two functionally distinct roles that the same underlying cognitive system performs.
>
> **Report-Specific Significance:** The loop provides the formal architecture within which all subsequent components of the report's framework are situated. It is the mechanical heart of the metacognitive reading model.
