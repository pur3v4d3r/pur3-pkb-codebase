## Open Threads

> [!tension-identified] Externalisation vs. Internalisation: Where Should Cognition Live?
> **Position A:** Externalised cognition (offloading to PKB systems) is optimal because it frees cognitive resources for higher-order processing and provides reliable, persistent, searchable memory (extended mind thesis, distributed cognition).
> **Position B:** Internalisation of knowledge and regulatory processes is essential for expertise, transfer, and flexible application in contexts where external tools are unavailable (traditional cognitive science, expertise research).
> **Current evidence:** Both positions have merit. Expert performance requires substantial internalised knowledge and skill, yet experts also routinely use external tools and systems. The dichotomy may be false: effective cognition likely involves a dynamic allocation between internal and external resources, contingent on task demands.
> **Why it matters:** PKB designers must decide whether the goal is permanent externalisation (building the best possible external cognitive system) or developmental internalisation (using the external system as a temporary training tool). This report argues for the latter.
