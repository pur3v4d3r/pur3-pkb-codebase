# Grow's Staged Self-Directed Learning Model (Grow, 1991)

> [!definition] Grow's Staged Self-Directed Learning Model (Grow, 1991)
> A developmental model describing four stages through which learners progress: Stage 1 (Dependent — requires authority/coach), Stage 2 (Interested — responds to motivator/guide), Stage 3 (Involved — benefits from facilitator), Stage 4 (Self-Directed — uses consultant/delegator). The model's critical insight is that mismatches between learner stage and teaching style produce predictable dysfunction.
>
> **Boundary:** Stages are domain-specific, not global. A learner may be at Stage 4 in one domain and Stage 1 in another. The model describes a developmental trajectory, not a fixed categorization.
>
> **Report-Specific Significance:** Provides the primary developmental framework for understanding how self-direction grows through scaffolded progression.
>
> **See also:** [[Scaffolded Fading]], [[Vygotsky's-Zone-of-Proximal-Development]]
