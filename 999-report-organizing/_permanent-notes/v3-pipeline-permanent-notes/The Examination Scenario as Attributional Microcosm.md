## Examples

> [!example] The Examination Scenario as Attributional Microcosm
> Consider a student who receives a failing grade on a midterm examination. The causal search activates immediately: *Why did I fail?* The student might attribute the failure to insufficient effort ("I didn't study enough"), to ability ("I'm not smart enough for this course"), to task difficulty ("That exam was impossibly hard"), or to circumstances ("I was ill that day"). Each of these attributions occupies a different position within the dimensional taxonomy that Weiner would later formalise, and each generates a different emotional response and a different behavioural trajectory. The student who attributes failure to effort feels guilt and resolves to work harder. The student who attributes failure to stable inability feels shame and considers dropping the course. The same objective event — the same grade, the same red marks on the same paper — produces radically divergent motivational outcomes. The mechanism is the attribution.
> *— [[attribution-theory-foundational-report-2026-04-19]]*
