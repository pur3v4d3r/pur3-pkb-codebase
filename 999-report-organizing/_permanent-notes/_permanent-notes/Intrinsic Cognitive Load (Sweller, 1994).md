# Intrinsic Cognitive Load (Sweller, 1994)

> [!definition] Intrinsic Cognitive Load (Sweller, 1994)
> The working memory demand generated by the inherent complexity of learning material, specifically by the number of interacting elements that must be processed simultaneously. Intrinsic load cannot be arbitrarily reduced without distorting the material, but it can be managed through sequencing, scaffolding, and expertise development. For a given learner at a given expertise level, intrinsic load is approximately fixed by the material's structure.
>
> **Boundary:** Intrinsic load is relative to expertise: what generates high intrinsic load for a novice may generate near-zero load for an expert who has schematized the relevant elements. This expertise-relativity is the foundation of the expertise-reversal effect discussed in Section 3.
>
> **Report-Specific Significance:** PKM design informed by CLT should scaffold intrinsic load through thoughtful note sequencing, progressive templates, and explicit prerequisite linking — not by simplifying material to the point of inaccuracy.
>
> **See also:** [[intrinsic-cognitive-load]], [[element-interactivity]], [[expertise-reversal-effect]]

> [!evidence] Intrinsic Cognitive Load (Sweller, 1994)
> The cognitive demand inherent to the material being learned, determined by the number of interacting elements that must be simultaneously processed in [[working-memory|working memory]] to achieve understanding. Intrinsic load is a function of [[element-interactivity|element interactivity]] relative to the learner's level of expertise.
>
> **Boundary:** Intrinsic load cannot be directly altered by instructional design; however, it can be managed by sequencing (presenting isolated elements before their interactions) or by building prerequisite schemas that reduce the number of novel interacting elements.
>
> **Report-Specific Significance:** Intrinsic load represents the irreducible core of learning demand. All CLT design strategies ultimately aim to ensure that working memory resources are available for processing intrinsic, rather than extraneous, complexity.
>

> [!evidence] Intrinsic Cognitive Load (Sweller, 1994)
> The processing demand imposed by the inherent complexity of the material being learned, determined by [[element-interactivity]] — the number of information elements that must be processed simultaneously to achieve understanding. Intrinsic load is a property of the interaction between the material and the learner's current expertise; it cannot be altered by instructional format, only managed through sequencing and scaffolding.
>
> **Boundary:** Not identical to "difficulty." A task can be difficult for motivational or metacognitive reasons without imposing high intrinsic load. The critical determinant is element interactivity, not subjective difficulty.
>
> **Report-Specific Significance:** One of two surviving load types in CLT's reconceptualized framework; its management through sequencing and progressive complexity is the primary design lever for complex material.
>
> **See also:** [[element-interactivity]], [[schema-construction]], [[scaffolding]]
