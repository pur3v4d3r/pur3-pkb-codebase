## Core Explanation

> [!evidence] Technical Detail: Instructional Complexity as a Single Construct
> Currently, instructional science lacks a unified complexity construct. Different traditions use different metrics:
> - CLT uses element interactivity
> - [[cognitive-task-analysis|Cognitive task analysis]] uses task complexity measures (number of steps, decision points, conditional branches)
> - Learning science uses *knowledge component* models (number of knowledge components required for a task)
> - [[deliberate-practice]] theory uses *desirable difficulties*
> - Educational data mining uses *item difficulty* parameters (IRT models)
>
> **The speculative proposition:** Element interactivity, properly formalized, may subsume these other complexity constructs. They are all, arguably, measuring the same underlying property — the number of novel relationships that must be simultaneously processed — through different lenses. If element interactivity is formalized as a graph-theoretic property of <material, expertise> pairs, then:
> - Task complexity = the density of the element interaction graph before expertise transformation
> - Knowledge components = the nodes in the element interaction graph
> - Item difficulty = a statistical estimate of average element interactivity across a population
> - Desirable difficulty = element interactivity slightly above the learner's schema capacity, forcing productive processing
>
> A unified instructional complexity construct would enable cross-paradigm research synthesis and create a common language for instructional design.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
