# Levels of Processing Theory (Craik & Lockhart, 1972)

> [!definition] Levels of Processing Theory (Craik & Lockhart, 1972)
> A framework proposing that the durability of memory traces is a function of the depth at which information is processed during encoding. Shallow processing (attending to sensory or perceptual features such as letter shapes or sounds) produces weaker, less durable traces. Deeper processing (attending to semantic, conceptual, and associative features) produces stronger, more durable traces. Elaborative rehearsal — actively connecting new information to existing knowledge — represents the deep end of the processing continuum.
>
> **Boundary:** LOP has been criticized for circularity (defining depth by subsequent memory performance rather than by independent process criteria), and for failing to specify a priori what counts as "deep" independent of outcomes. The ESP provides a specific counterexample to any simple LOP claim: deep processing does not guarantee retrieval if the test conditions do not match encoding conditions.
>

> [!evidence] Levels of Processing Theory (Craik & Lockhart, 1972)
> The theoretical framework proposing that memory trace durability is a direct function of the depth of cognitive processing applied to incoming stimuli during encoding. Processing occurs along a continuum from shallow (physical/structural feature analysis) to deep (semantic/meaning-engaged analysis), with deeper processing producing more durable, accessible memory representations. The framework positions memory as the residue of cognitive operations rather than a product of structural storage mechanisms.
>
> **Boundary:** The framework applies most robustly to explicit episodic memory for verbal material under standard semantic retrieval conditions. It is less applicable to implicit memory, procedural learning, and conditions where transfer-appropriate processing considerations override depth.
>
> **Report-Specific Significance:** The primary theoretical framework of this report — the locus of all other constructs.

> [!evidence] Levels of Processing Theory (Craik & Lockhart, 1972)
> A theory of memory encoding proposing that the durability and strength of a memory trace is determined by the depth of processing applied during encoding. Shallow processing (phonological, structural) produces weaker traces; deep processing (semantic, elaborative, self-referential) produces stronger, more durable traces.
>
> **Boundary:** The framework has been criticized for difficulty in operationalizing "depth" independently of memory outcomes (circular definition problem). It is better understood as a heuristic framework than a precise mechanistic theory.
>
> **Report-Specific Significance:** Levels of Processing provides the theoretical grounding for why active reading strategies (generation, elaboration, self-explanation) outperform passive re-reading — they inherently produce deeper processing.
>
