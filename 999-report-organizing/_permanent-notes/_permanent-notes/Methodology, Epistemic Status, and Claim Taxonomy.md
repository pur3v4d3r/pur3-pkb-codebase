> [!methodology-and-sources] Methodology, Epistemic Status, and Claim Taxonomy
> **Intellectual Traditions Synthesized**
> This report synthesizes knowledge from the following traditions: (1) Experimental cognitive psychology (Ebbinghaus, Bartlett, Craik, Baddeley) — controlled laboratory experiments establishing fundamental memory phenomena; (2) Neuropsychology (Tulving, Squire, Milner) — patient case studies and lesion analysis isolating dissociable memory systems; (3) Cognitive neuroscience (Bliss & Lømo, Nader, Squire) — molecular and systems neuroscience of consolidation; (4) Educational psychology (Bjork, Roediger, Sweller) — applied translation of memory science into instructional design; (5) Cognitive architecture (ACT-R, Baddeley model) — computational and theoretical frameworks for human memory.
>

>
> **Limitations**
> - Coverage of non-Western memory research traditions is absent
> - Developmental memory (infant memory, aging-related decline) is treated minimally
> - Memory pathology (PTSD, Alzheimer's, confabulation syndromes) is omitted
