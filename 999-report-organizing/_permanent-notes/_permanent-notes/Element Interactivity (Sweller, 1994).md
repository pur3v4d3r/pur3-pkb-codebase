# Element Interactivity (Sweller, 1994)

> [!definition] Element Interactivity (Sweller, 1994)
> The degree to which the elements of a learning task must be processed simultaneously in [[working-memory|working memory]] to be understood. High element interactivity means that many elements interact and must be held in mind together; low element interactivity means elements can be processed sequentially. Element interactivity determines [[intrinsic-cognitive-load|intrinsic cognitive load]] and, critically, decreases as learners develop chunks and schemas that compress multiple elements into single units.
>
> **Boundary:** Element interactivity is a function of the interaction between material complexity and learner expertise, not a fixed property of the material alone.
>
> **Report-Specific Significance:** Element interactivity provides the formal mechanism through which chunking reduces cognitive load: each new chunk reduces the effective number of interacting elements that must be held in working memory simultaneously.
>
> **See also:** [[element-interactivity]], [[intrinsic-cognitive-load]], [[john-sweller]]

> [!evidence] Element Interactivity (Sweller, 1994)
> The degree to which elements in a learning task must be processed simultaneously because they interact with and depend upon each other. Low element interactivity: elements can be learned in isolation (e.g., vocabulary pairs). High element interactivity: elements only make sense in relation to each other (e.g., cause-and-effect chains, multistep proofs). The primary determinant of intrinsic load; also the explanatory construct for why expertise makes complex tasks less cognitively demanding — schemas reduce the apparent interactivity of familiar configurations.

> [!evidence] Element Interactivity (Sweller, 1994)
> The number of information elements that must be processed simultaneously — held in working memory at the same time — to achieve understanding. Element interactivity is the primary determinant of intrinsic cognitive load and varies as a function of both material complexity and learner expertise (expert schemas chunk multiple elements into single units, reducing interactivity).
>
> **Boundary:** Element interactivity is not a fixed property of content but a relational property of the content-learner interaction. The same material has high element interactivity for novices and low element interactivity for experts.
>
> **Report-Specific Significance:** The construct that bridges CLT's architectural claims to its empirical predictions; all CLT effects are fundamentally effects of element interactivity management.
>
> **See also:** [[working-memory]], [[chunking]], [[expertise-reversal-effect]]
> *— [[cognitive-load-theory-foundational-report-2026-04-18]]*

> [!evidence] Element Interactivity (Sweller, 1994)
> The degree to which the elements constituting a body of information interact with each other and must therefore be processed simultaneously to produce understanding. Information with low element interactivity can be learned element-by-element without reference to the whole; information with high element interactivity can only be understood by grasping multiple elements and their relationships concurrently. High element interactivity is the primary source of intrinsic cognitive load.
>
> **Boundary:** Element interactivity is a property of the interaction between the material and the learner's current schema state, not a fixed property of the material itself. A concept that is high-interactivity for a novice may be processed as a single chunk (low interactivity) by an expert who has automated the relevant schema.
>
> **Report-Specific Significance:** Knowledge domains vary dramatically in their element interactivity profiles, and PKM practitioners working across multiple domains face variable intrinsic load that should inform how they time, structure, and support their PKM sessions.
>
> **See also:** [[element-interactivity]], [[intrinsic-cognitive-load]], [[Cognitive-Architecture-Working-Memory-&-Long-Term-Memory]], [[chunking]]
> *— [[pkm-and-cognitive-load-foundational-report-2026-04-05_report]]*

> The degree to which understanding a body of information requires simultaneous processing of multiple interdependent elements. High element interactivity (where elements must be grasped together) generates high intrinsic load; low element interactivity (where elements can be processed sequentially) generates low intrinsic load.
>
> **Boundary:** Element interactivity is determined by the interaction between material structure and learner schema state, not by material alone. Familiar patterns that require high simultaneous processing for novices may be handled as single chunks by experts.
