> [!diagram] Cognitive Slack Model: Working Memory Dynamics
> ```
> Working Memory Capacity (fixed)
> ═══════════════════════════════════════════════════════════
>
> BELOW THRESHOLD (<98% coverage):
> [ Decoding  | Comprehension | Unknown word 1 | Unknown word 2 | Unknown word 3 ]
>  ████████████████████████████████████████████████████████
>  → Capacity fully consumed → ZERO cognitive slack → no inference
>
> AT THRESHOLD (98-99% coverage):
> [ Decoding  | Comprehension | Unknown word 1          |    SLACK    ]
>  ████████████████████████████████████░░░░░░░░░░░░░░░░░░░
>  → COGNITIVE SLACK available → inference mechanism can activate
>
> ABOVE THRESHOLD (99%+):
> [ Decoding  | Comprehension |          LARGE SLACK           ]
>  ████████████████████████████░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░
>  → Large slack → inference + elaborative processing → deep encoding
>  BUT: fewer unfamiliar words encountered → lower acquisition opportunity
>
> OPTIMAL ZONE: 98-99% coverage (positive slack + sufficient unknown words)
> ```
> **Reading Guide:** This diagram illustrates why the coverage threshold creates a working memory tipping point. Below 98%, all capacity is consumed; above 99%, capacity is free but opportunities are rare. The 98-99% zone balances cognitive slack availability with unknown word density.
