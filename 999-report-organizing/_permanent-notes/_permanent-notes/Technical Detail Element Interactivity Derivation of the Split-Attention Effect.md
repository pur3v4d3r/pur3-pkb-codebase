## Core Explanation

> [!evidence] Technical Detail: Element Interactivity Derivation of the Split-Attention Effect
> **The situation:** Learning material consists of two or more sources of information that are mutually referential — for example, a geometry diagram and accompanying text explaining the diagram. The sources are *physically separated* (different locations on a page, different pages, or different modalities without integration).
>
> **The interactivity demand:** The learner must mentally integrate the sources. This requires:
> - Processing elements from Source A (diagram elements)
> - Processing elements from Source B (text elements)
> - Holding Source A elements in working memory while searching for corresponding Source B elements
> - Integrating the correspondence between A and B elements
>
> Each integration step requires simultaneously holding elements from both sources *plus* the relational mapping between them. The physical separation forces the learner to perform this integration entirely within working memory, adding element interactivity beyond what the content itself requires.
>
> **The [[split-attention-effect|split-attention]] intervention:** Physically integrate the information sources (e.g., place text labels directly on the diagram). This eliminates the need for the learner to perform mental integration — the interactivity between sources is resolved in the external representation rather than in working memory. The effective element interactivity drops to the *intrinsic* interactivity of the integrated content.
>
> **The element interactivity analysis:** The split-attention effect is predicted if and only if the two sources are *mutually referential* (they interact). If the two sources are intelligible independently (low interactivity between them), physical integration provides no benefit — in fact, it can produce the [[redundancy-effect]] by adding unnecessary elements.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
