# Technique: Original Synthesis  Connecting to an Existing Framework

> [!definition] **Technique: Original Synthesis  Connecting to an Existing Framework** *(from [[optimal-reading-session-worked-example-2026-03-25]])*
> *Why here: When a concept crystallizes in a way that connects to a different domain's framework, record it explicitly. This is the kind of note that makes your PKB genuinely productive — a cross-domain connection that neither source explicitly makes.*
> 
> **Synthesis produced:** The "SRL cycle as self-improving algorithm" claim in the report resonates with the structure of [[deliberate-practice]] in a way that deserves explicit articulation. In Ericsson's model, expert development accelerates because each practice session produces targeted feedback that makes the next session more efficient. In the SRL model described here, each reading cycle produces five specific inputs that make the next cycle better. Both systems have *increasing marginal returns* — later iterations are more efficient than earlier ones. The mechanism is different (expert feedback vs. self-generated feedback), but the structural logic is identical: the quality of the *feedback loop* is what separates developing expertise from mere repeated experience.
> 
> **PKB action:** Create a note linking [[deliberate-practice]] and [[Zimmerman's-Cyclical-SRL-Model]] via this structural isomorphism. See also: [[the-srl-cycle-as-a-calibration-engine]].
