# Schema as Variable-Slot Data Structure (Rumelhart, 1975)

> [!definition] Schema as Variable-Slot Data Structure (Rumelhart, 1975)
> For Rumelhart, a schema is a data structure with two components: a *fixed structure* that defines what the schema is for (the type), and a set of *variable slots* that are instantiated with specific values when the schema is applied to a particular case. The room schema has fixed structure (enclosed space used for human activity) and slots for dimensions, walls, floor, ceiling, doors, furniture, and occupants. Slot values are assigned by incoming data when data are available, or by *default values* — the schema's built-in expectations about the most probable slot contents in the absence of specific information. It is these default values that generate schema-driven inference, and it is the assignment of slot values to a specific context that constitutes schema *instantiation*.
