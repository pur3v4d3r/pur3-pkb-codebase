## Core Explanation

> [!evidence] Edge Case: When Cognition Is Not "In the Head"
> **The case:** Learning situations involving physical manipulation, gesture, embodied simulation, or environmental scaffolding — where cognition is distributed across body and environment rather than confined to working memory.
>
> **What standard element interactivity predicts:** Element interactivity is a working memory phenomenon. Elements must be processed *in working memory*. The body and environment provide inputs but don't contribute to element processing capacity.
>
> **What actually happens:** Research in [[4e-cognition|embodied, embedded, enacted, and extended cognition]] demonstrates that physical manipulation of learning materials, gesturing while explaining, and environmental offloading can reduce working memory demands in ways that are not merely "externalizing elements." For example, learners who physically manipulate algebra tiles show different learning patterns than those who work with abstract notation, even when the element interactivity of the mathematical content is identical. The physical manipulation appears to distribute processing across sensorimotor systems that are not captured by CLT's information-processing model of working memory.
>
> **Why this matters:** CLT's cognitive architecture assumes a clear separation between working memory (where element interactivity occurs) and the external environment (which provides inputs to working memory). Embodied cognition challenges this boundary by suggesting that processing capacity is partially constituted by bodily and environmental resources. If cognition extends beyond the skull, then element interactivity is not confined to working memory — it is distributed across a larger cognitive system that includes body and environment.
>
> **Implications:** This does not invalidate element interactivity but requires reconceptualizing where "elements" are processed. An extended-cognition-compatible version of CLT would need to define element interactivity as the number of elements that must be simultaneously processed *across the entire cognitive system* (brain, body, environment), not just within working memory. This remains a theoretical challenge because CLT's evolutionary framework (particularly the Narrow Limits of Change principle) seems to apply specifically to neural working memory, not to extended cognitive systems.
