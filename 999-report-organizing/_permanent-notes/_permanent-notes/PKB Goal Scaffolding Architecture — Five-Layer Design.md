> [!diagram] PKB Goal Scaffolding Architecture — Five-Layer Design
> ```
>  ┌─────────────────────────────────────────────────────────┐
>  │  LAYER 1: DIRECTION                                     │
>  │  Long-term learning directions + intrinsic goal content  │
>  │  Review: Quarterly                                       │
>  ├─────────────────────────────────────────────────────────┤
>  │  LAYER 2: PROJECT                                       │
>  │  Bounded learning projects + mastery success criteria    │
>  │  Review: Monthly                                         │
>  ├─────────────────────────────────────────────────────────┤
>  │  LAYER 3: CYCLE                                         │
>  │  Fortnightly goals + strategies + predicted challenges   │
>  │  Implements: Zimmerman's forethought phase               │
>  ├─────────────────────────────────────────────────────────┤
>  │  LAYER 4: SESSION                                       │
>  │  Session goals + strategy notes + post-session reflection│
>  │  Implements: Performance + self-reflection phases         │
>  ├─────────────────────────────────────────────────────────┤
>  │  LAYER 5: ASSESSMENT                                    │
>  │  Multi-scale review (micro/meso/macro)                  │
>  │  Informational feedback at process + SR levels           │
>  └─────────────────────────────────────────────────────────┘
>
>  ◄── Each layer satisfies autonomy, competence, relatedness ──►
> ```
> *— [[goal-setting-and-assessment-in-pkm-foundational-report-2026-04-15_report]]*
