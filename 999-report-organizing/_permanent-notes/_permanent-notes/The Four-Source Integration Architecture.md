> ```

>                ┌─────────────────┼─────────────────┐
>                │   COGNITIVE PROCESSING OPERATIONS │

>     │   MASTERY      │ │IOUS    │ │PERSUASION│ │   /AFFECTIVE  │
>     │   (dominant)   │ │EXPER.  │ │          │ │     STATES    │
