## Core Explanation

> [!evidence] Important Nuance: Extraneous Load as Extraneous Element Interactivity
> The reconceptualization of extraneous load is the key move. In the original tripartite model, "extraneous load" often functioned as a residual category — anything that made learning harder but wasn't attributable to intrinsic difficulty was labeled extraneous. This created circular explanations: "Why did this format impair learning? Because it increased extraneous load. How do we know it increased extraneous load? Because it impaired learning."
>
> Reconceptualizing extraneous load as extraneous element interactivity breaks this circularity. The question becomes operational: "Does this instructional format require the learner to simultaneously process elements that *do not need to be processed simultaneously* for understanding the content?" If yes, the format introduces extraneous element interactivity. This is testable, predictable, and not circular.
>
> **When the distinction matters:** Research design, measurement of cognitive load, and prediction of novel instructional effects.
> **When it doesn't:** Day-to-day instructional design decisions where the surface-level "reduce extraneous load" heuristic produces acceptable results.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
