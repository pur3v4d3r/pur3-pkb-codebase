# Element Interactivity (Sweller & Chandler, 1994)

> [!definition] Element Interactivity (Sweller & Chandler, 1994)
> The number of elements in a learning task that must be simultaneously held in working memory and considered in relation to each other for comprehension to be possible. High element-interactivity material (e.g., understanding a mathematical proof, comprehending a complex philosophical argument, reading dense technical documentation) exhausts working memory capacity and generates high intrinsic load. Low element-interactivity material (e.g., learning isolated vocabulary, recalling independent facts) can be processed element by element without simultaneous multi-element consideration.
>
> **Boundary:** Element interactivity in a learning task is relative to the learner's current schema acquisition. A beginner reading a chess position must process many independent elements; a grandmaster processes the same position as a small number of familiar patterns (schemas). Apparent interactivity decreases as expertise grows.
>
> **Report-Specific Significance:** Element interactivity analysis is the principled basis for the atomicity recommendation in PKM note design.
>
> **See also:** [[element-interactivity]], [[intrinsic-cognitive-load]], [[chunking]]

> [!evidence] Element Interactivity (Sweller & Chandler, 1994)
> The degree to which elements of a learning task must be processed simultaneously in [[working-memory|working memory]] because they are logically interdependent. Element interactivity determines [[intrinsic-cognitive-load|intrinsic cognitive load]]: high interactivity means elements cannot be understood in isolation and must be integrated, imposing heavy demand on limited working memory capacity.
>
> **Boundary:** Element interactivity is relative to expertise. Elements that are "interacting" for a novice become a single integrated chunk for an expert, reducing the effective interactivity of the task. Thus, the same material has different element interactivity for different learners.
>
> **Report-Specific Significance:** Element interactivity is the theoretical linchpin that connects cognitive architecture to instructional effects. It is CLT's primary theoretical construct for predicting when and why instruction succeeds or fails.
>
