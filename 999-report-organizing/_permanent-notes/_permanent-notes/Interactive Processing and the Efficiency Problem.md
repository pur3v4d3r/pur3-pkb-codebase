## Core Explanation

> [!evidence] Interactive Processing and the Efficiency Problem
> The computational advantage of interactive (top-down + bottom-up simultaneous) processing over purely sequential processing is dramatic. A purely bottom-up reader would process each letter, then each word, then each phrase, then each sentence before integrating them into a situational representation — a computational sequence far too slow for natural reading speeds. A purely top-down reader would hallucinate text, projecting schema expectations onto ambiguous input without sufficient data-checking. Interactive processing solves both problems: bottom-up data continuously updates and corrects top-down predictions, while top-down predictions reduce the computation needed to interpret ambiguous bottom-up signals.
> *— [[schema-theory-foundational-report-2026-04-03_report]]*
