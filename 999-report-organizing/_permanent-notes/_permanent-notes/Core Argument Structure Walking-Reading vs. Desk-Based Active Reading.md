> [!diagram] Core Argument Structure: Walking-Reading vs. Desk-Based Active Reading
> ```
> QUESTION: Should you walk while reading dense academic reports?
>
> ┌─────────────────────────────────────────────────────┐
> │  EVIDENCE STREAM 1: DUAL-TASK COSTS                 │
> │  Walking imposes modest but real cognitive cost      │
> │  (~10-25% for complex material)                     │
> │  [Pashler 1994, Wickens 2008, Al-Yahya 2011]       │
> └──────────────────────┬──────────────────────────────┘
>                        │
> ┌──────────────────────▼──────────────────────────────┐
> │  EVIDENCE STREAM 2: AUTOMATICITY LIMITS             │
> │  Walking is partially, not fully, automatic          │
> │  Gaze stabilization + turning = residual cost        │
> │  [Woollacott 2002, Yogev-Seligmann 2008]            │
> └──────────────────────┬──────────────────────────────┘
>                        │
> ┌──────────────────────▼──────────────────────────────┐
> │  EVIDENCE STREAM 3: EMBODIED COGNITION              │
> │  Walking enhances creativity BUT NOT                 │
> │  convergent analytical comprehension                 │
> │  [Oppezzo & Schwartz 2014]                          │
> └──────────────────────┬──────────────────────────────┘
>                        │
> ┌──────────────────────▼──────────────────────────────┐
> │  EVIDENCE STREAM 4: EXERCISE TIMING                 │
> │  Post-exercise > during-exercise for complex tasks   │
> │  [Lambourne & Tomporowski 2010, Chang 2012]         │
> └──────────────────────┬──────────────────────────────┘
>                        │
>                        ▼
>     ┌─────────────────────────────────────────┐
>     │  CONVERGENT CONCLUSION                   │
>     │  Walking-reading has a modest net cost   │
>     │  for complex analytical material         │
>     └───────────────────┬─────────────────────┘
>                         │
>                         │   HOWEVER, this is NOT
>                         │   the decisive factor...
>                         │
> ┌───────────────────────▼─────────────────────────────┐
> │  THE DECISIVE FACTOR: OPPORTUNITY COST              │
> │  Active PKB engagement invokes the Generation       │
> │  Effect (d = 0.40-0.87) — incompatible with walking │
> │  [Slamecka 1978, Bjork 1994, Dunlosky 2013]        │
> └───────────────────────┬─────────────────────────────┘
>                         │
>                         ▼
>     ┌─────────────────────────────────────────┐
>     │  RECOMMENDATION                          │
>     │  Temporal separation:                    │
>     │  Walk → Read at desk with PKB → Walk    │
>     │  (arousal)  (comprehension)  (consolidation) │
>     └─────────────────────────────────────────┘
> ```
> *— [[walking-and-academic-reading-foundational-report-2026-04-13_report]]*
