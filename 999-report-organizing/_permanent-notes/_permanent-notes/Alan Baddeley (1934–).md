## Additional Material

> [!person] Alan Baddeley (1934–)
> Emeritus Professor, University of York, UK. Developed the multi-component model of working memory (1974, with Graham Hitch), which underwent major elaborations in 2000 (adding the episodic buffer). Baddeley's model is the working memory architecture that CLT implicitly adopts, providing the empirical basis for the phonological loop, visuospatial sketchpad, and central executive distinctions that inform multimodal instructional design.
> *— [[cognitive-load-theory-and-pkm-foundational-report-2026-04-12_report]]*

> [!person] Alan Baddeley (1934–)
> Professor of Psychology, University of York, UK. Developer of the multi-component model of [[working-memory]] that provides CLT's architectural foundation. Baddeley's model — phonological loop, visuospatial sketchpad, central executive, episodic buffer — established the capacity constraints that CLT's prescriptions are designed to manage.
>
> **Core contributions:** Working memory model, capacity limitations, dual-channel architecture.
>
> **Relationship:** Foundational influence; CLT presupposes Baddeley's architectural claims while not committing to all specific model components.
> *— [[cognitive-load-theory-foundational-report-2026-04-18]]*

> [!person] Alan Baddeley (1934–)
> British cognitive psychologist who, with Graham Hitch, proposed the multicomponent working memory model (1974) that replaced the Atkinson-Shiffrin short-term memory store. Baddeley's subsequent four decades of work elaborated each component of the model, added the episodic buffer (2000), and integrated the model with neuropsychological evidence. His contributions defined the research program of working memory for five decades. Related figure: [[graham-hitch]], [[Nelson-Cowan]] (alternative models).
> *— [[memory-systems-working-memory-and-long-term-memory-foundational-report-2026-04-07_report]]*

> [!person] Alan Baddeley (1934–)
> British cognitive psychologist; architect of the working memory model (with Graham Hitch, 1974). Replaced the unitary short-term memory concept with a multicomponent working memory system. Key additions: the episodic buffer (2000). Key works: *Working Memory* (1986), *Your Memory: A User's Guide* (1982), "The Concept of Working Memory" (Baddeley & Hitch, 1974). Relationship to Miller: extended and refined Miller's capacity framework; relationship to Sweller: provided the architectural basis for CLT.

> *University of York, UK*
> Architect of the multicomponent [[Baddeley's-Working-Memory-Model|working memory model]] (1974, 2000) that provides the cognitive architecture framework for this report. His model of the central executive, phonological loop, visuospatial sketchpad, and episodic buffer defines the resource pools that walking and reading compete for.

> **Relationship to others:** Built on Atkinson-Shiffrin's modal model; influenced Sweller's CLT; disagreements with Cowan regarding unitarity of WM.

> [!person] Alan Baddeley (1934–)
> Professor of Psychology, University of York. Co-originator (with Graham Hitch) of the multicomponent model of working memory (1974); proposed the episodic buffer (2000). His programme of research has defined the dominant framework in working memory research for five decades. Key works: *Working Memory* (1986); *Working Memory, Thought, and Action* (2007).
>
> **Relationship to other figures:** Built upon and superseded the Atkinson-Shiffrin model. Influenced Sweller's cognitive load theory. Provided the architectural framework that Miyake and Friedman later fractionated.
> *— [[working-memory-foundational-report-2026-04-16_report]]*
