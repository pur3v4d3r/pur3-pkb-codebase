# Element Interactivity

> [!definition] Element Interactivity
> **Element Interactivity**: The degree to which elements of a learning task must be simultaneously held in working memory and processed together because of their mutual dependencies. High element interactivity (e.g., understanding a complex causal system) places higher intrinsic cognitive load demands than low element interactivity (e.g., isolated declarative facts). Element interactivity is reduced by expertise, because long-term schemas chunk multiple formerly separate elements into single higher-order units. See: [[cognitive-load-theory]], [[schema-theory]].

> [!evidence] Element Interactivity
> The number of interrelated information elements that must be processed simultaneously in working memory to comprehend material or perform a task; the proximate determinant of intrinsic cognitive load; *learner-relative* — the same material has different element interactivity for learners with different schemas. Distinct from "complexity" generally because it specifies the load source as *relational* rather than as *quantity of items in isolation*.
> *— [[cognitive-load-theory-element-interactivity-deep-dive-2026-04-20]]*

> [!evidence] Element Interactivity
> A property of instructional material describing the degree to which its component elements must be processed simultaneously rather than sequentially for understanding to occur. High element interactivity material (e.g., understanding how grammar rules interact to produce a complex sentence; understanding how enzyme kinetics depends on simultaneous knowledge of substrate concentration, inhibitor presence, and pH) imposes high intrinsic cognitive load because the elements cannot be meaningfully separated. Low element interactivity material (e.g., memorizing vocabulary definitions, learning a list of historical dates) can be processed element-by-element without losing meaning. Element interactivity is the mechanism that links content complexity to intrinsic cognitive load.
> *— [[cognitive-load-theory-focused-analysis-2026-03-06_report]]*

> [!evidence] Element Interactivity

Effective element interactivity — the element interactivity experienced by a given learner — decreases with expertise as more elements are automated as schemas.

> [!evidence] Element Interactivity
> [[element-interactivity]] refers to the degree to which individual information elements within a learning task must be processed simultaneously — rather than successively — because they are logically interdependent. High element interactivity means that understanding any one element requires simultaneous consideration of many others; low element interactivity means that elements can be understood independently.
>
> **Boundary:** Element interactivity is not defined by the *number* of elements alone but by the *pattern of dependencies* among them. A task with many independent elements (e.g., memorizing a list of unrelated vocabulary words) may have low element interactivity despite its large element count, while a task with few elements that are all interdependent (e.g., understanding a three-variable algebraic equation) may have high element interactivity.
>
> **Report-Specific Significance:** Element interactivity is CLT's candidate for a *unified explanatory mechanism*. It determines intrinsic load, predicts when CLT effects will and will not appear, and explains the [[expertise-reversal-effect]] as a function of changing element interactivity through schema acquisition.
>
> **See also:** [[cognitive-task-analysis]], [[schema-construction]], [[worked-example-effect]], [[expertise-reversal-effect]]

> [!evidence] Element Interactivity
> The degree to which the elements comprising a learning task must be processed simultaneously rather than sequentially in working memory. High element interactivity characterises material in which understanding any single element depends on its relationship to multiple other elements, creating an intrinsic cognitive load that cannot be reduced without simplifying the learning objective itself.
>
> **Boundary:** Element interactivity is a property of the material relative to the learner's expertise, not an absolute property of the material alone. As schemas develop, previously interacting elements are integrated into single chunks, reducing effective element interactivity.
>
> **Report-Specific Significance:** Element interactivity is the mechanism by which working memory constraints translate into learning difficulty — it specifies precisely why some material overwhelms working memory while other material does not.
>
