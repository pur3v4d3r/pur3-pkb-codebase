## Core Explanation

> [!evidence] [[Cognitive-Load-Theory-and-Academic-Text-Design]]
> **Description:** If academic reading comprehension is constrained by working memory capacity and processing efficiency, then academic text *design* — how authors structure, signpost, and format texts — directly shapes the reading comprehension demands placed on readers. Applying Sweller's Cognitive Load Theory to academic text design would yield evidence-based principles for authors, editors, and instructors who produce academic materials for readers at different expertise levels.
>
> **Connection to this report:** The working memory load-sharing account from Section 2 (Verbal Efficiency Theory) and the CI model's implicit working memory demands create a direct logical connection to text design principles.
>
> **Priority:** Exploratory
