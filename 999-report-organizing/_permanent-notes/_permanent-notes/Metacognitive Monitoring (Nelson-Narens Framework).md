# Metacognitive Monitoring (Nelson-Narens Framework)

> [!definition] Metacognitive Monitoring (Nelson-Narens Framework)
> Metacognitive monitoring refers to the meta-level's acquisition of information about the object level's current state. Operationally, monitoring is measured through prospective and retrospective judgments: **Ease of Learning (EOL)** judgments (pre-study predictions of learning difficulty), **Judgments of Learning (JOL)** (during or post-study predictions of future recall), **Feelings of Knowing (FOK)** (judgments of whether unrecalled information exists in memory and could be recognized), and **Retrospective Confidence Judgments** (post-response accuracy assessments). The accuracy of these judgments — their calibration — is a primary measure of metacognitive monitoring skill and a key determinant of whether monitoring can effectively guide control.
>
> **Boundary:** Metacognitive monitoring is NOT the same as attention; attention is a first-order cognitive resource-allocation mechanism, while metacognitive monitoring is a second-order process that tracks first-order processing.
>
