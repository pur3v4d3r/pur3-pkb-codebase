# Element-in-CLT

> [!definition] Element-in-CLT
> An element is anything that has been or needs to be learned — any unit of information that must be processed in working memory. For a novice, elements are typically the smallest meaningful components of the learning material. For an expert, a schema that encapsulates multiple lower-level elements functions as a single element.
