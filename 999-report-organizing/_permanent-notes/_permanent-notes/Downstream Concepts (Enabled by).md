## Cross-Domain Connections

> [!cross-domain-connection] Downstream Concepts (Enabled by)
> These concepts are enabled, grounded, or substantially informed by the working memory framework:
> - [[cognitive-load-theory]] — Directly derived from Baddeley's model; working memory architecture is CLT's explicit computational foundation
> - [[cognitive-theory-of-multimedia-learning]] — Mayer's CTML draws on Baddeley's dual-channel, limited-capacity architecture for all twelve of its design principles
> - [[metacognition]] — Effective metacognitive monitoring requires accurate awareness of one's own working memory load; working memory capacity partly constrains metacognitive processing
> - [[self-regulated-learning]] — The forethought, performance, and self-reflection phases of SRL all draw on central executive resources; working memory architecture is the cognitive substrate of self-regulation
> - [[deliberate-practice]] — Ericsson's model of expertise development via deliberate practice interfaces directly with working memory through the long-term working memory mechanism
> - [[schema-theory]] — Schemas are the long-term structure that reduces working memory demands; schema formation is the output of working memory's germane processing
> - [[instructional-design]] — Evidence-based instructional design (spaced practice, worked examples, integrated formats) is motivated by working memory architecture and cognitive load theory
> *— [[baddeley-model-of-working-memory-foundational-report-2026-04-03_report]]*
