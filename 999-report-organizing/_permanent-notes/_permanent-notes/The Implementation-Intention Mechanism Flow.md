> [!diagram] The Implementation-Intention Mechanism Flow
> ```
>                       ┌────────────────────────┐
>                       │    GOAL INTENTION       │
>                       │  "I want to achieve Z"  │
>                       └────────────┬───────────┘
>                                    │
>                                    ▼
>           ┌────────────────────────────────────────────┐
>           │   PRE-DECISIONAL DELIBERATION (Phase 1)    │
>           │   Weighing alternative goals; commitment   │
>           └────────────────────────┬───────────────────┘
>                                    │
>                              [Crossing Rubicon]
>                                    │
>                                    ▼
>           ┌────────────────────────────────────────────┐
>           │   PRE-ACTIONAL PLANNING (Phase 2)           │
>           │   FORM IMPLEMENTATION INTENTION:           │
>           │   "When situation X arises,                │
>           │    I will perform behavior Y"              │
>           └────────────────────────┬───────────────────┘
>                                    │
>                       [Cognitive Pre-Compilation]
>                                    │
>                                    ▼
>           ┌────────────────────────────────────────────┐
>           │   ACTIONAL ENACTMENT (Phase 3)              │
>           │                                            │
>           │   Cue X arrives → Perceptual System        │
>           │              detects (heightened           │
>           │              accessibility)                │
>           │                                            │
>           │   Detection → Behavior Y initiated         │
>           │              (immediate, efficient,        │
>           │              interference-shielded)        │
>           └────────────────────────┬───────────────────┘
>                                    │
>                                    ▼
>           ┌────────────────────────────────────────────┐
>           │   POST-ACTIONAL EVALUATION (Phase 4)        │
>           │   Outcome assessment; plan renewal,         │
>           │   revision, or revocation                   │
>           └────────────────────────────────────────────┘
> ```
>
> **Reading the diagram:** The mechanism's distinctive contribution is concentrated in the transition from Phase 2 to Phase 3 — the cognitive pre-compilation step that transforms a deliberative plan into a cue-triggered subroutine. Failures upstream of this step (weak goal commitment, poor cue specification) and downstream of it (cue non-arrival, environmental interference, goal re-deliberation) all degrade the eventual behavioral outcome.
> *— [[implementation-intentions-gollwitzer-foundational-report-2026-04-20]]*
