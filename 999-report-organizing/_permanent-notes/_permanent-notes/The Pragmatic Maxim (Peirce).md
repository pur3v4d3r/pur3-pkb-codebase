# The Pragmatic Maxim (Peirce)

> [!definition] The Pragmatic Maxim (Peirce)
> The [[Pragmatic-Maxim|pragmatic maxim]] states that the entire meaning of any concept lies in its conceivable practical effects. To clarify an idea, ask: what difference would it make *in practice* if this idea were true versus false? If there is no practical difference, the dispute is merely verbal. For learning, this principle implies that abstract knowledge must always be connected to possible applications — understanding is tested and developed through consequential action.
