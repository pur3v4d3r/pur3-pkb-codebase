> [!flashcard] Seed 7 — Application
> **Q:** How should elaborative interrogation be integrated into PKB note-building practice, and what is the key design criterion for EI-style note prompts?
>
> **A:** In PKB practice, EI should be applied by: (1) formulating Register 2 "why" questions as you read — ones whose answers require constructing causal connections, not locating sentences; (2) generating answers before consulting other sources; (3) writing notes at the situation model level ("X causes Y because [mechanism]") rather than the textbase level ("X causes Y"); (4) tagging unanswerable questions as prior knowledge gaps requiring background reading. The key design criterion for note prompts is the Dual Register Diagnostic: a prompt should be answerable only by constructing a causal-functional account, not by paraphrasing the source.
>

> [!flashcard] Seed 7 — Application
> **Q:** What are the four strategies in reciprocal teaching and what metacognitive function does each perform?
> **A:** (1) Predicting — activates prior knowledge, establishes comprehension goals; (2) Questioning — enforces self-monitoring via explicit comprehension question generation; (3) Clarifying — comprehension monitoring and fix-up strategy deployment for detected failures; (4) Summarizing — coherence evaluation at the discourse level, tests situation model construction.
> **Source:** Phase V, Section 5.1

> [!flashcard] Seed 7 — Application
> **Q:** How does metacognitive knowledge contribute differently to each phase of Zimmerman's cyclical SRL model?
> **A:** Forethought Phase: Person + Task + Strategy knowledge supports accurate task analysis, goal-setting, and strategic planning. Performance Phase: Procedural + conditional strategy knowledge supports monitoring standards and control responses. Self-Reflection Phase: Declarative + conditional knowledge supports accurate causal attribution and strategy evaluation, enabling productive updating of metacognitive knowledge from experience.
