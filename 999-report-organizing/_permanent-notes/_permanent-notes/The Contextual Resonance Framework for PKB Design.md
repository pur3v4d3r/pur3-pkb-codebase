## Core Explanation

> [!analytical-insight] The Contextual Resonance Framework for PKB Design
> Drawing on the ESP and the synergistic ecphory model, a framework for PKB design emerges that can be called the Contextual Resonance Framework. Its central claim is: notes should be encoded not only to represent content accurately but to maximize the probability of resonance with anticipated future retrieval contexts. This implies that note titles and opening lines should use the vocabulary that will be operationally active when the note is needed (retrieval-anticipatory indexing); that notes should contain both the theoretical concept and its practical applications (multi-context encoding); and that flashcard/review formats should simulate the problem contexts in which knowledge will be applied (retrieval practice in retrieval format). A PKB designed solely around conceptual links is LOP-optimized but ESP-underoptimized; it provides a rich trace but not necessarily the right access paths.
> *— [[encoding-specificity-principle-tulving-foundational-report-2026-04-07_report]]*
