## Additional Material

> [!diagram] Argument Map 1: Why the Multi-Store Model Was Replaced
> ```
> Multi-Store Model (Atkinson-Shiffrin, 1968)
> │   Claim: STM is necessary gateway to LTM; rehearsal transfers items
> │
> ├── CHALLENGED BY: Neuropsychological patients with intact LTM learning
> │   despite impaired STM (e.g., KF patient with verbal STM deficit
> │   but normal long-term learning)
> │   → STM is NOT required for LTM formation
> │
> ├── CHALLENGED BY: Dual-task experiments (Baddeley & Hitch, 1974)
> │   → Concurrent span task degrades WM use but not reasoning completely
> │   → STM is NOT unitary: verbal and spatial subsystems separable
> │
> ├── CHALLENGED BY: Maintenance rehearsal experiments
> │   → Rehearsing items for long time at shallow level ≠ long-term retention
> │   → Time in STM does NOT determine LTM consolidation
> │
> └── REPLACED BY: Working Memory Model (Baddeley-Hitch, 1974)
>     │   Multiple subsystems: PL + VSS + CE + EB
>     │   Active processing, not passive storage
>     └── + Levels of Processing (Craik & Lockhart, 1972)
>             Encoding depth, not rehearsal time, determines retention
> ```
> *— [[memory-systems-working-memory-and-long-term-memory-foundational-report-2026-04-07_report]]*
