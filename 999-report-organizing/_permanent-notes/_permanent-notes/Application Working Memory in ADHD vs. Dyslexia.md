## Flashcards

> [!flashcard] Application: Working Memory in ADHD vs. Dyslexia
> **Q:** How do the working memory profiles in ADHD and dyslexia differ, and what does this selectivity reveal about working memory architecture?
> **A:** ADHD: selective impairment in central executive functions (controlled attention, updating, inhibition, task-switching) with relatively preserved simple phonological span. Dyslexia: selective impairment in phonological loop capacity (reduced digit span, impaired non-word repetition, low phonological awareness) with relatively preserved visuospatial and executive functions. The selectivity demonstrates the independence of working memory components: ADHD implicates prefrontal executive systems; dyslexia implicates left inferior parietal/Broca's area phonological systems. Each disorder validates the model's architectural distinctions.
> *— [[baddeley-model-of-working-memory-foundational-report-2026-04-03_report]]*
