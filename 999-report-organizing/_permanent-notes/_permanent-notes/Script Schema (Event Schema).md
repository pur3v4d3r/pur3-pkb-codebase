# Script Schema (Event Schema)

> [!definition] Script Schema (Event Schema)
> A **script** (Schank & Abelson, 1977) is a specialized event schema that encodes knowledge about the typical sequence of actions, actors, props, and outcomes in a stereotyped situation. Classic examples include the *restaurant script*, the *doctor's office script*, and the *grocery shopping script*. Scripts are particularly important for understanding narrative text and social situations because they supply the implicit causal connective tissue that texts omit.
