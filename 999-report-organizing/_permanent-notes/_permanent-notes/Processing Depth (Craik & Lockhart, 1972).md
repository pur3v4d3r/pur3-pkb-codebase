# Processing Depth (Craik & Lockhart, 1972)

> [!definition] Processing Depth (Craik & Lockhart, 1972)
> The degree of cognitive analysis applied to an incoming stimulus, ranging from shallow (physical or structural feature analysis) through intermediate (phonological or phonemic analysis) to deep (semantic and meaningful analysis). Processing depth is the primary determinant of memory trace durability within the levels of processing framework: deeper processing produces stronger, more durable memory traces; shallower processing produces weaker, faster-decaying traces.
>
> **Boundary:** Processing depth is a theoretical construct, not a directly observable quantity. It is operationalized through experimental paradigms (e.g., orienting tasks) rather than measured directly. The framework assumes depth is a roughly continuous dimension, but acknowledges that the boundaries between levels are not sharply defined. The concept does not apply straightforwardly to all memory tasks — procedural learning, priming, and some forms of implicit memory may operate on different principles.
>
> **Report-Specific Significance:** This is the central theoretical construct of the entire framework — the variable that explains memory durability. Understanding what depth means, how it is operationalized, and what challenges the construct faces is essential to evaluating the theory's scientific standing.
>
> **See also:** [[levels-of-processing-theory]], [[deep-processing]], [[shallow-processing]], [[processing-depth]], [[orienting-task-paradigm]]

> [!evidence] Processing Depth (Craik & Lockhart, 1972)
> The level of cognitive elaboration applied to an encoded item, ranging from shallow phonological-orthographic processing to deep semantic-elaborative processing. A core prediction of [[levels-of-processing-theory]] is that encoding durability is a continuous, monotone function of processing depth: deeper processing produces more durable, accessible memory traces.
>
> **Boundary:** "Depth" in the levels-of-processing framework refers to semantic elaboration, not temporal duration of processing. Spending more time at a shallow level does not produce deep encoding.
