# Generative Cognition Architecture (GCA)

> [!definition] Generative Cognition Architecture (GCA)
> A structural configuration of four cognitive conditions — freed output channels, self-paced recursive engagement, private hypothesis space, and active metacognitive monitoring — that together make evaluative, analytical cognition cognitively affordable. Proposed in this analysis as the unifying framework for understanding why silent reading (and analogous practices) produces critical analysis under some conditions but not others.
