## Core Explanation

> [!evidence] Expert Debate: Is CLT's Cognitive Architecture Compatible with Embodied Cognition?
> **Position A (CLT Traditionalists — Sweller, Kalyuga):** CLT's cognitive architecture is specifically about *biological* information processing. The evolutionary principles describe how *brains* handle information, and working memory limitations are *neural* limitations. Environmental offloading is real but works by reducing the load on Working Memory (the biological system), not by extending it.
>
> **Position B (Extended Cognition Advocates — Clark, Kirsh):** Working memory limitations are not fixed biological constants but emergent properties of the cognitive *system* — which includes body and environment. Element interactivity should be reconceptualized as system-level interactivity, and CLT's predictions should apply to the extended cognitive system, not just the brain.
>
> **What the debate hinges on:** Whether working memory capacity is a *structural limit of biological neural processing* or an *emergent property of the cognitive system that includes the environment*. This is ultimately an empirical question, but current methods cannot distinguish the two accounts.
>
> **Current state:** Stable disagreement. CLT researchers largely ignore the embodied cognition literature, and embodied cognition researchers largely ignore CLT. Integration has been minimal.
>
> **Why the debate matters:** If Position B is correct, CLT's element interactivity mechanism needs significant extension. If Position A is correct, elements must always be defined in terms of what enters biological working memory, regardless of how the environment is configured.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
