# Cognitive Load Theory (Sweller, 1988)

> [!definition] Cognitive Load Theory (Sweller, 1988)
> An instructional design theory asserting that human learning is constrained by the limited capacity of [[working-memory|working memory]], and that effective instruction must manage the cognitive load imposed on working memory during learning. The theory distinguishes three types of load — intrinsic, extraneous, and germane — which are theorized to be additive within working memory's fixed capacity. The theory has generated numerous specific instructional prescriptions (worked example effect, split-attention effect, redundancy effect, guidance fading principle) with varying degrees of empirical support. CLT is distinct from other learning theories in that it directly grounds instructional prescriptions in a specific cognitive architecture rather than in behavioral outcomes alone.

CLT predicts that instructional effectiveness depends on managing the processing demands imposed on working memory during learning.
>
> **Boundary:** CLT addresses *cognitive* processing demands; it does not model motivational, affective, or social dimensions of learning. Its prescriptions apply most directly to initial instruction rather than to consolidation or transfer.

> [!evidence] Cognitive Load Theory (Sweller, 1988)
> An instructional design theory grounded in working memory architecture that distinguishes three types of cognitive load: intrinsic (inherent complexity of the material), extraneous (load imposed by poor instructional design that adds no learning value), and germane (load that contributes directly to schema formation and long-term memory consolidation). The central design prescription is to minimise extraneous load so that working memory resources can be directed toward germane processing.
>
> **Boundary:** The three-load model has been criticised for not being independently measurable and for potential overlap between extraneous and germane load. The core insight — that not all cognitive effort is equally valuable — remains robust even if the tripartite categorisation is imprecise.

> [!evidence] Cognitive Load Theory (Sweller, 1988)
> [[cognitive-load-theory]] proposes that all meaningful learning involves the construction and automation of schemas in [[long-term-memory]], and that the primary instructional design challenge is managing the cognitive load placed on [[working-memory]] during schema construction. Three load types are relevant: intrinsic (deriving from material complexity), extraneous (deriving from poor instructional design), and germane (deriving from schema-constructive processing). Because working memory is severely limited, effective learning environments maximize germane load while minimizing extraneous load within the bounds set by intrinsic complexity.
>
> **Boundary:** CLT was developed primarily as a theory of instructional design and has been critiqued for circularity in its early formulations (germane load was defined as "load that produces learning," which is difficult to operationalize independently of its effects). More recent work addresses this through direct measurement of working memory load and schema measures.
>
