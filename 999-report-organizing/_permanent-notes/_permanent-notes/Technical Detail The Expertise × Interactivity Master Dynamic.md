# Technical Detail: The Expertise × Interactivity Master Dynamic

## Core Explanation

> [!evidence] Technical Detail: The Expertise × Interactivity Master Dynamic
> **The dynamic:** An instructional intervention's effect on learning depends on the *relationship between* the effective element interactivity of the material (for the target learner) and the element interactivity change produced by the intervention.
>
> **When effective element interactivity is HIGH (novices):**
> Interventions that *reduce* effective element interactivity → beneficial (Learning ↑)
> Interventions that *increase* effective element interactivity → detrimental (Learning ↓)
>
> **When effective element interactivity is LOW (experts):**
> Interventions that *add* elements to an already manageable load → detrimental (extraneous interactivity)
> Interventions that *remove* scaffolding → beneficial (allows expert schemas to operate without interference)
>
> **The crossing point:** There exists a point in the learner's expertise development where the intervention switches from beneficial to detrimental (or vice versa). This crossing point is not a fixed location — it depends on the specific element interactivity structure of the material and the intervention. This is the [[expertise-reversal-effect]] expressed as a general dynamic rather than a single named effect.
>
> **Formal expression:** If we denote the effective element interactivity of the material for a learner as $EI_{eff}$, and working memory capacity as $WM_{cap}$, then:
> - When $EI_{eff} > WM_{cap}$: any reduction in $EI_{eff}$ relative to unassisted processing → beneficial
> - When $EI_{eff} < WM_{cap}$: additions that push total load above baseline → detrimental (wasted or interfering)
> - When $EI_{eff} \approx WM_{cap}$: the intervention's effect depends on precise calibration
>
> **Precision:** This is a qualitative model, not a quantitative formula. $EI_{eff}$ and $WM_{cap}$ cannot currently be measured with sufficient precision for numerical prediction.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
