> [!diagram] Core Argument: Why Metacognitive Knowledge Matters for Learning
> ```
> METACOGNITIVE KNOWLEDGE
> (Person-Task-Strategy; Declarative-Procedural-Conditional)
>         │
>         ├──► Accurate Task Analysis (Forethought Phase)
>         │         └──► Appropriate Strategy Selection ──► Learning Efficiency
>         │
>         ├──► Calibrated Monitoring Standards (Performance Phase)
>         │         └──► Responsive Control Commands ──► Error Correction
>         │
>         └──► Productive Self-Evaluation (Self-Reflection Phase)
>                   └──► Refined Future Planning ──► Learning Trajectory
>
> BUT: Knowledge-Activation Gap operates at each arrow
>       ↓
>       Declarative knowledge WITHOUT:
>       • Adequate proceduralization
>       • Context-sensitive indexing
>       • Monitoring-knowledge coupling
>       ↓
>       = Knowledge present but not activated
>       = Pseudometacognition
>       = No regulatory improvement
>
> SOLUTION ARCHITECTURE:
>   Explicit Instruction (declarative foundation)
>           +
>   Feedback-Rich Practice (calibration + indexing)
>           +
>   Domain-Embedded Conditional Knowledge (specificity)
>           =
>   Genuinely Functional Metacognitive Knowledge
> ```
> *— [[metacognitive-knowledge-foundational-report-2026-03-31_report]]*
