# Implementation Intention (Gollwitzer, 1993, 1999)

> [!definition] Implementation Intention (Gollwitzer, 1993, 1999)
> A subordinate planning structure that specifies a behavioral commitment in the if-then form *"When situation X occurs, I will perform behavior Y,"* thereby pre-linking a specific anticipated cue to a specific intended response. Implementation intentions are conceptually distinct from goal intentions (which specify desired outcomes) and operate by transferring control of the planned behavior from deliberative goal pursuit to a strategically engineered, cue-triggered initiation routine.
>
> **Boundary:** An implementation intention is not a habit, not a mere reminder, and not a substitute for goal commitment; it requires the underlying goal to remain endorsed and the specified cue to be perceptually discriminable.
>
