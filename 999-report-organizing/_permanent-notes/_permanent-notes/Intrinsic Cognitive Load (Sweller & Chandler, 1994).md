# Intrinsic Cognitive Load (Sweller & Chandler, 1994)

> [!definition] Intrinsic Cognitive Load (Sweller & Chandler, 1994)
> The component of cognitive load generated by the inherent complexity of the material being learned, specifically by the number of elements that must be simultaneously held in working memory and considered in relation to each other (element interactivity). Intrinsic load cannot be arbitrarily reduced without also reducing the complexity the learner must ultimately master; it can be managed through sequencing (introducing simpler elements before complex configurations) and chunking (reducing element count by forming higher-order schemas).
>
> **Boundary:** Does not include load generated by irrelevant features of the instructional design (extraneous) or by schema-building processes applied to the material (germane/reallocation).
>
> **Report-Specific Significance:** Understanding intrinsic load explains why atomicity in note design reduces cognitive overhead without reducing content value.
>
> **See also:** [[element-interactivity]], [[chunking]], [[schema-theory]]

> [!evidence] Intrinsic Cognitive Load (Sweller & Chandler, 1994)
> The cognitive load arising from the inherent complexity of the material being processed, specifically from element interactivity — the degree to which understanding requires simultaneously processing multiple interdependent elements. Intrinsic load cannot be reduced by design without changing the material itself; it can only be managed through sequencing, scaffolding, and schema development.
>
> **Boundary:** Intrinsic load is relative to the learner's schema state, not fixed by the material. The same complex topic generates high intrinsic load for a novice and low intrinsic load for an expert whose schemas have chunked the relevant patterns.
>
