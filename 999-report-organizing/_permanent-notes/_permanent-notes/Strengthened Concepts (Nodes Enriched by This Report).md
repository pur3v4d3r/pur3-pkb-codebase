## Cross-Domain Connections

> [!cross-domain-connection] Strengthened Concepts (Nodes Enriched by This Report)
> Prior understanding of these concepts is substantially strengthened by the working memory model's specification of underlying mechanisms:
> - [[metacognitive-self-regulation]] — Understanding that self-monitoring and strategy adjustment draw on the same limited central executive resources that manage the cognitive task itself reframes self-regulation as a cognitive load management problem
> - [[spaced-repetition]] — The worked memory model's account of why distributed practice reduces cognitive load (repetition builds schema automaticity, reducing future intrinsic load demands) provides a mechanistic grounding for spaced repetition's effectiveness
> - [[chunking]] — Working memory's limited capacity makes chunking not just a mnemonic trick but a fundamental ability — arguably the primary mechanism by which expertise expands effective cognitive capacity within working memory's limits
> - [[transfer-of-learning]] — Far transfer failures (including WM training) become more interpretable through the working memory lens: executive capacity is real and limited, but so is the specificity of its operation in particular task domains
> *— [[baddeley-model-of-working-memory-foundational-report-2026-04-03_report]]*
