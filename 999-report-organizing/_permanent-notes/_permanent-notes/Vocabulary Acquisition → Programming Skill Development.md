## Cross-Domain Connections

> [!cross-domain-connection] Vocabulary Acquisition → Programming Skill Development
> The threshold-dependency principle appears clearly in programming education. Beginning programmers who are exposed to large codebases before acquiring basic syntax, data structure, and algorithmic knowledge are below the comprehension threshold that would make reading production code educational — the density of unknown patterns prevents the contextual inference that would enable incidental acquisition of programming idioms. Above threshold (once basic patterns are automatic), reading production code is an extraordinarily efficient way to acquire idiomatic style, architectural pattern recognition, and library familiarity. The Matthew Effect operates here too: programmers with large technical vocabulary read code easily, which builds more technical vocabulary; those below threshold find code reading effortful and acquire little from it without deliberate supplementation.
> *— [[vocabulary-building-reading-dialectical-re-examination-2026-03-28_report]]*
