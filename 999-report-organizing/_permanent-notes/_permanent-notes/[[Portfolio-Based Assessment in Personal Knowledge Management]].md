> [!evidence] [[Portfolio-Based Assessment in Personal Knowledge Management]]
> **Description:** This report identifies formative assessment as the appropriate paradigm for PKM evaluation but does not develop the *structural form* that assessment takes over time. Portfolio assessment — curated collections of work demonstrating growth, depth, and integration — represents a natural extension. How can an Obsidian vault itself function as an evolving learning portfolio? What criteria distinguish a portfolio that demonstrates genuine understanding from one that merely documents activity? How do Dataview queries, graph metrics, and progressive summarisation interact with portfolio evaluation?
> **Connection to this report:** Section 7's three-layer assessment architecture requires a longitudinal container; portfolio assessment provides it.
