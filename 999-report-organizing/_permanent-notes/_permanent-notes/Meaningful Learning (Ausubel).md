# Meaningful Learning (Ausubel)

> [!definition] Meaningful Learning (Ausubel)
> A mode of learning in which new information is intentionally related to existing knowledge structures in the learner's cognitive field, producing genuine integration between new and existing concepts. Meaningful learning contrasts with *rote learning*, in which material is memorized in isolation without connection to existing knowledge — producing fragile, non-transferable, rapidly decaying retention. Ausubel argued that almost all formal instruction produces rote learning by default because it fails to establish the cognitive conditions required for assimilation: relevant anchoring ideas must be explicitly available and must be explicitly activated before new material is introduced.

> [!evidence] Meaningful Learning (Ausubel)
> Ausubel's term for learning in which new material is genuinely related to existing cognitive structure — understood rather than rote-memorized. Meaningful learning is distinguished from rote learning not by the method of instruction (Ausubel explicitly rejected the equation of meaningful learning with discovery) but by whether the learner has relevant prior cognitive structure and whether the new material is presented in a way that can be connected to it. Advance organizers — expository passages that establish the relevant prior organization — are Ausubel's primary instructional tool for facilitating meaningful learning.
