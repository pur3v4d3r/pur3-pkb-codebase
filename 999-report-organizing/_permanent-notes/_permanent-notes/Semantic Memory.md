# Semantic Memory

> [!definition] Semantic Memory
> The subsystem of declarative memory responsible for general knowledge about the world — facts, concepts, word meanings, encyclopaedic knowledge — divorced from the specific episodes in which they were acquired. When you know that Paris is the capital of France, you typically do not remember the specific occasion on which you learned this; the episodic context has been lost while the semantic content persists. Semantic memory is relatively resistant to the organic amnesias that devastate episodic memory, suggesting some neurological independence between the two systems.
