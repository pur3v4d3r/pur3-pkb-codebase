## Examples

> [!example] Derivation Example: The Redundancy Effect as Inverse Split-Attention
> The [[redundancy-effect]] is often presented as a separate principle, but element interactivity analysis reveals it as the *mirror image* of the split-attention effect, governed by the same dynamic:
>
> **When two sources are mutually referential (high cross-source interactivity):** They MUST be integrated → split-attention effect applies → physically integrate them.
>
> **When two sources are NOT mutually referential (one is self-sufficient):** The second source adds *extraneous element interactivity* — the learner must process the redundant source AND its (unnecessary) relationship to the self-sufficient source. Removing the redundant source reduces element interactivity.
>
> **The decision rule:** The same underlying mechanism (cross-source element interactivity) determines whether to integrate (split-attention) or eliminate (redundancy). The diagnosis depends entirely on whether the sources create necessary or unnecessary interactivity.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
