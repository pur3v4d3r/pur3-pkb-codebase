# Working Memory (Baddeley & Hitch, 1974)

> [!definition] Working Memory (Baddeley & Hitch, 1974)
> A limited-capacity cognitive system for the temporary maintenance and active manipulation of information in service of ongoing cognitive tasks. Distinct from the passive short-term store of the Atkinson-Shiffrin model: working memory is inherently active, involving both storage and processing. Comprises the phonological loop, visuospatial sketchpad, central executive, and episodic buffer. Capacity is typically estimated at 3–4 chunks for the focus of attention, substantially lower than Miller's original 7 ± 2 estimate, which conflated immediate recall with active manipulation. Working memory is NOT the same as short-term memory, intelligence, or attentional capacity, though it is correlated with all three.

> [!evidence] Working Memory (Baddeley & Hitch, 1974)
> A multicomponent cognitive system responsible for the temporary storage and manipulation of information in the service of ongoing cognitive tasks. Distinguished from short-term memory by its active, processing role. The original tripartite model — phonological loop, visuospatial sketchpad, central executive — was later extended with the episodic buffer as a fourth component. The capacity of the phonological loop and visuospatial sketchpad is severely limited (4±1 chunks; Cowan, 2001); the central executive's attentional resources are limited, not capacity-fixed.
>
> **Boundary:** Working memory is not a unitary memory store but a distributed functional system. Its "capacity" is not a simple number but a profile of limits varying by modality, processing demand, and material type. Confusing working memory with short-term memory produces incorrect predictions about capacity limits.
>
> **Report-Specific Significance:** Working memory limitation is the foundational constraint that makes cognitive offloading through PKM valuable. All seven design principles in this report are responses to this constraint.
>

> [!evidence] Working Memory (Baddeley & Hitch, 1974)
> [[working-memory]] is the cognitive system that temporarily maintains and manipulates information needed for complex cognitive tasks. Distinguished from simple short-term storage by its active processing character — working memory is not just a buffer but an executive system that coordinates the handling of information across specialized subsystems. Capacity is limited (approximately 4 active items; Cowan, 2001) and highly contested between domains — verbal and spatial material compete for the same limited central executive resources.
>
> **Boundary:** Working memory capacity is not equivalent to intelligence, though they are correlated. It is a processing resource, not a property of long-term knowledge. Critically, the effective capacity of working memory *in a specific domain* can be expanded without increasing raw capacity by building richer schemas — schemas allow more information to be held in a single chunk.
>
> **See also:** [[working-memory-capacity]], [[Baddeley's-Working-Memory-Model]], [[cognitive-load-theory]], [[chunking]], [[long-term-memory]]

> [!evidence] Working Memory (Baddeley & Hitch, 1974)
> [[working-memory]] is the cognitive system that temporarily maintains and manipulates information during complex cognitive tasks. [[Baddeley's-Working-Memory-Model|Baddeley and Hitch's model]] distinguishes a central executive (attentional control), phonological loop (verbal material), visuospatial sketchpad (spatial/visual material), and episodic buffer (cross-modal binding). > [!evidence] Working Memory (Baddeley & Hitch, 1974)
> A limited-capacity cognitive system responsible for the temporary storage and manipulation of information necessary for complex tasks such as language comprehension, learning, and reasoning. It comprises multiple specialized subsystems — the [[phonological-loop|phonological loop]], the [[visuospatial-sketchpad|visuospatial sketchpad]], and the [[episodic-buffer|episodic buffer]] — all coordinated by the [[central-executive|central executive]], which allocates attentional resources and manages the interface between working memory and [[long-term-memory|long-term memory]].
>
> **Boundary:** Working memory is distinct from short-term memory in that it involves active manipulation, not merely passive storage. It is also distinct from attention, though the two overlap substantially at the level of the central executive.
>
> **Report-Specific Significance:** The capacity limits of working memory are the fundamental constraint that determines whether walking competes with reading for cognitive resources or operates on independent channels.
>
