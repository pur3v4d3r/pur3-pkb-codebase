## Core Explanation

> [!evidence] Technical Detail: Top-Down and Bottom-Up Processing in Schema Activation
> Schema theory postulates two streams of processing that must be coordinated:
>
> **Bottom-up processing** ([[bottom-up-processing]]): Data-driven. The raw perceptual/linguistic input activates feature detectors, which activate higher-level pattern recognizers, which eventually activate schema-relevant nodes. This is slow but veridical — it's faithful to the actual input.
>
> **Top-down processing:** Schema-driven. Once a schema is partially activated, it propagates expectations *downward* through the processing hierarchy — essentially predicting what lower-level features should be present given the schema. These predictions then influence how bottom-up signals are interpreted.
>
> The interaction: top-down processing accelerates comprehension by constraining which bottom-up features need to be processed carefully (those unexpected by the schema) vs. which can be processed efficiently (those predicted by the schema). This is why reading speed increases dramatically in high-familiarity domains — the schema's top-down predictions match the incoming text, reducing the processing burden of each word.
>
> **Precision:** This is a schematic description of a processing architecture. At the neural level, the interaction is bidirectional and hierarchical across cortical areas (see Level 3-4 for neural substrate). The "two streams" description is a useful abstraction at the computational level.
> **Dependencies:** Familiarity with levels-of-processing frameworks, basic knowledge of cognitive processing hierarchies.
