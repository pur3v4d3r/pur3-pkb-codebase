# Technical Detail: The Isolated-Interacting Elements Effect

## Core Explanation

> [!evidence] Technical Detail: The Isolated-Interacting Elements Effect
> The [[isolated-interacting-elements-effect|isolated-interacting elements effect]] is a direct consequence of this distinction. When material high in element interactivity is *presented* as though its elements were isolated (by first teaching individual elements in isolation before requiring their simultaneous integration), learning improves for novices. This works because:
>
> 1. **Phase 1 (isolated):** Learners encounter individual elements one at a time, forming nascent schemas for each. Element interactivity is low because elements are processed serially.
> 2. **Phase 2 (interacting):** Learners now integrate the pre-learned elements. Because each element has been partially schematized in Phase 1, the number of *novel* interacting elements is reduced — some elements now function as schema-elements rather than raw elements.
>
> **The critical subtlety:** This is not the same as "teach simple things before complex things." It is specifically about presenting initially interacting elements as temporarily isolated, then reintroducing the interactivity. The distinction matters because the sequencing strategy only works when the material genuinely contains element interactivity — for material that is *already* low in element interactivity (truly isolated elements), the staged approach adds unnecessary steps.
>
> **Precision:** This effect has been demonstrated primarily with procedural and conceptual materials. Its boundaries with deeply relational materials (e.g., argument structures, theoretical models) are less studied.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
