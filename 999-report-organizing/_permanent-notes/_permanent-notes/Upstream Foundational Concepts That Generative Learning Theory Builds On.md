## Cross-Domain Connections

> [!cross-domain-connection] Upstream: Foundational Concepts That Generative Learning Theory Builds On
> - **[[constructivism]]** — The philosophical and psychological tradition asserting that knowledge is built rather than received; GLT is a specific operationalization of constructivist principles within cognitive architecture
> - **[[information-processing-theory]]** — Provides the cognitive architectural framework (encoding, storage, retrieval; working memory and long-term memory) within which GLT specifies generative mechanisms
> - **[[schema-theory]]** — The concept of organized knowledge structures in long-term memory; GLT's integration process is precisely the act of connecting new information to existing schemas
> - **[[levels-of-processing-theory]]** — Craik and Lockhart's depth-of-processing framework provides an earlier account of why elaborative encoding produces more durable memory, anticipating and informing GLT
> - **[[meaningful-learning-theory]]** — Ausubel's concept that learning is meaningful when connected to prior knowledge (vs. rote memorization); GLT extends this into a process-level account of how meaningful learning occurs
> - **[[Baddeley's-Working-Memory-Model]]** — The cognitive architectural model of working memory used by Mayer in CTML; provides the dual-channel substrate for multimedia generative processing
> *— [[generative-learning-theory-foundational-report-2026-04-03_report]]*
