## Core Explanation

> [!evidence] Reconstructive Memory: From Bartlett to Loftus
> **Description:** A historical-genealogical report tracing the development of constructivist accounts of memory from Bartlett's (1932) schema-based theory through Loftus's misinformation effect research to modern memory distortion studies. Should address the theoretical tension between productive reconstruction and problematic distortion.
>
> **Connection to This Report:** The synergistic ecphory model's insistence that retrieval is constructive — and therefore that the same trace can yield different outputs depending on the retrieval cue — directly connects to the Bartlett-Loftus constructivist tradition. The forensic memory section (7.5) specifically invokes Loftus's work.
