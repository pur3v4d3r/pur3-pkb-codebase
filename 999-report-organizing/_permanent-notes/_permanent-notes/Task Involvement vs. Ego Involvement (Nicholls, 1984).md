# Task Involvement vs. Ego Involvement (Nicholls, 1984)

> [!definition] Task Involvement vs. Ego Involvement (Nicholls, 1984)
> **Definition:** In [[john-g.-nicholls]]' original framework, task involvement and ego involvement represent two qualitatively distinct states of engagement with an achievement activity. Task involvement is a motivational state in which success is defined as mastery of the task — demonstrating learning, improvement, or competence relative to one's own prior performance. Ego involvement is a motivational state in which success is defined as demonstrating superior ability relative to others, or at minimum avoiding demonstration of inferior ability. This is NOT merely a difference in goal content — it is a difference in the epistemological standard by which competence itself is evaluated.
> **Report-Specific Significance:** Nicholls' distinction provides the conceptual foundation for the mastery-performance axis in the 2×2 framework, but it was fundamentally a state-based theory, not a goal-orientation theory. The transition to goal orientations as stable individual differences required theoretical work that Nicholls himself was ambivalent about.
> **Operational Indicators:** Ego involvement can be identified by characteristic cognitive responses to failure (ability attribution, helplessness, withdrawal) and to success (relative-ability inference, defensive self-presentation). Task involvement can be identified by error correction behaviour, curiosity about process, and resilience to comparative failure.
