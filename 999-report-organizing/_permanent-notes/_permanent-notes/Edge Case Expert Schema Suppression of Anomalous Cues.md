# Edge Case: Expert Schema Suppression of Anomalous Cues

## Core Explanation

> [!evidence] Edge Case: Expert Schema Suppression of Anomalous Cues
> **The case:** When an expert's well-automated schema is activated by a highly typical pattern of cues, the top-down constraint from the activated schema actively suppresses attention to cues that don't fit the schema. The expert has less conscious access to anomalous features than a novice would, because the novice's less-dominant schema has weaker suppressive effects.
>
> **Clinical medicine instance:** A senior physician seeing patient with classic presentation of a common condition (chest pain + radiation + diaphoresis → MI) has the MYOCARDIAL-INFARCTION schema activated with high confidence. If the patient also has an atypical presentation element consistent with an alternative diagnosis (aortic dissection, which can mimic MI), the expert's strong schema commitment causes the atypical element to be noticed less than it would be by the resident who has not yet formed strong schema commitment. The clinical literature documents this as "anchoring" — commitment to an initial schema that suppresses perception of disconfirming evidence.
>
> **What standard understanding predicts:** Greater expertise → greater diagnostic accuracy uniformly. Expert schemas should prevent errors, not create new types of errors.
>
> **What actually happens:** The relationship between schema strength and error rate is *non-monotonic*. Novices make many errors of commission (wrong schema activation). Moderate experts make fewer errors overall. Highly automated experts make fewer errors on typical cases but a new category of errors: missed atypical presentations that activate their well-formed schema despite significant anomaly.
>
> **Why this matters:** Schema automation — the same process that makes expertise efficient — also creates systematic blind spots for the instances that don't fit the expert's schema well. This has implications for any domain where missing atypical instances is high-stakes: radiology, aircraft maintenance, security screening, medical diagnosis.
>
> **The metacognitive intervention:** Deliberate slowing and explicit anomaly-searching strategies ("What would make me wrong here?") can partially compensate for automatic schema suppression in high-stakes expert decisions. This is why structured "diagnostic time-out" protocols in medicine aim at the right clinical population: not novices (who haven't yet automated irrelevant schemas) but experts (who have automated schemata strong enough to suppress anomalous cues).
