# Working Memory (Baddeley & Hitch, 1974; revised 1986–2000)

> [!definition] Working Memory (Baddeley & Hitch, 1974; revised 1986–2000)
> A limited-capacity, limited-duration cognitive system responsible for the temporary activation and manipulation of information during ongoing cognitive tasks. Distinguished from short-term memory by its active, generative character: working memory does not merely store; it processes. The model's central executive coordinates attention allocation across subsystems, making executive functioning the direct correlate of what CLT will later call "available cognitive resources."
>
> **Boundary:** Working memory is NOT synonymous with short-term memory, though the terms are often conflated in popular discourse. Short-term memory emphasizes passive storage; working memory emphasizes active processing. For CLT's purposes — and for PKM design — the distinction matters because extraneous load taxes the processing (working memory) dimension, not merely the storage dimension.
>
> **Report-Specific Significance:** Every CLT prescription about instructional design and every PKM practice this report recommends ultimately traces back to the properties of working memory described here. Understanding its architecture is prerequisite to understanding why any practice works.
>
