# Schema Instantiation

> [!definition] Schema Instantiation
> The process by which an abstract schema receives specific variable values from the current input, producing a specific instance interpretation. Instantiation is NOT simple retrieval: it is a constraint-satisfaction process in which the abstract variable structure is bound to specific values that maximally satisfy the constraints while accounting for the available input. Instantiation involves both value binding (assigning specific values to slots) and inference generation (predicting likely values for slots not directly specified by input).
>
> **Complexity:** Instantiation can be partial — some slots may remain unbound if input is insufficient. Partial instantiation produces a schematic interpretation with explicit gaps, not a binary success/failure.

> [!evidence] Schema Instantiation
> The process of creating a working copy of a generic, abstract schema and filling its slots with specific values from the current situation. Instantiation involves *variable binding* — connecting abstract schema slots to specific situational entities — and *default value assignment* — filling unspecified slots with typical expected values. Instantiation occurs rapidly and largely automatically for well-established schemas.
> *— [[schema-theory-foundational-report-2026-04-03_report]]*
