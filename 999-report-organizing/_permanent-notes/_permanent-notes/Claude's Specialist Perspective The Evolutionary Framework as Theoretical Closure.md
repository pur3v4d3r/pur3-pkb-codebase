## Reflections

> [!claude-insight] Claude's Specialist Perspective: The Evolutionary Framework as Theoretical Closure
> The evolutionary analogy is not merely pedagogical — it provides theoretical closure for why element interactivity must be the central mechanism. If learning is the construction of schemas (Information Store Principle), and most schemas are borrowed (Borrowing and Reorganizing), and novel schema construction requires random generation-and-test (Randomness as Genesis), and working memory limits the rate of novel processing (Narrow Limits of Change), then *the only variable that determines whether learning succeeds or fails is whether the element interactivity of the to-be-learned material exceeds working memory capacity*. This is not one prediction among many — it is the *entire theoretical prediction*. Every instructional effect is a special case of this single prediction applied to different instructional contexts.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
