# Need Absence

> [!definition] Need Absence
> A state in which a basic psychological need is not being satisfied in a given context without active thwarting. Distinguished from need frustration by the absence of the specific defensive responses that active thwarting produces. The distinction is operationalized in the Basic Psychological Need Satisfaction and Frustration Scale (BPNSFS; Chen et al., 2015).
