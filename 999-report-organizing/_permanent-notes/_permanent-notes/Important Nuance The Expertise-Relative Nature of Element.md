## Core Explanation

> [!evidence] Important Nuance: The Expertise-Relative Nature of "Element"
> The definition of "element" is *inherently relative to the learner's current knowledge state*. This relativity is not a weakness of the concept but a feature of its theoretical architecture. Consider the following example:
>
> **For a beginning algebra student:** The expression $3x + 5 = 17$ contains multiple interacting elements: the variable $x$, the coefficient 3, the operation of multiplication (implicit in $3x$), the constant 5, the addition operation, the equality relation, and the target value 17. Understanding the equation requires simultaneously processing the relationships among all of these elements.
>
> **For an experienced algebra student:** The expression $3x + 5 = 17$ is a single element — a schema of "simple linear equation" that immediately activates procedural knowledge (isolate the variable, reverse operations). The multiple lower-level elements have been encapsulated into a single schema-element.
>
> **When the distinction matters:** Always, when counting element interactivity or designing instruction for a specific population.
> **When it doesn't:** When making broad qualitative predictions ("this material is high in element interactivity for the target population").
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
