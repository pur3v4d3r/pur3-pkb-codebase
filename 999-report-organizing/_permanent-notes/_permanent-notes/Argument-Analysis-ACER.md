# Argument-Analysis-ACER

> [!definition] Argument-Analysis-ACER
> Competency involving identification of claims, premises, reasoning structure; recognition of argument types (deductive, inductive, abductive); detection of implicit assumptions; and evaluation of argument strength. ACER framework emphasizes argument analysis as foundational CT skill because arguments are primary vehicles for communicating reasoning.
