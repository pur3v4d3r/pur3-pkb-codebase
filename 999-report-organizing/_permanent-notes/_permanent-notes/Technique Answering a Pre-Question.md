## Core Explanation

> [!evidence] Technique: Answering a Pre-Question
> *Why here: Return to the pre-question generated during the text survey. Use the section to explicitly close the loop — and note where the answer surprised you.*
>
> **Pre-Question Q4 (revisited):** Why does motivation get its own dedicated section in a report that is ostensibly about process? What failure mode is this section addressing?
>
> **Answer constructed from reading:** The failure mode is motivational attrition. The SRL protocols require sustained effortful engagement with difficult material. This is intrinsically costly. Without specific design features that satisfy the three basic psychological needs identified by [[self-determination-theory]] (autonomy, competence, relatedness), the practice gradually becomes aversive and is abandoned — even when the learner intellectually endorses it. The motivational architecture section is addressing the gap between *knowing the protocol* and *wanting to execute it when the material is hard*.
>
> **What surprised me:** The section identifies something called the "Early Implementation Dip" — an initial performance degradation when learners begin implementing explicit self-regulatory protocols, because the cognitive overhead of the new practices competes with resources for content processing. This is directly relevant to my situation. If I begin using these protocols and notice that my comprehension feels *worse* in the short term, the correct response is not "these techniques don't work" — it is to persist with process-goal standards (was I following the protocol?) rather than outcome standards (did I understand everything?). The Dip is a feature, not a defect.
> *— [[optimal-reading-session-worked-example-2026-03-25_report]]*
