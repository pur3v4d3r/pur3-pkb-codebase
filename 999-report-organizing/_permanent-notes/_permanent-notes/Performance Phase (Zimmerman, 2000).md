# Performance Phase (Zimmerman, 2000)

> [!definition] Performance Phase (Zimmerman, 2000)
> The second phase of the cyclical model, comprising self-control (deliberate application of the selected strategy) and self-monitoring (ongoing tracking of performance quality against the goal standard established in forethought). The phase in which regulatory behavior is executed and observable.

> [!evidence] Performance Phase (Zimmerman, 2000)
> The phase occurring during learning performance, encompassing two categories: (1) *Self-Control* — applying the strategies selected during forethought (imagery, self-instruction, attention focusing, task strategies); and (2) *Self-Observation* — metacognitive monitoring and self-recording of performance quality and strategy effectiveness. The Performance Phase is where learning strategies operate and where real-time monitoring data is generated.
> *— [[zimmerman-srl-focused-analysis-2026-03-22_report]]*

> [!evidence] Performance Phase (Zimmerman, 2000)
> The second phase of the cycle, encompassing the learning activity itself. Contains *self-control* processes (self-instruction, imagery, attention focusing, task strategies) and *self-observation* processes ([[self-monitoring]], self-recording). The critical claim is that self-observation during performance generates feedback data that will be processed in the Self-Reflection Phase. The tight-loop assumption is most visible here: Zimmerman proposes that effective learners are *continuously* monitoring their performance against their goals, generating real-time data that will enable adaptive adjustment.
> *— [[zimmermans-cyclical-model-srl-dialectical-re-examination-2026-03-23_report]]*
