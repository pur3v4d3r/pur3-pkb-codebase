## Core Explanation

> [!evidence] [[clt-as-a-dynamic-load-optimization-problem]]
> **Description:** CLT's standard treatment presents load as a property of static instructional designs. A more sophisticated framing treats cognitive load during active learning as a dynamic optimization problem, where the learner and the learning environment co-adapt in real time. This topic would examine adaptive instructional systems, real-time cognitive load monitoring (eye-tracking, pupillometry, interaction data), and the implications for PKM systems that can detect and respond to practitioner load states.
> **Connection to This Report:** Section 7 identified the measurement problem as CLT's main empirical vulnerability. Dynamic, real-time load monitoring would resolve this limitation. Section 6's expertise-adaptation principle would benefit from a formal dynamic account.
> **Priority:** High
> **Suggested Report Type:** Comparative Architecture — comparing existing adaptive learning system architectures against the CLT-dynamic-optimization standard.
> **Prerequisites:** [[cognitive-load-theory]], [[metacognition]], [[working-memory]]
