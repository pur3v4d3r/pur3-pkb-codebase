# Reconsolidation

> [!definition] Reconsolidation
> Reconsolidation is the process by which a previously consolidated memory, upon being reactivated through retrieval, re-enters a labile state and requires renewed protein synthesis-dependent stabilisation to be maintained. Discovered experimentally by [[Karim-Nader|Karim Nader]], [[Glenn-Schafe|Glenn Schafe]], and [[Joseph-LeDoux|Joseph LeDoux]] in 2000, reconsolidation challenges the traditional view that consolidation is a one-time event, suggesting instead that memories are dynamically updated each time they are recalled. This has implications for both the therapeutic modification of maladaptive memories (as in the treatment of post-traumatic stress) and for the understanding of how memories are transformed by each act of retrieval.
>
> **Boundary:** Reconsolidation is not the same as initial consolidation; it applies only to reactivated memories and may involve different molecular mechanisms.
>
> **See also:** [[memory-consolidation]], [[retrieval-practice]]

> [!evidence] Reconsolidation
> The process by which a retrieved (reactivated) memory returns briefly to a protein-synthesis-dependent, labile state during which it can be modified, before being re-stabilized (reconsolidated). Discovered by Nader, Schafe, and LeDoux (2000) in amygdala-dependent fear memories. Reconsolidation provides a cellular mechanism for memory updating — the integration of new information into reactivated memory traces — and for the therapeutic modification of maladaptive memories. The reconsolidation window opens upon memory reactivation and closes when the memory is re-stabilized (typically over hours, blocked by protein synthesis inhibitors).
>
> **Boundary:** Not all memories reconsolidate equivalently; very remote, strongly consolidated memories may be less susceptible. Reconsolidation requires genuine memory reactivation (not merely cue presentation without retrieval) and is most robustly demonstrated for fear-conditioned, emotionally significant memories.
>
