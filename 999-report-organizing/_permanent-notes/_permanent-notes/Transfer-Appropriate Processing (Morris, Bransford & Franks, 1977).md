# Transfer-Appropriate Processing (Morris, Bransford & Franks, 1977)

> [!definition] Transfer-Appropriate Processing (Morris, Bransford & Franks, 1977)
> A principle stating that memory performance is optimized when the cognitive processing requirements at retrieval match the type of processing engaged at encoding. Rather than focusing on trace strength or encoded cue-target relationships, TAP foregrounds the *type of cognitive operation* performed: phonological, semantic, syntactic, imagistic. A test that reactivates the same type of processing as learning will produce better memory than one that requires a different type of processing, regardless of how deeply or elaborately material was processed.
>
> **Boundary:** TAP may appear to subsume the ESP, but the two differ in important ways. TAP is process-level; the ESP is content-level. TAP does not require specific encoded cue information; it requires matching processing type. The predictions diverge in cases where the type of processing matches but the specific encoded content does not.
>
> **See also:** [[transfer-appropriate-processing]], [[Morris,-Bransford,-and-Franks]], [[transfer-of-learning]], [[levels-of-processing-theory]], [[encoding-specificity-principle]]

> [!evidence] Transfer-Appropriate Processing (Morris, Bransford & Franks, 1977)
> The principle that memory performance is optimized when the type of cognitive processing performed at encoding *transfers appropriately* to (i.e., overlaps with) the type of cognitive processing required at retrieval. Rather than claiming that deep processing is universally superior, TAP claims that the best encoding for any given test is the encoding that most closely matches what the test requires. Shallow processing can outperform deep processing if the retrieval test demands shallow features.

> [!evidence] Transfer-Appropriate Processing (Morris, Bransford & Franks, 1977)
> The principle that memory performance is optimized when encoding operations match retrieval operations. Challenges the universality of LOP's depth-superiority claim by showing that shallow encoding can outperform deep encoding on retrieval tests that tap shallow features. Now widely regarded as complementary to LOP rather than a replacement: depth predicts performance under semantically demanding retrieval; TAP specifies the conditions under which depth advantages will and will not appear.

> [!evidence] Transfer-Appropriate Processing (Morris, Bransford & Franks, 1977)
> A theoretical principle proposing that memory performance is maximized not by maximally deep processing per se, but by processing at encoding that matches the type of processing required at retrieval. Encoding creates representations of certain types (phonological, semantic, visual); retrieval tests require certain types of representations to be activated. When the encoding representation type matches the retrieval requirement, performance is enhanced irrespective of the nominal depth of the encoding.
>
> **Boundary:** Transfer-appropriate processing does not deny that semantic processing is generally advantageous for standard memory tests. It argues that this advantage is a consequence of the fact that standard tests typically rely on semantic cues — not evidence for an unconditional superiority of deep processing. The principle holds that the appropriate encoding depends on what the learner will need to *do* with the information at retrieval.
>
> **Report-Specific Significance:** This is the most theoretically significant challenge to the levels framework, requiring either substantial revision or careful limitation of the depth hypothesis's scope.
>
> **See also:** [[encoding-specificity-principle]], [[encoding-specificity]], [[Morris,-Bransford,-and-Franks]], [[retrieval-practice]]

> [!evidence] Transfer-Appropriate Processing (Morris, Bransford & Franks, 1977)
> The principle that memory performance is maximized not by the deepest possible encoding but by encoding that matches the type of processing required at retrieval. Semantic (deep) encoding produces superior performance on standard memory tests because standard tests rely on semantic retrieval cues; phonological (shallow) encoding produces superior performance on rhyme-based tests because those tests require phonological retrieval. The match between encoding type and retrieval type is the critical variable, which is an encoding-retrieval match account rather than an unconditional depth account.
>
> **Boundary:** TAP does not deny the general advantage of semantic processing for most practical memory tasks. It argues this advantage is conditional on test type, not an unconditional property of "depth." For most academic and everyday memory demands (which rely on semantic cues), TAP and LOP make the same prediction.
