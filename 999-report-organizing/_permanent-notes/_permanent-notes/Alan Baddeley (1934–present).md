## Additional Material

> [!person] Alan Baddeley** (1934–present)
> British cognitive psychologist; developer (with Graham Hitch) of the influential multi-component model of working memory (1974), replacing Atkinson and Shiffrin's unitary short-term memory store with a three-then-four component architecture. Baddeley's model provides the cognitive architecture that CLT's load analysis operates within.
>
> **Core contribution to this report:** Multi-component WM model (Central Executive, phonological loop, visuospatial sketchpad, episodic buffer); working memory capacity as the binding constraint on learning and complex cognition.
> *— [[pkm-and-cognitive-load-foundational-report-2026-04-05_report]]*
