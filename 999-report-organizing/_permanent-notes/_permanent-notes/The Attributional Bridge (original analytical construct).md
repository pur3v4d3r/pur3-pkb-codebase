# The Attributional Bridge (original analytical construct)

> [!definition] The Attributional Bridge (original analytical construct)
> The interpretive mechanism within the Self-Reflection Phase by which performance outcomes are translated into belief updates. The bridge is not a neutral conduit but an active interpreter whose architecture (attributional tendencies, evaluation standards) determines what motivational consequences performance outcomes have. Distinguishable from attribution per se by its functional role in the cycle's feedback dynamics.
