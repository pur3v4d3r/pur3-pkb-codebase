# Event Indexing Model (Zwaan, Langston, & Graesser, 1995)

> [!definition] Event Indexing Model (Zwaan, Langston, & Graesser, 1995)
> **Definition:** A model of situation model structure proposing that readers continuously monitor and update five dimensions of the described situation: temporal, spatial, causal, intentional, and entity. Reading times increase when any dimension shifts, indicating active model maintenance. Boundary condition: the model describes competent readers; poor comprehenders show less sensitivity to dimension shifts, indicating less active model monitoring.
>
> **Report-Specific Significance:** Provides the structural architecture for the reconstructed situation-model monitoring strategy; the five dimensions serve as the monitoring checklist for deliberate situation-model construction.
>
> **Cross-References:** [[situation-model]], [[situation-models-in-text-comprehension]], [[mental-simulation]], [[working-memory-in-reading]]
