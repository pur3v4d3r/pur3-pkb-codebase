## Core Explanation

> [!evidence] Aporia I: The Explanation-Test Collapse
> The explanation-test, which seemed to provide a clean criterion for understanding, has been shown to fail in both directions. It can be *passed without understanding* — sophisticated parrots, memorised explanations, and recited arguments all generate surface-level explanatory fluency without structural grasp. And it can *fail in the presence of understanding* — tacit knowledge domains, where genuine expertise is embodied in perception or motor skill rather than verbal articulation, produce genuine understanding that explanation cannot capture. The test is useful as a defeater: failing it provides evidence against understanding. But passing it confirms nothing definitive.
> *— [[what-does-it-mean-to-truley-understand-something-2026-03-10_report]]*
