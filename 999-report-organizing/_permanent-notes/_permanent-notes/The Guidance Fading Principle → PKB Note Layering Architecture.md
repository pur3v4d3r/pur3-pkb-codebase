## Cross-Domain Connections

> [!cross-domain-connection] The Guidance Fading Principle → PKB Note Layering Architecture
> The [[guidance-fading-principle|Guidance Fading Principle]] from CLT (progressively reduce instructional support as expertise develops) maps directly onto PKB note suite design. A well-designed note cluster should include: (a) scaffolded entry-level notes that explicitly decompose element interactions for novice readers, (b) intermediate notes that assume some schemas and focus on higher-order interactions, (c) frontier notes that operate at expert-level element interactivity, assuming all lower schemas are in place. This three-tier structure operationalizes the guidance fading principle as a spatial architecture rather than a temporal sequence — the expertise-appropriate entry point into a note cluster is the reader's choice, but the architecture should support multiple entry points across the expertise spectrum.
> *— [[cognitive-load-theory-focused-analysis-2026-03-22_report]]*
