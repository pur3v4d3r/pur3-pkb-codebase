# Distinctiveness (Memory Encoding)

> [!definition] Distinctiveness (Memory Encoding)
> The degree to which a memory trace is clearly differentiated from other traces in the memory system — unique in its properties, associations, and contextual embedding such that retrieval cues can selectively and unambiguously activate it. Distinctiveness is achieved through unusual content, unique contextual embedding, or highly specific elaboration that differentiates the trace from similar items. It is related to but not identical with depth: a deeply processed item can still be poorly distinctive if it activates only shared semantic features without unique individuating information.
>
> **Boundary:** Distinctiveness should be distinguished from salience — a distinctive memory is not simply one that attracted more attention, but one that is uniquely characterized in memory. Distinctiveness theory (Hunt, 1995) elaborates the role of distinctive processing more fully than the original LOP framework.
>
> **See also:** [[deep-processing]], [[self-reference-effect]], [[elaboration]]
