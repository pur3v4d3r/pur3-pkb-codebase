# Cognitive Load (Sweller, 1988)

> [!definition] Cognitive Load (Sweller, 1988)
> The total amount of mental activity imposed on working memory at a given moment during learning or task performance. Measured across three components: intrinsic load (arising from the inherent complexity of the material), extraneous load (arising from poor instructional or environmental design), and germane load (the subset of intrinsic processing directed toward schema formation). Total cognitive load must not exceed working memory capacity, or performance and learning degrade. Distinguished from "cognitive effort" (subjective experience of load) and "cognitive demand" (objective task requirements independent of learner characteristics).
>
> **Boundary:** Cognitive load is a property of the learner-task interaction, not just the task. The same material may impose high load on a novice and negligible load on an expert whose schemas allow chunk-based recognition.
>
> **Report-Specific Significance:** The central construct around which both CLT's instructional prescriptions and this report's PKM analysis are organized.
>
> **See also:** [[cognitive-load-theory]], [[working-memory]], [[element-interactivity]], [[Germane-Cognitive-Load-Sweller,-van-Merriënboer-&-Paas,-1998-—-Original-Formulat]]

> [!evidence] Cognitive Load (Sweller, 1988)
> The total demand placed on working memory by a learning task at any given moment. Originally conceived as a single unitary construct, later differentiated into three types. Critical boundary condition: cognitive load is a property of the interaction between a learner and a task, not a property of the task alone — the same task imposes different loads on different learners, and on the same learner at different stages of expertise development. The boundary condition that "load" is learner-relative is frequently forgotten in practice.

> [!evidence] Cognitive Load (Sweller, 1988)
> The total mental effort imposed on working memory during a cognitive task. High cognitive load — produced by complex content, unfamiliar material, or multi-step tasks — consumes the cognitive resources needed for CT. CT instruction must attend to cognitive load, ensuring that the content complexity is calibrated to learners' existing knowledge so that sufficient cognitive resources remain available for analytical processing.

> [!evidence] Cognitive Load (Sweller, 1988)
> The total demand placed on [[working-memory]] by a cognitive task at a given moment. Cognitive load is multidimensional, varying in source (intrinsic, extraneous, germane), intensity (ranging from negligible to overload), and temporal profile (sustained, peaked, oscillating). When total cognitive load exceeds working memory capacity, processing efficiency falls, errors increase, and learning is impaired.
>
> **Boundary:** Cognitive load is a property of the interaction between a person and a task, not a property of either alone. The same task generates different loads for different individuals depending on prior knowledge, expertise, and current cognitive state. A note-linking decision that is trivial for an experienced PKM practitioner may be genuinely demanding for a novice.
>
> **Report-Specific Significance:** The concept of cognitive load as a bottleneck resource enables precise diagnosis of PKM system failures — not as personal faults or motivational deficits, but as predictable consequences of design decisions that exceed cognitive capacity.
>
> **See also:** [[intrinsic-cognitive-load]], [[extraneous-cognitive-load]], [[germane-cognitive-load]], [[working-memory]], [[cognitive-architecture]]
> *— [[pkm-and-cognitive-load-foundational-report-2026-04-05_report]]*

> [!evidence] Cognitive Load (Sweller, 1988)
> The total demand placed on working memory during a cognitive task, arising from the complexity of the material, the quality of its presentation, and the degree of effortful processing invested in comprehension and schema formation. Measured subjectively via Paas's 9-point mental effort scale or inferred from dual-task performance costs.
>
> **Boundary:** Cognitive load is not synonymous with subjective difficulty. Tasks can feel difficult due to high intrinsic load (genuine material complexity), high extraneous load (poor design), or both. Distinguishing the source of experienced difficulty is the clinician act that CLT makes possible.
