# DIME Annotation Protocol (original synthesis)

> [!definition] DIME Annotation Protocol (original synthesis)
> A reading annotation system derived from the Event Indexing Model's five situational dimensions, designed to externalize the situation model rather than the textbase. Annotations are organized around five types: Causal chain annotations (→ markers for causal relationships); Temporal gap annotations (T? for unclear sequence); Spatial annotations (S: for spatial configuration); Intentional annotations (I: for agent goals); Entity annotations (E: for state tracking). Includes compression annotations at section ends as quality checks.
>
> **Boundary:** Original synthesis by this report. Well-motivated by Event Indexing theory but not directly validated by annotation-specific empirical research.
>
> **Epistemic Status:** Well-motivated synthesis requiring empirical validation.
>
