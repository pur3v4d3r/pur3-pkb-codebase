# Extraneous Cognitive Load

> [!definition] Extraneous Cognitive Load
> Cognitive processing demand imposed by instructional design rather than by content complexity — specifically, demand that does not contribute to schema formation and therefore wastes working memory resources. The primary target of CLT-informed design. Paradigmatic sources: spatial separation of related information requiring mental integration (split-attention effect), presentation of the same information in multiple formats that each require processing (redundancy effect), exclusive use of visual presentation when auditory channel could share the load (modality effect). Boundary condition: "extraneous" is design-imposed, not content-determined — the same information can have high or low extraneous load depending on how it is presented.

The primary target of CLT-derived instructional design recommendations because it is reducible without compromising what is learned.

> [!evidence] Extraneous Cognitive Load
> The cognitive load imposed not by the content itself but by how it is presented — the instructional design decisions that require cognitive effort without contributing to schema construction. Split-attention layouts (where related information must be mentally integrated because it is spatially separated), redundant explanations that duplicate information already available in diagrams, and cluttered or poorly organized interfaces all generate extraneous load. This is the "wasteful" load — theoretically eliminable through good design. Reducing extraneous load is CLT's most actionable instructional prescription.

> [!evidence] Extraneous Cognitive Load
> [[extraneous-cognitive-load|Extraneous cognitive load]] (also called extraneous load or ineffective load) is the component of cognitive load generated by instructional procedures and materials that do not contribute to [[schema-construction]] or [[schema-automation]]. It represents wasted cognitive capacity — working memory resources consumed by activities that are irrelevant or detrimental to the learning objective.
>
> **Boundary:** Extraneous load is not always obvious. Some instructional activities that *appear* pedagogically active (e.g., searching for information across spatially separated sources) impose extraneous load because they require cognitive effort that does not directly support schema building.
>
> **Report-Specific Significance:** Extraneous load is the primary target of CLT-based instructional design. Reducing extraneous load is the *first-order design objective* because it frees working memory capacity for intrinsic load processing and germane activity.
>
