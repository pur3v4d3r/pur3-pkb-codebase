# Cognitive Load (in communication)

> [!definition] Cognitive Load (in communication)
> The total mental effort required to process a communicative message, decomposable into intrinsic load (inherent complexity of the content), extraneous load (complexity created by poor message design), and germane load (processing devoted to schema formation). Effective message construction minimizes extraneous load. See [[cognitive-load-theory]], [[working-memory]], [[chunking]].
