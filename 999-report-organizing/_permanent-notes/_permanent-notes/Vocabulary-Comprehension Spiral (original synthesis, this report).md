# Vocabulary-Comprehension Spiral (original synthesis, this report)

> [!definition] Vocabulary-Comprehension Spiral (original synthesis, this report)
> A bidirectional, mutually amplifying feedback architecture in which vocabulary knowledge and reading comprehension are dynamically coupled: vocabulary enables comprehension; comprehension quality determines the inferential context richness available for vocabulary acquisition; acquisition quality determines future vocabulary representations that support comprehension. The system has two stable equilibria: a positive spiral (high vocabulary → rich context → deep processing → richer vocabulary) and a negative spiral (thin vocabulary → impoverished context → shallow processing → minimal gain).
>
> **Boundary:** The spiral model is a qualitative dynamical account, not a quantitative predictive model. It does not specify precise bifurcation thresholds or growth rates; it explains the *structure* of the trajectory, not its exact shape.
>
