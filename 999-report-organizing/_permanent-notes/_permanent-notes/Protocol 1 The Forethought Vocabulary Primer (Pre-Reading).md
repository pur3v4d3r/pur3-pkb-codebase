## Additional Material

> [!protocol] Protocol 1: The Forethought Vocabulary Primer (Pre-Reading)
> **Context:** Use at the beginning of any academic reading session where SRL engagement matters. Based on the reconstructed account that forethought-phase vocabulary constitutes the motivational architecture of the session. Reflects reconstructed (not thesis) understanding.
>
> **Steps:**
> 1. **Goal formulation** (transformation framing): State the session's goal using a transformation template: "By the end of this reading, I will understand [specific argument/concept/connection] well enough to [apply it / explain it / connect it to / interrogate it with]." Note: "well enough to" encodes a success criterion that is about comprehension quality, not task completion.
>
> 2. **Difficulty anticipation** (developmental framing): Note what you expect to find difficult using temporal markers: "I haven't yet built background in [area]; I'll approach unfamiliar terms as vocabulary to construct, not obstacles to avoid."
>
> 3. **Regulatory language check**: Is your goal formulation using identified/integrated language ("I want to because," "this connects to") or introjected language ("I have to," "I should finish")? If introjected, ask: what is the genuine personal value in understanding this? Reformulate using that value.
>
> **Success Criteria:** Goal formulation is transformation-focused, uses temporal developmental framing, and reflects identified/integrated (not introjected) regulatory language.
>
> **Common Pitfalls:** Defaulting to completion framing ("I'll read this chapter"); using purely effort-attribution without strategy-attribution ("I'll just work hard").
