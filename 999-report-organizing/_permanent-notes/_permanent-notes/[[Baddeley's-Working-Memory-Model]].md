## Core Explanation

> [!evidence] [[Baddeley's-Working-Memory-Model]]
> - **Description:** The working memory model (Baddeley & Hitch, 1974; Baddeley, 2000) replaced the unitary short-term store with a multi-component active memory system. Understanding this model's architecture — phonological loop, visuospatial sketchpad, central executive, episodic buffer — is essential for understanding how deep processing actually operates during encoding: what cognitive systems perform semantic elaboration, and how limited capacity resources shape the depth achievable.
> - **Connection to this report:** This report references the working memory model as a complementary revision of stage model assumptions; its architecture explains the mechanisms through which elaborative processing operates.
> - **Priority:** High
