## Core Explanation

> [!analytical-insight] Encoding-Retrieval Match as a Design Constraint for Knowledge Systems
> Synthesizing the ESP's claims across the full range of this report, a general design principle emerges that extends beyond individual memory science to any system that must encode and later retrieve information: the encoding-retrieval match principle should function as a hard design constraint. This means that for any knowledge system — educational curriculum, PKB architecture, professional documentation, organizational knowledge management, therapeutic exposure protocol — the following question must be asked during the design of the encoding phase: "Under what conditions will this knowledge need to be retrieved, and what cues will be operationally available in those conditions?" The encoding design must then create traces that will resonate with those anticipated retrieval cues. This principle, while derivable from the ESP, is broader than memory psychology. It is a constraint on epistemological architecture — on how knowledge should be structured to remain accessible to the minds and systems that will need it.
> *— [[encoding-specificity-principle-tulving-foundational-report-2026-04-07_report]]*
