> [!schema-activation] Activating Prior Knowledge: What You Already Know About This Topic
> Before reading, consider what you already understand about these connected areas in your PKB:
>
> **Existing conceptual anchors this report builds upon:**
> - **[[cognitive-load-theory]]**: Sweller's framework distinguishing intrinsic, extraneous, and germane load. This report reframes the entire domain of PKM as a systematic extraneous-load reduction strategy.
> - **[[extended-mind-theory]]**: Clark and Chalmers' argument that cognition can extend beyond the skin/skull boundary when external resources satisfy certain functional criteria. This report applies that framework specifically to PKB design.
> - **[[metacognition]]**: Flavell's framework for thinking about thinking. Cognitive offloading is, in a crucial sense, metacognitive architecture — the practitioner must monitor their own working memory states to offload strategically.
> - **[[long-term-memory]]**: The primary destination for information that has been processed out of working memory. Understanding the working-memory–long-term-memory interface is essential for understanding why offloading works when it does.
>
> **Advance organiser — the report's central argument in one sentence:**
> Working memory is a finite, fragile, and non-trainable-beyond-narrow-limits resource; [[personal-knowledge-management]] systems, when designed with this constraint as the organising principle, function as externally distributed working memory that amplifies what a single biological mind can accomplish.
>
> **Guiding question to hold throughout:** *To what degree is a well-designed PKB a genuine extension of your cognitive architecture, and what design decisions follow from that claim?*
> *— [[pkm-working-memory-cognitive-offloading-foundational-report-2026-04-05_report]]*
