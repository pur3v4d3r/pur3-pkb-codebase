## Cross-Domain Connections

> [!cross-domain-connection] Lateral Concepts (Parallel and Complementary)
> These frameworks address related phenomena from different angles and enrich understanding through contrast and complementarity:
> - [[dual-coding-theory]] — Paivio's dual-coding theory proposes separate verbal and imagistic systems for long-term encoding; parallels Baddeley's dual-channel working memory architecture at the long-term level
> - [[levels-of-processing-theory]] — Craik and Lockhart's levels-of-processing framework offers an alternative account of memory encoding depth without structural components; shares the emphasis on active processing but disputes the modular architecture
> - [[Cowan's-Embedded-Processes-Model]] — The primary theoretical alternative to Baddeley's framework; treating working memory as activated long-term memory + focus of attention offers different predictions and theoretical virtues
> - [[executive-function]] — Broader construct from developmental and neuropsychology that includes Baddeley's central executive as a core component alongside planning, abstract reasoning, and other frontal functions
> - [[long-term-memory]] — Working memory and long-term memory are in constant dynamic interaction; the episodic buffer is the proposed interface; and long-term memory schemas determine effective working memory capacity through chunking
> *— [[baddeley-model-of-working-memory-foundational-report-2026-04-03_report]]*
