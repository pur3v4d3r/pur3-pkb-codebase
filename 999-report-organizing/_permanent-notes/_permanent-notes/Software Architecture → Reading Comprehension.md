## Cross-Domain Connections

> [!cross-domain-connection] Software Architecture → Reading Comprehension
> In software engineering, the phenomenon is called **emergent complexity** — the property that a codebase composed of individually well-written functions can nevertheless be architecturally incoherent, with poor separation of concerns, circular dependencies, and unmaintainable global structure. Individual functions that compile and run correctly do not assemble into good architecture automatically. Architecture requires dedicated architectural attention — a global-level perspective that cannot be derived from reading each function in isolation. The engineer who reviews code function-by-function and says "this function is correct, this function is correct, therefore the system is well-designed" is committing the Automatic-Assembly Fallacy. The transfer encoding: when you find yourself satisfied with local quality (each sentence, each function, each decision) without a dedicated global-level check, the Fallacy may be operating.
> *— [[situation-model-construction-dialectical-re-examination-2026-03-29_report]]*
