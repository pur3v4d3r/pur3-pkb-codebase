# Episodic Memory (Tulving, 1972)

> [!definition] Episodic Memory (Tulving, 1972)
> A memory system dedicated to the storage and retrieval of personally experienced events, indexed by their temporal and spatial context. Episodic memory represents the *where* and *when* of experience, enabling what Tulving called "mental time travel" — the capacity to consciously re-experience past events. Distinguished from [[semantic-memory]] by its temporal context-specificity and by the phenomenological quality of "remembering" (as opposed to merely "knowing").
>
> **Boundary:** Episodic memory is not simply autobiographical memory; it is the more precise cognitive-science construct of a memory system with a specific encoding signature (temporal-contextual indexing). Many animals may have semantic-type memory without possessing full episodic memory in Tulving's strict sense.
>
> **See also:** [[declarative-memory]], [[long-term-memory]], [[memory-systems]], [[working-memory]], [[hippocampus]]

> [!evidence] Episodic Memory (Tulving, 1972)
> [[episodic-memory]] is a memory system that stores personally experienced events — *episodes* — in their temporal and spatial context. It allows "mental time travel": the subjective re-experiencing of past events that preserves the *when*, *where*, and phenomenological *what it was like* of experiences. Episodic memory is autonoetic — it involves self-aware consciousness of one's personal past. It depends critically on the hippocampus for encoding and is susceptible to interference and distortion by subsequent experiences.
>
> **Boundary:** Episodic memory is distinct from [[semantic-memory]]: it is not simply knowledge *about* a past event (semantic) but a subjective re-experiencing *of* it that preserves contextual detail. Knowing that the French Revolution began in 1789 is semantic; remembering where you were when you first learned this is episodic.
>

> [!evidence] Episodic Memory (Tulving, 1972)
> The subsystem of declarative memory storing personally experienced events in their spatio-temporal context. Involves subjective mental time travel — the capacity to consciously re-experience past events or pre-experience future ones (episodic future thinking). Episodic memory is highly context-dependent and reconstructive, incorporating post-event information and shaped by current knowledge and goals. It is the most hippocampus-dependent of all memory types and the most vulnerable to organic amnesia. Episodic memory is NOT a faithful recording: it is a reconstruction, incomplete and susceptible to distortion.
> *— [[memory-systems-working-memory-long-term-memory-foundational-report-2026-03-11_report]]*
