## Additional Material

> [!protocol] Protocol 1: Building a Forethought Template
> **Purpose:** Create a study session template that scaffolds all forethought functions.
>
> **Steps:**
> 1. Create a new template in the PKB with the header "Study Session: [Date]"
> 2. Add a **Forethought** section with the following fields:
>    - Topic (specific)
>    - Learning Objective (what will be able to do after session)
>    - Difficulty Estimate (1-5 with justification)
>    - Strategy Selection (from evidence-based strategies reference note)
>    - Time Allocation (adjusted for difficulty)
>    - Predicted Comprehension (% — for calibration training)
> 3. Add a **Performance** section with:
>    - Mid-session check-in prompt (on track? what is the gap? strategy adjustment?)
>    - Space for notes, annotations, and uncertainty markers
> 4. Add a **Reflection** section with:
>    - Post-session self-test results
>    - Calibration comparison (predicted vs. actual)
>    - Adaptive planning (what changes for next session?)
> 5. Link the template to the PKB goal scaffolding architecture
