# Working Memory

> [!definition] Working Memory
> **Working Memory** (Baddeley & Hitch, 1974): A limited-capacity cognitive system that temporarily maintains and manipulates information in an active, accessible state to support ongoing cognitive tasks. Distinct from both short-term memory (which it subsumes) and long-term memory (with which it interacts). Distinguished from passive short-term storage by its active, executive-controlled operations, its multicomponent architecture, and its functional role as an interface between perception, long-term memory, and current cognitive processing. See also: [[short-term-memory]], [[long-term-memory]], [[memory-systems]].

> [!evidence] Working Memory
> [[working-memory|Working memory]] refers to the cognitive system responsible for the temporary maintenance and active manipulation of information during complex cognitive tasks. Unlike long-term memory, which stores vast quantities of knowledge with no known upper limit, working memory is severely constrained in both capacity and duration, typically holding between three and seven independent elements for periods of seconds unless actively rehearsed.
>
> **Boundary:** Working memory is not merely short-term storage; it includes executive processes that coordinate attention, inhibit irrelevant information, and update the contents of awareness. It is distinct from [[short-term-memory|short-term memory]] in the narrower sense, which refers only to passive retention.
>
> **Report-Specific Significance:** Working memory constraint is the foundational condition that makes chunking both necessary and powerful. Without this constraint, there would be no adaptive pressure to organize information into higher-order structures, and the developmental trajectory from novice to expert would lack its primary cognitive driver.

> [!evidence] Working Memory
> A limited-capacity cognitive system responsible for the temporary maintenance and active manipulation of information in the service of complex cognitive tasks — including reasoning, comprehension, learning, and problem-solving. Unlike the passive STM of the Atkinson-Shiffrin model, working memory is inherently active and involves both storage and processing. The original Baddeley-Hitch model posited three components: the [[phonological-loop|Phonological Loop]], the [[visuospatial-sketchpad|Visuospatial Sketchpad]], and the [[central-executive|Central Executive]]. A fourth component, the [[episodic-buffer|Episodic Buffer]], was added by Baddeley in 2000. Working memory capacity is now typically assessed through *complex span tasks* (e.g., reading span, operation span) rather than simple digit span, and capacity estimates cluster around 3–4 chunks, substantially lower than Miller's original 7 ± 2.
> *— [[memory-systems-working-memory-long-term-memory-foundational-report-2026-03-11_report]]*

> [!evidence] Working Memory
> A limited-capacity cognitive system responsible for the temporary maintenance and simultaneous manipulation of information in the service of complex cognition, including comprehension, reasoning, learning, and planning. Working memory is distinguished from mere short-term storage by its emphasis on active processing and executive control.
>
> **Boundary:** Working memory is not synonymous with [[short-term-memory]], though the two constructs share historical lineage. Short-term memory, as classically conceived, refers to passive, time-limited storage; working memory adds the dimension of active processing and attentional control.
>
> **Report-Specific Significance:** Working memory serves as the foundational construct for this entire analysis — the bottleneck through which all higher cognition must pass, and therefore the system whose architecture most directly constrains and enables learning.
