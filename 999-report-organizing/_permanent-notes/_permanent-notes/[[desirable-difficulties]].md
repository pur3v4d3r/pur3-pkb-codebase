## Core Explanation

> [!evidence] [[desirable-difficulties]]
> - **Description:** Bjork's desirable difficulties framework identifies task features (spacing, interleaving, testing, generation, variability of practice) that produce difficulty during learning but enhanced long-term retention and transfer. The framework directly operationalizes LOP principles: difficulty arises precisely because shallow, automatic processing is prevented and deep, effortful processing is required.
> - **Connection to this report:** Section 4 and the Far Transfer section reference desirable difficulties as an application of depth principles to learning design; this topic merits a dedicated treatment examining each difficulty type and its LOP mechanism.
> - **Priority:** High
