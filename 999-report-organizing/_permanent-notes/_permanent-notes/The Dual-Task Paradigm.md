## Core Explanation

> [!evidence] The Dual-Task Paradigm
> Baddeley & Hitch's founding methodology was the **dual-task paradigm**: participants were required to maintain digit sequences in memory (loading the presumed short-term store) while simultaneously performing complex reasoning tasks. If the unitary STS was the primary working space for cognition, loading it should severely impair reasoning. The results were striking: **even with maximum digit-span loads, reasoning was slowed but not catastrophically impaired**. This suggested separate sub-systems — rehearsal and reasoning were drawing on different resources.
> *— [[baddeley-working-memory-model-foundational-report-2026-03-31_report]]*

> [!evidence] The Dual-Task Paradigm
> The foundational methodology for establishing working memory's component structure involves presenting participants with a primary task while simultaneously imposing a secondary task designed to load a specific component. If the two tasks use the same component, performance on one or both suffers; if they use different components, interference is minimal. This logic has produced robust evidence for the independent operation of verbal and visuospatial working memory — holding a spoken phone number while navigating by map degrades both tasks less than holding the number while memorising an unrelated number list.
> *— [[memory-systems-working-memory-long-term-memory-foundational-report-2026-03-11_report]]*
