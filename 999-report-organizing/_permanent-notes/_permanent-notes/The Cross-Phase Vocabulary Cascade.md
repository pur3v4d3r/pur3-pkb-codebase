> ┌─────────────────────────────────────────────────────────────────┐
> │               ZIMMERMAN'S SRL CYCLE WITH VOCABULARY LAYER        │
> └─────────────────────────────────────────────────────────────────┘
>
>  FORETHOUGHT PHASE         PERFORMANCE PHASE        REFLECTION PHASE
>  ┌────────────────┐        ┌────────────────┐       ┌────────────────┐
>  │ Goal Vocabulary│─seeds──▶ Monitoring     │       │ Attribution    │
>  │                │        │ Sensitivity    │       │ Vocabulary     │
>  │ Regulatory     │        │                │       │                │
>  │ Vocabulary     │        │ What cues get  │       │ Locus/Stability│
>  │                │        │ noticed:       │       │ /Controllabity │
>  │ Mastery vs.    │        │ Understanding  │       │                │
>  │ Completion     │        │ vs. Completion │       │ Ability vs.    │
>  └────────────────┘        └──────┬─────────┘       │ Strategy vs.   │
>          ▲                        │                 │ Effort         │
>          │                    Outcome               └───────┬────────┘
>          │                   Experience                     │
>          │                (comprehension level)             │
>          │                                                  │
>          └──────────────────────────────────────────────────┘
>                         SEEDS NEXT CYCLE
>
>  VOCABULARY QUALITY DETERMINES:
>  Forethought → How precisely monitoring is calibrated
>  Performance → What counts as an error worth repairing
>  Reflection  → Whether expectancy stays open or closes
> ```
> **Reading Guide:** Follow the arrows to see how vocabulary in each phase feeds the next. The critical insight: the loop can compound constructively (strategy vocabulary in reflection → specific goals in forethought → fine monitoring → better outcomes) or destructively (ability vocabulary in reflection → vague goals → coarse monitoring → poor outcomes → confirmed ability attribution).
