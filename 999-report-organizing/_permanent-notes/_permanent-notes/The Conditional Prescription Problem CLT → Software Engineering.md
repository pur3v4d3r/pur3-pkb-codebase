## Cross-Domain Connections

> [!cross-domain-connection] The Conditional Prescription Problem: CLT → Software Engineering
> In software development, abstraction layers, frameworks, and scaffolding tools accelerate novice developers by reducing the cognitive load of managing low-level details. The same scaffolding becomes an impediment for expert developers who need fine-grained control and whose expertise allows them to process the low-level details efficiently. The Rails developer who moves to systems programming finds the framework a constraint rather than a support — the expertise reversal effect operating in software. The structural principle: scaffolding that enables performance in early-competency stages generates dependency and constrains performance in expert stages. The prescriptions for when to add abstraction and when to drop to lower levels are strongly developer-expertise-indexed.
> *— [[cognitive-load-theory-dialectical-re-examination-2026-03-22_report]]*
