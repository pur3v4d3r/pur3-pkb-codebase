> Attribution retraining is a family of intervention techniques that deliberately redirect causal explanations from maladaptive dimensional coordinates (internal-stable-uncontrollable) to adaptive ones (internal-unstable-controllable), thereby altering expectancy, emotion, and behaviour. Effective retraining operates through a two-stage architecture (induction + consolidation), targets specific controllable factors rather than offering generic encouragement, and maintains internal locus to preserve agency. The mechanism is recursive: the reattribution shifts dimensional coordinates, which alters consequences, which produces new outcomes that are interpreted through the recalibrated framework. Attribution retraining belongs to the broader category of wise interventions — brief, precise, and disproportionately effective because it targets the interpretive mechanism rather than the informational substrate.
> *— [[attribution-theory-foundational-report-2026-04-19]]*

> Individual differences in working memory capacity, measured through complex span tasks, predict a wide range of higher cognitive outcomes but do not straightforwardly translate into trainable skills — working memory training shows robust near-transfer but limited far-transfer effects. Cowan's embedded-processes model offers the most influential alternative to Baddeley's framework, locating working memory in activated long-term memory plus a limited focus of attention rather than specialized subsystems. The competition between models is theoretically productive, with each framework capturing genuine phenomena; future unified theories will likely need to account for both modality-specific processing (Baddeley) and modality-independent attentional limits (Cowan).

> [!section-summary] Section 7 Summary
> The guidance controversy pits cognitive load theory's argument for explicit instruction against constructivism's argument for active discovery. The most defensible resolution is that optimal guidance is not a fixed property of instruction but a learner-expertise-task interaction: novices benefit most from explicit instruction and worked examples that manage cognitive load; experienced learners benefit from productive challenge and guided discovery that stretch schema development. Productive failure research (Kapur) demonstrates that pre-instruction problem-solving, even if unsuccessful, can significantly enhance subsequent learning from explicit instruction by activating prior knowledge and generating productive disequilibrium. The debate ultimately concerns sequencing and balance, not a categorical choice — effective instruction combines explicit knowledge delivery with scaffolded constructivist challenge, calibrated to learner development.
> *— [[constructivist-learning-theory-foundational-report-2026-04-03_report]]*

> [!section-summary] Section 7 Summary
> The levels of processing framework faces two fundamental theoretical challenges. The circularity objection holds that "depth" is defined partly by its outcomes, making the depth-memory relationship circular and potentially unfalsifiable. The transfer-appropriate processing (TAP) principle, demonstrated empirically by Morris et al. (1977), shows that "shallow" phonological processing can produce better memory than "deep" semantic processing when the retrieval test requires phonological matching — fundamentally challenging the claim that depth unconditionally predicts retention. TAP argues that memory performance depends on encoding–retrieval match, not absolute depth. Despite these challenges, the depth effect remains robust within a restricted scope: explicit episodic memory recall under standard semantic tests. The framework's heuristic value for educational design persists.
> *— [[levels-of-processing-theory-foundational-report-2026-04-07_report]]*
