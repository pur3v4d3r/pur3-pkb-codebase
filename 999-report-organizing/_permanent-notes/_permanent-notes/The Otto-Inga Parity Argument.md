## Core Explanation

> [!evidence] The Otto-Inga Parity Argument
> If a piece of information (a) is reliably accessible, (b) is automatically endorsed when accessed, (c) plays the same functional role in guiding behaviour as a biological memory trace would, then there is no principled reason to deny that it constitutes a belief — regardless of whether it is stored in neurons or in a notebook. The location of storage is cognitively irrelevant; the functional role is what counts.
> *— [[extended-mind-theory-foundational-report-2026-03-11_report]]*
