# The Parity Principle (Clark & Chalmers, 1998)

> [!definition] The Parity Principle (Clark & Chalmers, 1998)
> If, as we confront some task, a part of the world functions as a process which, were it done in the head, we would have no hesitation in recognising as part of the cognitive process, then that part of the world is (for that time) part of the cognitive process. The principle is explicitly functionalist in character: cognitive status is determined by causal-functional role, not by material constitution or spatial location. It does NOT entail that all external processes count as cognitive — only those meeting the functional equivalence criterion.

> [!evidence] The Parity Principle (Clark & Chalmers, 1998)
> The [[parity-principle]] states: if a process in the external world plays the same functional role in cognitive processing that an internal cognitive process would play, then the external process is rightfully classified as part of the cognitive system. Parity justifies classifying external resources as cognitive components by comparing their functional contribution to that of internal cognitive processes, without requiring internal or biological localization.
>
> **Boundary:** The principle is normative about classification, not necessarily about phenomenal experience. It does not claim that Otto "feels" like he's consulting his memory when he reads his notebook (phenomenologically, he probably does not), but that the functional role is equivalent. Critics (Adams & Aizawa; Rupert) contest whether functional equivalence is sufficient for cognitive extension.
>
