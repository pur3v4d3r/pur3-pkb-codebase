## Practical Implications

> [!example] Prompt Pattern 1: Explicit Prior Knowledge Signal
> At the start of every Foundational Report, include a section-level instruction that directs schema activation toward the specific relevant prior knowledge domains. This can be achieved by adding a structured preamble to the report generation prompt:
>
> *"Before developing any content, identify 2–3 knowledge structures the reader is most likely to already have that are relevant to [topic]. In Phase I, explicitly invite the reader to activate these structures with a concrete question or brief scenario. Name the structures specifically — do not use generic invitations like 'think about what you know.'"*
>
> **Example output this produces:**
> Rather than: *"Before reading, think about what you already know about memory."*
> The prompt produces: *"Before reading, take a moment to recall how you think about the difference between knowing how to ride a bicycle and knowing that Paris is in France. Hold that distinction in mind as you read — it maps directly onto the foundational architecture this report builds on."*
> *— [[advance-organizers-prior-knowledge-foundational-report-2026-03-11_report]]*
