## Core Explanation

> [!evidence] PKB Note Quality: Encoding-Retrieval Alignment
> Before saving a permanent note to the PKB, check:
> - [ ] Title and opening line use vocabulary likely to be active when this note will be needed
> - [ ] The note contains at least one concrete example drawn from an anticipated usage scenario
> - [ ] The note is linked to relevant problem types, not just to conceptually related notes
> - [ ] Any flashcard or SR anchor for this note tests in a format simulating likely retrieval demand
> - [ ] The note has been accessed via at least one active retrieval attempt (not just added)
> *— [[encoding-specificity-principle-tulving-foundational-report-2026-04-07_report]]*
