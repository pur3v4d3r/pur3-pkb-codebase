# Frontier Question: Can Instructional Systems Adapt in Real Time to the Learner's Element Interactivity?

> *Definition pending — derived from 2 source report(s).*

## Core Explanation

> [!evidence] Frontier Question: Can Instructional Systems Adapt in Real Time to the Learner's Element Interactivity?
> **The question:** Given that element interactivity is expertise-relative and changes dynamically as the learner acquires schemas, can technology-enhanced instruction adapt its scaffolding in real time — detecting when element interactivity exceeds capacity and providing support, then withdrawing support as schemas develop?
>
> **Current best understanding:** This is the holy grail of CLT-informed instructional technology. [[Adaptive-Instruction|Adaptive instruction]] based on CLT has been partially implemented in:
> - Intelligent tutoring systems that adjust worked example fading based on learner performance (proxy for element interactivity)
> - Systems that use response time and error patterns to estimate current learning state
> - Emerging systems that use physiological measures (eye tracking, skin conductance) as real-time load indicators
>
> **What we don't know:** How to bridge the gap between *detecting* that load is high (relatively doable via physiological or behavioral measures) and *diagnosing* the element interactivity structure (very difficult — knowing load is high doesn't tell you *which* elements are overloading). Without structural diagnosis, adaptive systems can only make crude adjustments (provide more scaffolding / remove scaffolding) rather than targeted interventions (support *these specific* element interactions).
>
> **Active research directions:** [[Sergei-Kalyuga|Kalyuga's]] rapid assessment methods — brief diagnostic tasks that estimate the learner's schema development for specific content — represent the most CLT-grounded approach to real-time adaptation. Machine learning approaches that model learner knowledge state from interaction patterns are an alternative that trades theoretical specificity for predictive power.
>
> **Predicted resolution timeline:** Crude adaptation (more/less scaffolding) is already possible. Targeted adaptation (supporting specific element interactions) is a decade or more away, contingent on progress on the measurement problem.
>
> **What would change if resolved:** Fully adaptive CLT-based instruction would personalize education to each learner's current schema development, automatically implementing faded worked examples, isolated-interacting sequencing, and expertise-responsive scaffolding. This is the ultimate practical application of element interactivity theory.
> *— [[cognitive-load-theory-deep-dive-2026-04-12_report]]*
