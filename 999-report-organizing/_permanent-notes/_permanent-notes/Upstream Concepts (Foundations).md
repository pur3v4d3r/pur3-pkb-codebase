## Cross-Domain Connections

> [!cross-domain-connection] Upstream Concepts (Foundations)
> These concepts directly underpin working memory theory and should be understood before full engagement with the model:
> - [[cognitive-psychology-core-concepts]] — Working memory is one cognitive psychology's central constructs; the field provides the theoretical vocabulary and methodology
> - [[information-processing-theory]] — The information processing metaphor (input, storage, transformation, output) provides the meta-framework within which working memory is defined
> - [[multi-store-model]] — Atkinson and Shiffrin's model is the immediate theoretical predecessor that Baddeley and Hitch challenged and replaced
> - [[short-term-memory]] — The concept working memory subsumed and reframed; understanding the limitations of the simple STM view motivates the multicomponent framework
> - [[selective-attention]] — Attention is the engine of the central executive; working memory and attention are increasingly understood as tightly integrated rather than separate systems
> - [[cognitive-architecture]] — Working memory occupies a specific place in the larger cognitive architecture; understanding the broader system contextualizes working memory's role
> - [[Miller's-Magical-Number-Seven]] — Miller's 1956 work established the capacity constraints on short-term processing that Baddeley's model refined and mechanistically explained
> *— [[baddeley-model-of-working-memory-foundational-report-2026-04-03_report]]*
