> [!diagram] The Forethought-Reflection Calibration Engine
> ```
> ┌─────────────────────────────────────────────────────────────┐
> │                    FORETHOUGHT PHASE                         │
> │                                                             │
> │  [Task Analysis]              [Motivational Beliefs]        │
> │  Goal Setting ──────────────► Self-Efficacy (calibrated)   │
> │  Strategic Planning          Goal Orientation (mastery)    │
> │       │                      Outcome Expectations          │
> │       │                              │                      │
> │       └──────────────────────────────┘                      │
> │                         │                                   │
> │                 PERFORMANCE PHASE                           │
> │                   (Reading Session)                         │
> │                         │                                   │
> │              SELF-REFLECTION PHASE                          │
> │                                                             │
> │  [Self-Judgment]              [Self-Reaction]               │
> │  Self-Evaluation ──────────► Self-Satisfaction/Affect      │
> │  (vs. comprehension          Adaptive Inference ──────┐    │
> │   criterion)                        OR                │    │
> │  Causal Attribution ─────► Defensive Inference        │    │
> │  (Controllable?)                                       │    │
> │                                                        │    │
> └────────────────────────────────────────────────────────│────┘
>                    FEEDBACK LOOP: Adaptive Inference ────┘
>                    → Updates → Next Forethought Phase
>                    → Builds → Calibrated Self-Efficacy
>                    → Refines → Strategic Planning
>
> CALIBRATION LOG tracks accuracy of comprehension predictions
> across cycles → METACOGNITIVE CALIBRATION emerges as output
> ```
> **Reading Guide:** The diagram shows the structural architecture of the Calibration Engine. The critical variable is the attribution decision in Self-Judgment: controllable attributions route to adaptive inferences, which feed forward to improve the next Forethought Phase. Uncontrollable attributions route to defensive inferences, which degrade the next Forethought Phase. The Calibration Log sits outside the cycle and tracks its accuracy over time.
> *— [[srl-forethought-self-reflection-pkb-focused-analysis-2026-03-24 (1)_report]]*
