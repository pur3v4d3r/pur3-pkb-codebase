# Extended Metacognition

> [!definition] Extended Metacognition
> [**Extended-Metacognition**:: The thesis that metacognitive monitoring and regulation can be distributed across biological and non-biological components of a coupled system. Under extended metacognition, a PKM system's structural features (wiki-links, tags, status markers) function as external monitoring devices, while its interface affordances (search, graph view, review prompts) function as external regulation mechanisms. The thesis rests on the assumption that what matters for metacognition is functional role, not substrate.]

> [!evidence] Extended Metacognition
> Extended metacognition is the thesis that metacognitive processes — monitoring, regulation, and evaluation of one's own cognitive activity — can be partially constituted by external artefacts and systems rather than wholly realised in neural tissue. On this view, a PKM system that reliably performs monitoring functions (e.g., identifying knowledge gaps through link analysis) and regulatory functions (e.g., scheduling review through spaced repetition) is not merely *supporting* metacognition but *participating* in it. The system is part of the metacognitive architecture.
>
> **Boundary:** Extended metacognition does not claim that all external tools are metacognitive extensions. The extension thesis requires functional integration — the external system must be reliably coupled with the cognitive system, readily accessible, and its outputs must be endorsed and used as the agent's own. A notebook sitting unused in a drawer is not an extension of anything.
>
