# Engram (Semon, 1904 / modern usage)

> [!definition] Engram (Semon, 1904 / modern usage)
> The stored memory trace — the physical or functional representation in the brain/memory system of a past experience. In Tulving's usage, the engram is the residue of encoding that persists between learning and retrieval. Ecphory is the process by which the cue activates the engram. Modern neuroscience has progressed toward identifying engrammic cells (see Tonegawa & Liu, 2019 on optogenetic engram studies).
>
> **Boundary:** "Engram" in casual usage sometimes conflates trace content with trace strength. The ESP's account treats the engram as a multi-attribute structure, not simply a strength value.
>
> **See also:** [[memory-consolidation]], [[hippocampus]], [[encoding-specificity-principle]]
