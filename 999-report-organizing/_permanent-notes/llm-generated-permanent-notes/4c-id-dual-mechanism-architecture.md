# 4C/ID Dual-Mechanism Architecture

> [!definition] 4C/ID Dual-Mechanism Architecture
> 4C/ID Dual-Mechanism Architecture is a framework in instructional design that distinguishes between schema construction for non-recurrent skill aspects and schema automation for recurrent ones, each served by different types of learning tasks and supportive information.
