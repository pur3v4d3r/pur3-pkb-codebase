# alan-baddeley

> [!definition] alan-baddeley
> - **Key-Term**: [[alan-baddeley]]
> - **Definition**: Alan Baddeley is a British psychologist known for his work on human memory, particularly the development of the working memory model which includes components such as the central executive and the phonological loop and visuospatial sketchpad.

## Core Explanation

> [!analytical-insight] Core Explanation
> Alan Baddeley's seminal contribution to cognitive psychology was the development of the working memory model in the late 20th century. This model posits that working memory is a limited-capacity system responsible for holding and manipulating information over short periods, with distinct components handling different types of information.

> [!analytical-insight] Explanation 2
> The central executive acts as the controller, directing attention and coordinating between the other components. The phonological loop deals primarily with verbal and auditory information, while the visuospatial sketchpad handles visual and spatial data. These components work together to enable tasks such as reading comprehension, problem-solving, and planning.

> [!analytical-insight] Explanation 3
> Key nuances include the recognition that working memory is not a single entity but a complex system of interacting parts, each specialized for different types of information processing.

> [!example] Application
