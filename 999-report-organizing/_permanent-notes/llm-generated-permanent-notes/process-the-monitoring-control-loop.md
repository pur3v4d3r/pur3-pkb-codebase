# Process: The Monitoring–Control Loop

> [!definition] Process: The Monitoring–Control Loop
> A cognitive architecture involving two functional levels — an object level performing a task and a meta level observing it — with information flows for monitoring (object to meta) and control (meta to object).

## Flashcards

> [!flashcard] Process: The Monitoring–Control Loop
> **Q:** Describe the structure of the Nelson–Narens monitoring–control loop and how it applies to reading.
> **A:** The framework distinguishes two functional levels — the *object level* performing the cognitive task and the *meta level* observing it — with two information flows between them: monitoring (object → meta) and control (meta → object). Applied to reading, comprehension processes operate at the object level while metacognitive processes operate at the meta level, with monitoring providing signals about comprehension state and control providing regulatory action when monitoring detects breakdown.
