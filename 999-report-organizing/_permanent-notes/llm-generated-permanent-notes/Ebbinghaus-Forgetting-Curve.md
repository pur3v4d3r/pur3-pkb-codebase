# Ebbinghaus-Forgetting-Curve

> [!definition] Ebbinghaus-Forgetting-Curve
> - **Key-Term**: [[Ebbinghaus-Forgetting-Curve]]
> - **Definition**: The Ebbinghaus-forgetting-curve is a model that describes the exponential decay of memory retention over time, named after Hermann Ebbinghaus who first studied it in the late 19th century.
> - **Domain**: other
> - **Status**: 🌱 budding | Confidence: speculative

## Core Explanation

> [!analytical-insight] Core Explanation
> The curve illustrates how information is lost over time when there is no attempt to retain it. It shows that forgetting is rapid immediately after learning but slows down as time progresses.

> [!analytical-insight] Explanation 2
> Ebbinghaus conducted experiments using nonsense syllables and found that the rate of forgetting followed a predictable pattern, which he plotted on a graph showing the decline in memory retention over days, weeks, and months.

> [!analytical-insight] Explanation 3
> The curve has been used to support various educational strategies such as spaced repetition and review sessions.

## Practical Implications

> [!example] Application
> Educators can use this concept to design effective study schedules that include regular reviews of material to enhance long-term retention.

> [!example] Application
> In clinical education, understanding the forgetting curve helps in planning continuous professional development programs for healthcare professionals.
