# Schema Construction Through Progressive Linking

> [!definition] Schema Construction Through Progressive Linking
> Schema Construction Through Progressive Linking is a cognitive strategy where knowledge is organized into a structured network by iteratively adding and connecting new information to an existing set of related ideas.

## Examples

> [!example] Schema Construction Through Progressive Linking
> Consider a practitioner building understanding of [[metacognition|metacognition]] through PKB practice. The initial note might define the concept and link it to one or two related ideas. Over weeks and months of sustained engagement, the practitioner creates additional notes on [[metacognitive-knowledge|metacognitive knowledge]], [[metacognitive-monitoring|metacognitive monitoring]], [[metacognitive-regulation|metacognitive regulation]], the [[nelson-narens-model|Nelson-Narens model]], [[Metacognitive Scaffolding|metacognitive scaffolding]], and the relationship between metacognition and [[self-regulated-learning|self-regulated learning]]. Each new note, linked to existing ones, adds structural complexity to the emerging knowledge graph. The graph that results is an externalized schema — a visible, navigable representation of the knowledge organization that supports expert thinking about metacognition. Crucially, the process of constructing this graph is itself a schema construction process: the cognitive act of deciding where each new note fits, what it connects to, and how it relates to existing understanding is precisely the elaborative, integrative processing that builds schemas in long-term memory.
