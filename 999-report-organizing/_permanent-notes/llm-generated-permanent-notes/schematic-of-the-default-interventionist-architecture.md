# Schematic of the Default-Interventionist Architecture

> [!definition] Schematic of the Default-Interventionist Architecture
> A cognitive architecture depicting a dual-process system where default responses generated by Type 1 processing are endorsed unless triggered conditions necessitate more deliberate Type 2 processing.
