# Checklist: PKM System Design Audit (Seven-Problem Framework)

> [!definition] Checklist: PKM System Design Audit (Seven-Problem Framework)
> A structured audit framework for evaluating the design of a Personal Knowledge Management (PKM) system against seven key dimensions: encoding, organization, retrieval, regulation, motivation, cognitive load, and their respective sub-factors.

## Core Explanation

> [!evidence] Checklist: PKM System Design Audit (Seven-Problem Framework)
> **Encoding:**
> - [ ] System requires elaboration at note creation (not just capture)
> - [ ] Templates prompt connection to existing knowledge
> - [ ] Deep encoding is the path of least resistance
>
> **Organization:**
> - [ ] Bidirectional linking is the primary organizational mechanism
> - [ ] Graph visualization is available and used
> - [ ] Orphan notes are systematically detected and linked
>
> **Retrieval:**
> - [ ] Spaced repetition or equivalent review system is integrated
> - [ ] Self-testing is embedded in review workflows
> - [ ] Retrieval is treated as a learning event, not just an access operation
>
> **Regulation:**
> - [ ] Metacognitive monitoring tools are available (dashboards, metrics)
> - [ ] Knowledge state is visible to the practitioner
> - [ ] SRL cycle (plan → execute → reflect) is supported by system design
>
> **Motivation:**
> - [ ] Practitioner has genuine choice in system design and workflow
> - [ ] Progress is visible (streaks, metrics, growth indicators)
> - [ ] Habit-supporting structures exist (consistent cues, implementation intentions)
>
> **Cognitive Load:**
> - [ ] Template complexity is justified by germane processing benefit
> - [ ] Plugin count is minimized to essentials
> - [ ] Workflow steps do not impose unnecessary decision points
> *— [[pkb-pkm-planning-and-cognitive-science-foundational-report-2026-04-18]]*
