# The Translation Window Diagnostic

> [!definition] The Translation Window Diagnostic
> The Translation Window Diagnostic is a framework used to assess whether a motivational theory can effectively guide goal-setting activities without ethical compromise and ensure that measurements adequately capture multi-dimensional aspects necessary for future pursuit capacity.

## Additional Material

> [!diagram] The Translation Window Diagnostic
> ```
>     ┌────────────────────────────────────────────────────┐
>     │           THE TRANSLATION WINDOW                   │
>     │                                                    │
>     │   Open when ALL FOUR conditions hold:              │
>     │                                                    │
>     │   ┌──────────────────┐  ┌──────────────────┐       │
>     │   │ Proxy Fidelity   │  │ Honest           │       │
>     │   │ (goal activities │  │ Attainability    │       │
>     │   │ = valued         │  │ (feasible w/o    │       │
>     │   │ activities)      │  │ ethical          │       │
>     │   │                  │  │ compromise)      │       │
>     │   └──────────────────┘  └──────────────────┘       │
>     │                                                    │
>     │   ┌──────────────────┐  ┌──────────────────┐       │
>     │   │ Measurement      │  │ Failure          │       │
>     │   │ Adequacy         │  │ Tolerance        │       │
