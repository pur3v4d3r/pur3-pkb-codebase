# PKB Architecture Cognitive Load Audit

> [!definition] PKB Architecture Cognitive Load Audit
> PKB Architecture Cognitive Load Audit is a systematic evaluation to identify and mitigate extraneous cognitive load in Personal Knowledge Base workflows by assessing navigation complexity, template efficiency, tool usage, workflow management steps, and alignment with practitioner expertise.

## Core Explanation

> [!evidence] PKB Architecture Cognitive Load Audit
> **Purpose:** Identify and reduce extraneous cognitive load in current PKB workflows.
>
> - [ ] **Navigation audit:** Can any note in the vault be reached within 3 clicks from a relevant MOC? If not, navigational complexity is imposing extraneous load.
> - [ ] **Template audit:** Do current templates require cognitive effort on formatting/metadata that could be automated? If so, template overhead is consuming germane processing capacity.
> - [ ] **Tool audit:** How many different tools/plugins/windows must be active simultaneously during a typical note-making session? Each additional tool imposes split-attention effects.
> - [ ] **Workflow audit:** Does the current workflow include steps that manage the system rather than process knowledge? Each system-management step is a candidate for automation or elimination.
> - [ ] **Expertise check:** Are current templates and constraints appropriate for the practitioner's current expertise level, or do they impose guidance that the practitioner has outgrown (expertise reversal)?
