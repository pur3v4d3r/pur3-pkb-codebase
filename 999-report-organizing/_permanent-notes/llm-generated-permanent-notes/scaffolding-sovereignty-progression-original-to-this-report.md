# Scaffolding-Sovereignty Progression (Original to This Report)

> [!definition] Scaffolding-Sovereignty Progression (Original to This Report)
> A five-phase developmental framework integrating constructs from Vygotsky, Zimmerman, SDT, and heutagogy to describe how curriculum transforms dependent learners into self-directed ones: (1) Guided Dependence, (2) Structured Exploration, (3) Negotiated Autonomy, (4) Supported Independence, (5) Autonomous Sovereignty. The progression is recursive and domain-specific.
>
> **Boundary:** This is an integrative synthesis, not an empirically validated stage model. The five phases describe a design orientation rather than a fixed developmental sequence.
>
> **Report-Specific Significance:** The first original contribution of this report, providing a unified framework for the structural dimension of curriculum design for self-direction.
>
> **See also:** [[zone-of-proximal-development]], [[self-regulated-learning]], [[heutagogy]], [[self-determination-theory]]
