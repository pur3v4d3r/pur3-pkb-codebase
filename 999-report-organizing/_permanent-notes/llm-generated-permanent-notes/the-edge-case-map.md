# The Edge Case Map

> [!definition] The Edge Case Map
> The Edge Case Map illustrates scenarios that deviate from standard conditions in self-determination theory, highlighting unusual or extreme situations such as controlled internalization and autonomous regulation of harm.

## Additional Material

> [!diagram] The Edge Case Map
> ```
>     STANDARD MODEL HOLDS       │     STANDARD MODEL STRAINS
>     ─────────────────────────  │  ─────────────────────────
>     Substrate-surface aligned  │  Controlled internalization
>     Post-reflective populations│  Identification w/o integration
>     Content-neutral behaviors  │  Autonomous regulation of harm
>     Slow human socialization   │  Cross-cultural autonomy issues
