# SDL-SRL Grain-Size Continuum

> [!definition] SDL-SRL Grain-Size Continuum
> SDL-SRL Grain-Size Continuum is a conceptual framework that illustrates the progression from fine-grained self-regulated learning (SRL) strategies within specific tasks to coarser-grained lifelong self-directed learning (SDL) practices and heutagogy, emphasizing monitoring, resource selection, and epistemic reconstruction.
