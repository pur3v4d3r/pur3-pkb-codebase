# Process: How Monitoring Drives Control

> [!definition] Process: How Monitoring Drives Control
> Process: How Monitoring Drives Control refers to the mechanism by which the accuracy of monitoring directly influences the effectiveness of control decisions, particularly in cognitive tasks like studying, where inaccurate monitoring can lead to premature termination of study sessions due to overconfidence.

## Flashcards

> [!flashcard] Process: How Monitoring Drives Control
> **Q:** Describe the mechanism by which inaccurate monitoring leads to maladaptive study behavior.
> **A:** The monitoring-control coupling means control decisions are only as good as the monitoring that informs them. When the fluency illusion inflates JOLs, the meta-level's model indicates the material is well-learned → the discrepancy between current state and goal state appears small → study time allocation is reduced → study is terminated prematurely → the learner discovers the error only upon failed retrieval.
