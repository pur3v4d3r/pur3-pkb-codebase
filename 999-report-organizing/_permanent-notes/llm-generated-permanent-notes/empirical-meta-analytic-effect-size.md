# Empirical: Meta-Analytic Effect Size

> [!definition] Empirical: Meta-Analytic Effect Size
> Empirical: Meta-Analytic Effect Size refers to a quantitative synthesis of effect sizes derived from multiple studies, providing an aggregate measure of the magnitude of an observed phenomenon.

## Flashcards

> [!flashcard] Empirical: Meta-Analytic Effect Size
> **Q:** What is the average effect size of implementation intentions on behavior change reported in the Gollwitzer & Sheeran (2006) meta-analysis?
> **A:** Cohen's d = 0.65, considered medium-to-large in the social sciences. This estimate is based on 94 studies across multiple behavioral domains.
