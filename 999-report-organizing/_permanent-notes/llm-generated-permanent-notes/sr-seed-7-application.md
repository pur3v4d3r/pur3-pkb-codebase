# SR Seed 7 — Application

> [!definition] SR Seed 7 — Application
> SR Seed 7 — Application refers to the implementation of a PKB template that includes fields for predicting comprehension and self-testing results, used to train calibration accuracy through comparison and reflection.

## Flashcards

> [!flashcard] SR Seed 7 — Application
> **Q:** How can a PKB template train calibration accuracy?
> **A:** Include a "Predicted Comprehension %" field in forethought templates and a "Self-Test Result %" field in reflection templates. Compare prediction to outcome to calculate calibration error. Track errors over time to identify systematic biases (e.g., chronic overconfidence). Adjust prediction strategies based on identified patterns.
