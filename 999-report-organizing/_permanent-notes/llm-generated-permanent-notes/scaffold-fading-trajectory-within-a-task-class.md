# Scaffold-Fading Trajectory Within a Task Class

> [!definition] Scaffold-Fading Trajectory Within a Task Class
> Scaffold-Fading Trajectory Within a Task Class is a sequence of tasks where initial problems are fully guided (worked examples), gradually reducing guidance (completion tasks with increasing gaps) until learners perform independently on conventional tasks.

## Additional Material

> [!diagram] Scaffold-Fading Trajectory Within a Task Class
> ```
>     Task Class N (Complexity Level N)
>     ─────────────────────────────────────────────────
>
>     Scaffold Level:   HIGH ████████████░░░░░░░░░░ LOW
>
>     Task 1:  [WORKED EXAMPLE]        ← Full solution provided
>              Learner: Study + Self-explain
>
>     Task 2:  [COMPLETION TASK]       ← Partial solution
>              Learner: Complete the gaps
>
>     Task 3:  [COMPLETION TASK]       ← Larger gaps
>              Learner: Complete more independently
>
>     Task 4:  [CONVENTIONAL TASK]     ← No scaffolding
>              Learner: Full independent performance
>
>     ─────────────────────────────────────────────────
>     → ADVANCE to Task Class N+1 (higher complexity)
> ```
