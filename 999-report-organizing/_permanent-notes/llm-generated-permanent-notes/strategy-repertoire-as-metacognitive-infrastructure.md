# Strategy Repertoire as Metacognitive Infrastructure

> [!definition] Strategy Repertoire as Metacognitive Infrastructure
> Strategy Repertoire as Metacognitive Infrastructure refers to a curated set of learning strategies within a Personal Knowledge Base that serves as externalized conditional metacognitive knowledge, enabling learners to select appropriate strategies based on monitoring feedback.

## Reflections

> [!claude-insight] Strategy Repertoire as Metacognitive Infrastructure
> The capacity for strategic adjustment presupposes a strategy repertoire — a set of alternative approaches from which the learner can select. A learner who knows only one study strategy (e.g., rereading) cannot adjust strategically even if monitoring accurately detects that rereading is failing. PKB systems can scaffold [[learning-strategy-selection|learning strategy selection]] by maintaining a living reference note that catalogues [[evidence-based-learning-strategies|evidence-based learning strategies]], their optimal use conditions, and their limitations. When a mid-session check-in reveals a strategy mismatch, the learner can consult this reference to select an alternative. The reference note functions as externalised conditional metacognitive knowledge — knowledge about *when* and *why* to deploy particular strategies — that might otherwise remain inert.
