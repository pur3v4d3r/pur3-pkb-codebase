# Organizational Architecture in Practice

> [!definition] Organizational Architecture in Practice
> Organizational Architecture in Practice refers to the structure and organization of knowledge within a Personal Knowledge Management (PKM) system, determining how notes and information are categorized and linked for efficient retrieval and application.

## Examples

> [!example] Organizational Architecture in Practice
> Consider a PKM system in which a note on [[Cognitive Load Theory (CLT)|cognitive load theory]] is created. In a folder-based system, the practitioner must decide: does this note belong in "Cognitive Science," "Learning Theory," "Instructional Design," or "PKM Design Principles"? The note can live in only one location, and retrieval from the other three contexts requires remembering where it was filed. In a link-based system, the same note is connected to `[[schema-theory-and-knowledge-organization]]` (because CLT depends on schemas), `[[working-memory]]` (because CLT models WM constraints), `[[instructional-design]]` (because CLT informs design), and `[[Cognitive Load Theory (CLT)]]` (because CLT constrains PKB architecture). The note is retrievable from any of these pathways — just as the concept "cognitive load theory" in a well-developed schema network is retrievable from any of its associated contexts.
