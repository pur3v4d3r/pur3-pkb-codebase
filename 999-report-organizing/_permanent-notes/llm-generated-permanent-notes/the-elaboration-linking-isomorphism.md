# The Elaboration–Linking Isomorphism

> [!definition] The Elaboration–Linking Isomorphism
> The Elaboration–Linking Isomorphism refers to the structural parallel between elaborative encoding in cognitive science and the practice of creating wiki-links in Personal Knowledge Base (PKB) systems, where each link represents a cognitive connection that strengthens memory traces.

## Reflections

> [!claude-insight] The Elaboration–Linking Isomorphism
> A structural parallel emerges between elaborative encoding in cognitive science and wiki-linking in PKB practice that deserves explicit articulation. When a practitioner creates a wiki-link between a new note and an existing permanent note, the cognitive act required — identifying the relationship, assessing its nature, selecting the appropriate target — constitutes a form of elaborative interrogation. The link itself is not merely an organizational convenience; it is the visible trace of an elaborative encoding event, an externalized record of the cognitive connection that strengthens both the new and the existing memory traces. PKB architectures that encourage dense, meaningful linking are, in effect, architectures that mandate elaborative encoding at every point of knowledge integration.
