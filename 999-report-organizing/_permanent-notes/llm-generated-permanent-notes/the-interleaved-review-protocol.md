# The Interleaved Review Protocol

> [!definition] The Interleaved Review Protocol
> The Interleaved Review Protocol involves reviewing notes from various domains in a mixed order, attempting to recall each note's content before reading it, then synthesizing insights across reviewed notes.

## Additional Material

> [!protocol] The Interleaved Review Protocol
> **Purpose:** Implement interleaved retrieval practice during PKB review sessions.
>
> **Steps:**
> 1. **Select 5-7 notes** from different domains/topics (interleaving, not blocking by category).
> 2. For each note, **read only the title**. Attempt to recall the core argument, key connections, and significance before reading the note content (retrieval practice).
> 3. **Read the note.** Compare recalled content to actual content. Identify gaps (metacognitive monitoring).
> 4. After reviewing all notes, **write a brief synthesis note** connecting insights across the reviewed notes (far transfer, elaboration).
> 5. **Update review metadata** to reflect which notes need additional processing.
