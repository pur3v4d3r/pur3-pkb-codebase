# Michael Bratman (Stanford University)

> [!definition] Michael Bratman (Stanford University)
> Michael Bratman is an American philosopher known for his work on intention as a planning state with stability, settledness, and downstream commitment-organizing functions, which provides the philosophical foundation for understanding implementation intentions.

## Additional Material

> [!person] Michael Bratman (Stanford University)
> The American philosopher whose *Intention, Plans, and Practical Reason* (1987) developed the philosophical theory of intention as a planning state with stability, settledness, and downstream commitment-organizing functions. Bratman's planning theory provides the philosophical foundation against which implementation intentions can be understood as a specific psychological mechanism that exploits the structural features Bratman identified at the philosophical level.
