# The Four-Source Integration Architecture

> [!definition] The Four-Source Integration Architecture
> The Four-Source Integration Architecture is a model in social-cognitive psychology that describes how cognitive processing operations integrate information from enactive mastery, vicarious experiences, verbal persuasion, and physiological/affective states, with source weighting influenced by task difficulty perception, effort and assistance interpretation, source credibility, and convergence across sources.
