# Learning Task (van Merriënboer & Kirschner, 2018)

> [!definition] Learning Task (van Merriënboer & Kirschner, 2018)
> Authentic whole-task experiences organized into task classes of increasing complexity, forming the backbone of a 4C/ID training blueprint. Each learning task requires learners to integrate and coordinate all constituent skills of the target complex skill. Within each task class, scaffolding (via worked examples, completion tasks, and conventional tasks) is faded from high support to full independence.
>
> **Boundary:** Learning tasks are not exercises that isolate individual skill components. Their defining characteristic is the integration of multiple skill elements within a single performance context, even when scaffolding reduces the cognitive demand.
>
> **Report-Specific Significance:** Learning tasks constitute the first and most architecturally central of the four components, serving as the primary vehicle for both schema construction and performance integration.
>
> **See also:** [[Cognitive Scaffolding]], [[the-worked-example-effect]], [[faded-worked-example]], [[Completion-Problem-Effect]]
