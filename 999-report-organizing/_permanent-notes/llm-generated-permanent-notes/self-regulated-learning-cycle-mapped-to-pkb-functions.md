# Self-Regulated Learning Cycle Mapped to PKB Functions

> [!definition] Self-Regulated Learning Cycle Mapped to PKB Functions
> Self-Regulated Learning Cycle Mapped to PKB Functions is a framework that aligns the stages of self-regulated learning—forethought, performance, and reflection—with specific Personal Knowledge Base (PKB) functions such as project notes, learning goals, strategy documents, note-making, wiki-linking, retrieval reviews, status tracking, and progress metrics.
