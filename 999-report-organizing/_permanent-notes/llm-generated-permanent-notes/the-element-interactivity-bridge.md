# The Element-Interactivity Bridge

> [!definition] The Element-Interactivity Bridge
> The Element-Interactivity Bridge refers to the principle that complex learning tasks cannot be simplified by breaking them into less interactive sub-tasks, as integration remains inherently demanding and should be practiced holistically.

## Reflections

> [!claude-insight] The Element-Interactivity Bridge
> Element interactivity functions as the conceptual linchpin connecting cognitive load theory to instructional design for complex learning. It explains why complex learning cannot be simplified by decomposition — breaking a high element-interactivity task into low element-interactivity sub-tasks does not reduce the total processing demand, it merely defers the integration challenge to a later point when the learner must coordinate skills that were learned in isolation. The 4C/ID model's insistence on whole-task practice from the beginning is a direct response to this insight: if integration is inherently effortful, that effort must be distributed across the learning process rather than concentrated at the end.
