# Distinction: Goal Intention vs. Implementation Intention

> [!definition] Distinction: Goal Intention vs. Implementation Intention
> Goal intentions indicate what one intends to achieve, while implementation intentions specify when, where, and how one plans to enact those goals.

## Flashcards

> [!flashcard] Distinction: Goal Intention vs. Implementation Intention
> **Q:** What is the central distinction between goal intentions and implementation intentions?
> **A:** Goal intentions specify *what* the actor wants to achieve ("I intend to achieve Z"); implementation intentions specify *when, where, and how* the corresponding behavior will be enacted ("when X, I will Y"). Goal intentions alone weakly predict behavior; implementation intentions amplify behavioral enactment of endorsed goals.
