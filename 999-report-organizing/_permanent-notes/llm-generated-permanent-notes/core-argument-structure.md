# Core Argument Structure

> [!definition] Core Argument Structure
> Core Argument Structure refers to the central thesis that a Personal Knowledge Base (PKB) is an extension of cognitive architecture, not merely a tool, integrating encoding, consolidation, organization, and metacognitive governance to address cognitive load constraints.
