# Claude's perspective on the reorganization

> [!definition] Claude's perspective on the reorganization
> Claude's perspective on the reorganization refers to the transformation in Cognitive Load Theory (CLT) from viewing intrinsic load as a fixed category to considering it as a variable related to element interactivity, which allows for deeper analysis and measurement of CLT effects.

## Reflections

> [!claude-insight] Claude's perspective on the reorganization
> The shift from "intrinsic load is given" (early CLT) to "intrinsic load is element interactivity for the current learner" (modern CLT) is one of the more theoretically generative moves in the recent history of [[educational-psychology]], because it transforms a *category* into a *variable*. Once intrinsic load is a variable that can be analyzed, decomposed, and (in principle) measured, every CLT effect can be reread through it: the [[the-worked-example-effect]] becomes a strategy for managing element interactivity by externalizing the relational structure; the [[isolated-elements]] effect becomes the explicit acknowledgment that high-interactivity material can be temporarily *de-interactified* by presenting elements serially before requiring their integration; the [[Expertise Reversal Effect (Kalyuga, Ayres, Chandler, Sweller, 2003)]] becomes the consequence of the fact that element interactivity itself drops as schemas form. The reorganization is not cosmetic — it changes what counts as a CLT explanation.
