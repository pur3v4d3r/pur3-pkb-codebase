# Pause and Construct

> [!definition] Pause and Construct
> Pause and Construct involves taking a moment to actively engage in the creation or visualization of relationships among concepts, such as drawing diagrams, which enhances understanding by focusing germane processing.

## Additional Material

> [!active-reading] Pause and Construct
> Before proceeding, attempt to draw a simple diagram showing the relationship among the three load types, working memory capacity, and element interactivity. Where does schema automation fit? Where does the [[Expertise Reversal Effect (Kalyuga, Ayres, Chandler, Sweller, 2003)]] enter? The effort of constructing this diagram — rather than merely reading about the relationships — engages precisely the germane processing that CLT describes.
