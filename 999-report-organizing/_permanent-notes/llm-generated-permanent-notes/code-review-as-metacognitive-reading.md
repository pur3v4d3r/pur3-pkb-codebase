# Code Review as Metacognitive Reading

> [!definition] Code Review as Metacognitive Reading
> Code Review as Metacognitive Reading involves evaluating code based on one's confidence in its correctness, which can lead to overconfidence; thus, it benefits from external verification through test execution or peer review.

## Core Explanation

> [!evidence] Code Review as Metacognitive Reading
> The transferable structural principle is that any reading-like assessment in which the reader's confidence is the gating signal for whether to take action will be vulnerable to fluency-induced overconfidence and will benefit from the substitution of external verification (test execution, hand-tracing, peer review) for internal feeling-of-correctness. The boundary condition is that the external verification must actually be *implemented* in the practice; reviewers who possess the principle but never run the tests gain little benefit from possession alone.
