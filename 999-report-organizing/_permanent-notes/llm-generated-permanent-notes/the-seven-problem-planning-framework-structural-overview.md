# The Seven-Problem Planning Framework — Structural Overview

> [!definition] The Seven-Problem Planning Framework — Structural Overview
> The Seven-Problem Planning Framework is a cognitive planning model that structurally organizes problems into content (encoding, organizing), process (retrieval, regulation), and sustaining (motivation) categories, with an integrative seventh problem for convergent design under the constraints of cognitive load theory.
