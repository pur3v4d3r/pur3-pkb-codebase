# The Cyclical Feedback Architecture as Learning Engine

> [!definition] The Cyclical Feedback Architecture as Learning Engine
> A cyclical feedback architecture as a learning engine refers to the iterative process where forethought, performance, self-reflection, and adaptive inferences create a continuous loop that enhances learning over time.

## Core Explanation

> [!evidence] The Cyclical Feedback Architecture as Learning Engine
> The power of Zimmerman's model lies not in any individual phase but in the **cyclical feedback architecture** connecting them. Forethought generates predictions and plans; performance tests those predictions against reality; self-reflection evaluates the gap between prediction and outcome; and the resulting adaptive inferences feed back into the next forethought phase. It is this feedback loop — not any single regulatory act — that drives learning over time. PKB scaffolding is effective to the degree that it preserves and strengthens this cyclical feedback structure rather than fragmenting it into disconnected activities.
