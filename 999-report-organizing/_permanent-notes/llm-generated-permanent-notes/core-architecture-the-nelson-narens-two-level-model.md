# Core Architecture: The Nelson-Narens Two-Level Model

> [!definition] Core Architecture: The Nelson-Narens Two-Level Model
> Core Architecture: The Nelson-Narens Two-Level Model is a metacognitive framework comprising a meta-level that dynamically models object-level state based on cues, and an object-level responsible for encoding and retrieval processes, where the meta-level can influence but not be influenced by the object-level.
