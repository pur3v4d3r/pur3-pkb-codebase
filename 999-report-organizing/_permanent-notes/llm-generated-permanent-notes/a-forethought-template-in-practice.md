# A Forethought Template in Practice

> [!definition] A Forethought Template in Practice
> A Forethought Template in Practice is a structured format used before engaging with study material to set learning objectives, estimate difficulty, select strategies, allocate time, and predict comprehension, facilitating metacognitive calibration.

## Examples

> [!example] A Forethought Template in Practice
> Consider a PKB study session template with the following fields:
>
> ```
> ## Study Session: {{date}}
> ### Forethought
> - **Topic:** [specific topic or chapter]
> - **Learning Objective:** [what I will be able to do after this session]
> - **Difficulty Estimate:** [1-5 scale + brief justification]
> - **Strategy Selection:** [active recall / elaborative interrogation / self-explanation / worked examples]
> - **Time Allocation:** [minutes] — adjusted for difficulty estimate
> - **Predicted Comprehension:** [% — to be compared post-session]
> ```
>
> The "Predicted Comprehension" field is a particularly potent scaffolding move. By forcing a pre-study prediction, the template creates a concrete standard against which post-study comprehension can be calibrated. This transforms the self-reflection phase from vague self-assessment ("I think I understood most of it") into quantitative calibration ("I predicted 80% comprehension and achieved 55% on self-testing — I was overconfident by 25 percentage points").
