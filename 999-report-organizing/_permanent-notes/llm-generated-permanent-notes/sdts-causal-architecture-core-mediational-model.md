# SDT's Causal Architecture — Core Mediational Model

> [!definition] SDT's Causal Architecture — Core Mediational Model
> SDT's Causal Architecture — Core Mediational Model illustrates how social-environmental conditions influence basic psychological needs (autonomy, competence, relatedness), which in turn affect motivation quality and ultimately lead to various outcomes such as well-being or ill-being.
