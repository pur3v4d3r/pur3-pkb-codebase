# The Attributional Bridge (Original to this report)

> [!definition] The Attributional Bridge (Original to this report)
> The conceptual positioning of attribution as the interpretive layer through which the constructs of other motivational theories (self-efficacy, self-determination, implicit theories) acquire their specific psychological content. Attribution provides the mechanism by which raw experience is converted into motivationally significant causal narratives.
>
> **Boundary:** This is an integrative conceptualisation, not a new empirical claim. It synthesises existing relationships between attribution and other theories into an architectural metaphor.
>
> **See also:** [[the-attributional-bridge — Attribution as the Interpretive Layer]], [[self-determination-theory]], [[self-efficacy-theory]], [[growth-mindset]]
