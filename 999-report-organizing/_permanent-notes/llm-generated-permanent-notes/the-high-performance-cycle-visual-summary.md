# The High Performance Cycle — Visual Summary

> [!definition] The High Performance Cycle — Visual Summary
> A visual summary depicting a cyclical process where setting specific, difficult, and accepted goals, combined with adequate moderators, leads to performance improvements through four mediating mechanisms (directive, energizing, persistence, strategic), resulting in intrinsic and extrinsic rewards that enhance satisfaction and internal attribution, ultimately leading to renewed or strengthened commitment for the next cycle.

## Additional Material

> [!diagram] The High Performance Cycle — Visual Summary
> ```
>             ┌──────────────────────────────────────────┐
>             │ Specific, Difficult, Accepted Goal       │

>                              │

>             │ Four Mediating Mechanisms                │
>             │   1. Directive (attention)               │

>             │   3. Persistence (over time)             │
>             │   4. Strategic (planning/discovery)      │
>             └────────────────┬─────────────────────────┘
>                              │
>                              ▼

>                              ▼

>             │ Intrinsic + Extrinsic Rewards            │

>                              │
>                              ▼
>             ┌──────────────────────────────────────────┐
