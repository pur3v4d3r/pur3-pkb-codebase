# Grow's Stage Diagnostic Checklist

> [!definition] Grow's Stage Diagnostic Checklist
> Grow's Stage Diagnostic Checklist is a tool used to evaluate an individual's current stage in self-directed learning across four stages: Dependent, Interested, Involved, and Self-Directed.

## Core Explanation

> [!evidence] Grow's Stage Diagnostic Checklist
> Use this checklist to assess your current stage in a specific learning domain:
>
> **Stage 1 (Dependent):** ☐ I need clear step-by-step instructions ☐ I feel anxious without teacher guidance ☐ I don't know what I don't know
>
> **Stage 2 (Interested):** ☐ I'm enthusiastic but need structure ☐ I can set goals within a framework ☐ I respond well to encouragement
>
> **Stage 3 (Involved):** ☐ I can learn independently with occasional guidance ☐ I can evaluate multiple resources ☐ I see the teacher as a facilitator
>
> **Stage 4 (Self-Directed):** ☐ I set my own learning objectives ☐ I evaluate my own progress ☐ I seek consultation only when I choose to
> *— [[self-directed-learning-foundational-report-2026-04-19]]*
