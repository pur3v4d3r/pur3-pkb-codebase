# CLT as the Unifying Diagnostic for PKB Design Failures

> [!definition] CLT as the Unifying Diagnostic for PKB Design Failures
> CLT as the Unifying Diagnostic for PKB Design Failures refers to applying Cognitive Load Theory (CLT) to systematically identify and address common frustrations in Personal Knowledge Base (PKB) design, such as complexity, navigational difficulty, and inefficient workflows.

## Reflections

> [!claude-insight] CLT as the Unifying Diagnostic for PKB Design Failures
> Many commonly reported PKB frustrations — the note that is "too complex to understand when reviewed later," the knowledge graph that feels "overwhelming to navigate," the workflow that "takes too long and produces too little" — can be systematically diagnosed through CLT's three-load framework. The complex note likely imposes intrinsic overload because it attempts to address multiple high-interactivity concepts without adequate decomposition into atomic components. The overwhelming graph generates extraneous load through its navigational demands. The unproductive workflow suffers from extraneous load in its process mechanics that leaves insufficient capacity for germane processing. CLT does not merely explain these failures; it prescribes their remedies: decompose complexity ([[atomic-note|atomic notes]]), simplify navigation (clear hierarchies, effective MOCs), and automate workflow mechanics (templates, keyboard shortcuts, habituated routines).
