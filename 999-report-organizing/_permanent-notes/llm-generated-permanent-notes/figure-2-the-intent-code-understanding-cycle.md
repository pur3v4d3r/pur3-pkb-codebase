# Figure 2: The Intent-Code-Understanding Cycle

> [!definition] Figure 2: The Intent-Code-Understanding Cycle
> The Intent-Code-Understanding Cycle is a process where developers formulate their intentions in natural language, Copilot generates code suggestions, developers encounter unfamiliar constructs, develop understanding through explanation or documentation, and modify the code with critical learning moments, repeating the cycle to expand knowledge.
