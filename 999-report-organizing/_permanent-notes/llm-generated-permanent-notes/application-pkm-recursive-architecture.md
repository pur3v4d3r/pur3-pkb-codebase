# Application: PKM Recursive Architecture

> [!definition] Application: PKM Recursive Architecture
> A recursive application of implementation intentions in personal knowledge management, where each completed action serves as a cue for the next intended behavior, facilitating automaticity and reducing reliance on willpower.

## Flashcards

> [!flashcard] Application: PKM Recursive Architecture
> **Q:** What is the recursive application of implementation intentions in personal knowledge management contexts?
> **A:** Building behavioral architectures in which one cue-triggered behavior serves as the cue for the next implementation intention, allowing the entire intellectual practice to run on cue-triggered automaticity rather than continuous willpower. Example: morning sit-down → spaced-repetition review → primary reading → note-making → capture review.
