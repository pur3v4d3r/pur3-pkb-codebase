# The Recursive Application Worth Surfacing

> [!definition] The Recursive Application Worth Surfacing
> A series of if-then plans where each subsequent plan is triggered by the completion of a previous one, reducing the need for continuous willpower and building a reliable behavioral structure.

## Reflections

> [!claude-insight] The Recursive Application Worth Surfacing
> One of the most useful and least-discussed applications of implementation intentions in PKM contexts is *recursive* — using if-then plans to install the cue-triggered behaviors that subsequently trigger other implementation intentions. The first plan in such a recursive structure must be installed by deliberate effort, but once it is operating, it can serve as the cue for the next plan, which can serve as the cue for the next, building up a behavioral architecture in which the entire intellectual practice runs on cue-triggered automaticity rather than continuous willpower. The morning sit-down triggers the spaced-repetition review; the completion of the review triggers the day's primary reading; the close of the reading triggers the note-making; the close of the note-making triggers the capture review; and so on. The volitional resource that would have been required at each transition has been pre-spent during the planning phase, and the intellectual practice acquires a structural reliability that has nothing to do with willpower in the moment.
> *— [[implementation-intentions-gollwitzer-foundational-report-2026-04-20]]*
