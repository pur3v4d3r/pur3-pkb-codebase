# The Substructure: Need-to-Style Mapping

> [!definition] The Substructure: Need-to-Style Mapping
> The Substructure: Need-to-Style Mapping is a framework within self-determination theory that outlines how different psychological needs (relatedness, competence, autonomy) develop at specific transitions and are not interchangeable.
