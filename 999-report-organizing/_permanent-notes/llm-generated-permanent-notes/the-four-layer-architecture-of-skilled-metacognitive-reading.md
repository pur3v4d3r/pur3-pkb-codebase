# The Four-Layer Architecture of Skilled Metacognitive Reading

> [!definition] The Four-Layer Architecture of Skilled Metacognitive Reading
> The Four-Layer Architecture of Skilled Metacognitive Reading is a model comprising layers such as Monitoring-Control Loop for real-time control, Standard of Coherence for evaluating text coherence, Knowledge of Cognition for cognitive strategies, and Regulatory Repertoire for metacognitive actions.

## Additional Material

> [!diagram] The Four-Layer Architecture of Skilled Metacognitive Reading
> ```
>     ┌─────────────────────────────────────────────────────────────┐
>     │  Layer 1: MONITORING–CONTROL LOOP (Nelson & Narens 1990)    │
>     │                                                             │
>     │     META LEVEL                                              │
>     │       │   ▲                                                 │
>     │  control│   │monitoring                                     │
>     │       ▼   │                                                 │
>     │     OBJECT LEVEL (comprehension processes)                  │
>     └─────────────────────────────────────────────────────────────┘
>                          ▲
>                          │ evaluated against ↓
>     ┌─────────────────────────────────────────────────────────────┐
>     │  Layer 2: STANDARD OF COHERENCE (Baker 1985)                │
>     │  lexical → syntactic → propositional → structural → external│
>     │  (configurable per text, purpose, passage)                  │
>     └─────────────────────────────────────────────────────────────┘
>                          ▲
>                          │ informed by ↓
>     ┌─────────────────────────────────────────────────────────────┐
>     │  Layer 3: KNOWLEDGE OF COGNITION (Flavell / Brown)          │
>     │  declarative (what) + procedural (how) + conditional (when) │
>     │  spanning person, task, and strategy knowledge              │
>     └─────────────────────────────────────────────────────────────┘
>                          ▲
>                          │ supplies ↓
>     ┌─────────────────────────────────────────────────────────────┐
>     │  Layer 4: REGULATORY REPERTOIRE (Pressley & Afflerbach)     │
>     │  reread / look-back / look-ahead / look-up /                │
>     │  self-question / summarize / self-explain / meta-pause      │
>     └─────────────────────────────────────────────────────────────┘
> ```
>
> Each layer can fail independently (monitoring insensitivity, standard set too low, missing conditional knowledge, impoverished repertoire) or in combination, producing the documented patterns of comprehension failure surveyed across Sections 5 and 6.
> *— [[metacognition-and-reading-foundational-report-2026-04-20]]*
