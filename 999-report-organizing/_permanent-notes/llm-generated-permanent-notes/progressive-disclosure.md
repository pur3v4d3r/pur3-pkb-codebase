# progressive-disclosure

> [!definition] progressive-disclosure
> - **Key-Term**: [[progressive-disclosure]]
> - **Definition**: Progressive disclosure is an instructional design technique that gradually reveals information to learners, starting with the most essential elements and progressively adding more details as needed to avoid overwhelming them.
> - **Domain**: other
> - **Status**: 🌱 budding | Confidence: speculative

## Core Explanation

> [!analytical-insight] Core Explanation
> Progressive disclosure is a pedagogical strategy rooted in cognitive load theory (CLT) that aims to manage the amount of information presented to learners at any given time. By gradually revealing information, it helps prevent cognitive overload and enhances learning efficiency.

> [!analytical-insight] Explanation 2
> In practice, progressive disclosure can be applied through various methods such as hiding advanced options until they are needed or providing step-by-step instructions in a user interface. This approach ensures that learners focus on the most critical aspects of a task before being introduced to more complex elements.

> [!analytical-insight] Explanation 3
> Key nuances include the balance between revealing too much information at once and not enough, which can be influenced by factors such as learner experience level and the complexity of the task.

## Practical Implications

> [!example] Application
> In e-learning design, progressive disclosure can improve user engagement and comprehension by reducing cognitive load. This is particularly useful in complex systems or software where users need to learn multiple features.

> [!example] Application
> In instructional materials, it helps maintain a clear focus on essential information, making the learning process more manageable for students.
