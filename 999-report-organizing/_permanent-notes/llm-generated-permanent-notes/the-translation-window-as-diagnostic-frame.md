# The Translation Window as Diagnostic Frame

> [!definition] The Translation Window as Diagnostic Frame
> The Translation Window as Diagnostic Frame is a framework for evaluating whether a goal-setting intervention will likely result in positive performance outcomes or negative pathologies by assessing proxy fidelity, honest attainability, measurement adequacy, and failure tolerance.

## Core Explanation

> [!analytical-insight] The Translation Window as Diagnostic Frame
> The translation window provides a unified diagnostic for assessing whether a proposed goal-setting intervention is likely to produce the desired performance gains or the dark-side pathologies. The diagnostic asks four questions: First, do the activities required to meet the goal coincide with the activities the underlying value requires (the **proxy fidelity** question)? Second, is honest pursuit of the goal feasible given the performer's current ability and accessible strategy (the **honest attainability** question)? Third, does the goal's measurement capture all the dimensions of performance that matter (the **measurement adequacy** question)? Fourth, do the consequences of failure preserve the performer's capacity to pursue future goals constructively (the **failure tolerance** question)? When all four answers are yes, the translation window is open and Goal Setting Theory's machinery can be expected to produce its predicted benefits. When any answer is no, the same machinery will produce predicted pathologies — and the severity of the pathology will scale with the number of negative answers and the difficulty of the goal that has been set despite them.
