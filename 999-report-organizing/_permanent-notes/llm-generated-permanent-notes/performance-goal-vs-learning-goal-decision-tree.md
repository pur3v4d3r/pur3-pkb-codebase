# Performance Goal vs. Learning Goal Decision Tree

> [!definition] Performance Goal vs. Learning Goal Decision Tree
> A Performance Goal vs. Learning Goal Decision Tree is a structured approach to determine whether a goal should be framed as a performance goal (focused on specific outcomes) or a learning goal (emphasizing the acquisition of new strategies or processes), based on criteria such as existing skills, measurability, and environmental conditions.

## Core Explanation

> [!evidence] Performance Goal vs. Learning Goal Decision Tree
> ```
> Q1: Does the performer already possess the strategy required to achieve the goal?
>     YES → Q2
>     NO  → SET LEARNING GOAL (specify the strategy or process to acquire)
>
> Q2: Is the performance variable cleanly measurable on a single dimension?
>     YES → Q3
>     NO  → Use multi-dimensional outcome measurement; consider mixed goals
>
> Q3: Are the conditions of the translation window all open?
>     YES → SET PERFORMANCE GOAL (specific, difficult, with moderators in place)
>     NO  → Either close the window first or set a learning goal instead
> ```
> *— [[goal-setting-theory-locke-latham-foundational-report-2026-04-20]]*
