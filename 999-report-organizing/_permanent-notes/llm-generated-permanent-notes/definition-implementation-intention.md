# Definition: Implementation Intention

> [!definition] Definition: Implementation Intention
> An implementation intention is a subordinate planning structure in the form 'When situation X occurs, I will perform behavior Y,' which links a specific anticipated cue to a specific intended response, facilitating automatic behavior initiation.

## Flashcards

> [!flashcard] Definition: Implementation Intention
> **Q:** What is an implementation intention?
> **A:** A subordinate planning structure of the form "When situation X occurs, I will perform behavior Y," which pre-links a specific anticipated cue to a specific intended response, thereby transferring control of the behavior from deliberative goal pursuit to a cue-triggered initiation routine.
