# Fading Is Not Abandonment

> [!definition] Fading Is Not Abandonment
> Fading is not abandonment; it involves gradually reducing support while monitoring learner performance, allowing for temporary reinstatement if needed.

## Practical Implications

> [!warning] Fading Is Not Abandonment
> The fading metaphor can be misleading if interpreted as abrupt removal. Fading is gradual, monitored, and reversible. If a learner experiences regulatory degradation after a scaffold is removed — evident in declining calibration accuracy, omitted planning, or reduced reflection quality — the scaffold should be temporarily reinstated. Fading is not a one-way process; it is an experimental probe of developmental readiness. The developmental arc includes lateral movements and temporary regressions as well as forward progress.
