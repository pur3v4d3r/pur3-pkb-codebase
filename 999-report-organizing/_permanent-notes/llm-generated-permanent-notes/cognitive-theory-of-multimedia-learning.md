# cognitive-theory-of-multimedia-learning

> [!definition] cognitive-theory-of-multimedia-learning
> - **Key-Term**: [[cognitive-theory-of-multimedia-learning]]
> - **Definition**: Cognitive theory of multimedia learning is a framework that explains how people learn from both auditory and visual information presented simultaneously, emphasizing the role of prior knowledge in processing this combined information effectively.
> - **Domain**: cognitive-psychology
> - **Status**: 🌱 budding | Confidence: speculative

## Core Explanation

> [!analytical-insight] Core Explanation
> The theory posits that learning involves two channels: one for verbal information (auditory or written) and another for visual-spatial information. These channels operate independently but can be integrated when necessary to construct a coherent mental model.

> [!analytical-insight] Explanation 2
> It suggests that learners are more effective when multimedia materials are designed to exploit the dual-channel system, such as using narration to explain visuals rather than providing text descriptions of the same content.

> [!analytical-insight] Explanation 3
> Key nuances include the idea that not all information needs to be presented simultaneously; instead, it can be sequenced in a way that enhances learning.

## Practical Implications

> [!example] Application
> In e-learning design, multimedia materials should be structured to align with the dual-channel system for better comprehension and retention.

> [!example] Application
> Educators should avoid overloading learners with too much information at once; instead, they should focus on presenting content in a way that supports integration of verbal and visual information.
