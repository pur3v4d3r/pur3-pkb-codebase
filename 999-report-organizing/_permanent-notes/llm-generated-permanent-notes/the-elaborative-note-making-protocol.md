# The Elaborative Note-Making Protocol

> [!definition] The Elaborative Note-Making Protocol
> The Elaborative Note-Making Protocol is a cognitive strategy involving reading material without notes, recalling it from memory, linking new content to existing knowledge, reflecting on its significance, revising the note based on the original source, and assigning comprehension metadata.

## Additional Material

> [!protocol] The Elaborative Note-Making Protocol
> **Purpose:** Transform passive information capture into active elaborative encoding during PKB note creation.
>
> **Steps:**
> 1. **Read/process source material** without taking notes; focus on understanding.
> 2. **Close the source.** Write the note from memory (generation effect).
> 3. **Identify 3-5 existing permanent notes** to which this content connects. Create wiki-links and write 1-2 sentences explaining each connection (elaborative interrogation).
> 4. **Write a "so what?" statement** — why this matters, what it implies, what it changes about understanding (self-explanation).
> 5. **Reopen the source.** Compare the note to the original. Correct errors, add critical details that were missed.
> 6. **Assign status metadata** reflecting honest assessment of comprehension depth (metacognitive monitoring).
