# element-interactivity — A Dedicated Foundational Treatment

> [!definition] element-interactivity — A Dedicated Foundational Treatment
> Element interactivity is a foundational construct in Cognitive Load Theory that determines intrinsic load by considering the interaction between instructional elements and learner expertise.

## Core Explanation

> [!evidence] element-interactivity — A Dedicated Foundational Treatment
> **Description:** Element interactivity is CLT's most consequential construct — the bridge between architectural claims and empirical predictions — yet it lacks a dedicated treatment in the PKB. A comprehensive note would cover formal definitions, calculation methods, the relational nature of interactivity (material × learner expertise), measurement approaches, and implications for instructional sequencing across domains.
>
> **Connection to this report:** Section 2 introduces element interactivity as the determinant of intrinsic load, and the construct appears in every subsequent section. The current report treats it as instrumental to CLT's larger framework, but the construct itself warrants independent analysis.
