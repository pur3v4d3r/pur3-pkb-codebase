# Prospective-Memory

> [!definition] Prospective-Memory
> - **Key-Term**: [[Prospective-Memory]]
> - **Definition**: Prospective-memory refers to the ability to remember to perform an intended action at some future time or place, distinct from remembering factual information. It involves planning and setting up reminders for oneself in advance of when one needs to act.
> - **Domain**: cognitive-psychology
> - **Status**: 🌱 budding | Confidence: speculative

## Core Explanation

> [!analytical-insight] Core Explanation
> Prospective-memory is a cognitive process that allows individuals to plan and execute actions in the future based on current intentions. This mechanism relies on encoding specific details about the intended action, such as what to do, where to do it, and when to do it, which are then stored in memory for later retrieval.

> [!analytical-insight] Explanation 2
> The core mechanism of prospective-memory involves setting up implementation intentions—specific plans that link a situational cue with an intended response. For example, 'When I see my keys, I will put on my coat.' These implementation intentions help bridge the gap between current intentions and future actions by creating automatic associations that facilitate recall.

> [!analytical-insight] Explanation 3
> Key nuances include the distinction between time-based and event-based prospective-memory tasks, where time-based tasks rely more heavily on temporal cues, while event-based tasks depend on specific situational triggers. Theoretical roots also explore the role of executive functions in managing these plans and the potential neural substrates involved.

## Practical Implications

> [!example] Application
