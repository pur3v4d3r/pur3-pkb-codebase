# Externalized Metacognition — Systems, Tools, and Cognitive Augmentation

> [!definition] Externalized Metacognition — Systems, Tools, and Cognitive Augmentation
> Externalized metacognition involves using systems and tools to perform metacognitive functions such as monitoring comprehension, calibrating confidence, detecting knowledge gaps, and prompting strategic adjustments, which are typically managed through unaided self-assessment.

## Core Explanation

> [!evidence] Externalized Metacognition — Systems, Tools, and Cognitive Augmentation
> **Description:** A comprehensive investigation of how external tools and systems can perform metacognitive functions — monitoring comprehension, calibrating confidence, detecting knowledge gaps, and prompting strategic adjustments — that would otherwise depend on the learner's unaided self-assessment. This topic extends the metacognitive prosthesis concept from Section 5 into a full theoretical framework, examining historical precedents (external memory systems, cognitive artifacts), contemporary implementations (PKM dashboards, learning analytics, adaptive systems), and the philosophical implications of distributing metacognition across human-tool systems.
>
> **Connection to this report:** Directly extends the PKB-as-metacognitive-prosthesis framing (Section 5) and the externalized metacognition design principle (Section 7).
