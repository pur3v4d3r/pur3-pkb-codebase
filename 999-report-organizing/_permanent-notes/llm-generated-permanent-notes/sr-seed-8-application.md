# SR Seed 8 — Application

> [!definition] SR Seed 8 — Application
> SR Seed 8 — Application refers to the deployment of learning contracts in Phase 3 (Negotiated Autonomy) of the Scaffolding-Sovereignty Progression, where learners can set and evaluate their own goals effectively.

## Flashcards

> [!flashcard] SR Seed 8 — Application
> **Q:** How should learning contracts be deployed within the Scaffolding-Sovereignty Progression?
> **A:** Learning contracts are most effective during Phase 3 (Negotiated Autonomy), when learners have sufficient metacognitive capacity to set meaningful goals and evaluate their own learning strategies. Deployed too early (Phases 1-2), they produce superficial or derivative goals. Deployed too late (Phase 5), they are unnecessary constraints on sovereignty.
