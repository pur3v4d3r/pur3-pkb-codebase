# Directive Function

> [!definition] Directive Function
> The mechanism by which a committed goal organizes attention preferentially toward goal-relevant activities and away from goal-irrelevant activities, including the suppression of competing tasks, the filtering of competing stimuli, and the privileged occupancy of working memory by goal-related representations.
>
> **Boundary:** The directive function operates on activities the performer recognizes as relevant to the goal; activities whose relevance is not perceived will not be selected even if they would advance the goal, which is one mechanism by which goals can paradoxically narrow performance on tasks requiring exploration.
>
> **Report-Specific Significance:** The directive function is the cleanest example of the theory's signature pattern — a mechanism that is unambiguously beneficial in narrow tasks but that produces tunnel vision in tasks requiring breadth.
>
> **See also:** [[selective-attention]], [[attention-and-learning]]
