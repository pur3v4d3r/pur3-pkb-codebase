# Process: Monitoring-Control Loop

> [!definition] Process: Monitoring-Control Loop
> A monitoring-control loop in metacognition involves continuous cycles where monitoring assesses learning progress and difficulties, which then informs control actions to adjust study strategies accordingly.

## Flashcards

> [!flashcard] Process: Monitoring-Control Loop
> **Q:** What are the two components of the monitoring-control loop in metacognition, and how do they interact?
> **A:** Monitoring generates information about the current state of learning (assessments of comprehension, difficulty, and progress). Control translates that information into strategic action (adjusting study strategies, allocating effort, seeking clarification). Monitoring informs control; control modifies behavior; behavior generates new monitoring data.
