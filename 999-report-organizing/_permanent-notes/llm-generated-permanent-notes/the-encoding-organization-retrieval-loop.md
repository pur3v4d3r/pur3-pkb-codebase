# The Encoding-Organization-Retrieval Loop

> [!definition] The Encoding-Organization-Retrieval Loop
> The Encoding-Organization-Retrieval Loop is a cyclical process in personal knowledge management involving encoding information through deep processing, organizing it into schema networks for better findability, and retrieving it using techniques like spaced repetition to strengthen memory traces.

## Additional Material

> [!diagram] The Encoding-Organization-Retrieval Loop
> ```
>     ┌──────────────────┐
>     │  ENCODING         │  Levels of processing
>     │  (Section 2)      │  Dual coding, generation
>     │  Deep → Durable   │  Elaborative interrogation
>     └────────┬─────────┘
>              │ Produces richly encoded traces
>              ▼
>     ┌──────────────────┐
>     │  ORGANIZATION     │  Schema networks
>     │  (Section 3)      │  Spreading activation
>     │  Linked → Findable│  Link density metrics
>     └────────┬─────────┘
>              │ Creates multiple retrieval pathways
>              ▼
>     ┌──────────────────┐
>     │  RETRIEVAL        │  Testing effect
>     │  (Section 4)      │  Spaced repetition
>     │  Effortful → Strong│ Desirable difficulties
>     └────────┬─────────┘
>              │ Retrieval events strengthen traces
>              │ and reveal organizational gaps
>              └──────────► loops back to ENCODING
> ```
