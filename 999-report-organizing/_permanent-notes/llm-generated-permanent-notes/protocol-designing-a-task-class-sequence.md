# Protocol: Designing a Task Class Sequence

> [!definition] Protocol: Designing a Task Class Sequence
> Protocol: Designing a Task Class Sequence is a method for structuring learning tasks into progressively complex classes by identifying core skills, creating intermediate levels with incremental challenges, and defining scaffolded instruction and supportive information for each class.

## Additional Material

> [!protocol] Protocol: Designing a Task Class Sequence
> **Purpose:** Sequence learning tasks into task classes of progressive complexity.
>
> **Steps:**
> 1. **Identify the simplest version** of the whole task that still requires coordination of the core constituent skills. This is Task Class 1.
> 2. **Identify the full-complexity version** of the task as performed by experts. This is the final Task Class.
> 3. **Identify 3-6 intermediate complexity levels** by adding interacting elements incrementally. Each level should add genuinely new coordination demands, not merely surface-level difficulty.
> 4. **For each task class, define:**
>    - The interacting elements present at this level
>    - The elements NOT yet included (simplification)
>    - The scaffold-fading sequence: worked example → completion tasks → conventional tasks
>    - The supportive information required for this complexity level
>    - The procedural information for recurrent skills at this level
> 5. **Verify progression logic:** Does each new task class build on skills practiced in the previous class? Would a learner who mastered Class N have the prerequisites for Class N+1?
