# the-atkinson-shiffrin-multi-store-model

> [!definition] the-atkinson-shiffrin-multi-store-model
> - **Key-Term**: [[the-atkinson-shiffrin-multi-store-model]]
> - **Definition**: The Atkinson-Shiffrin multi-store model is a theory of memory that proposes three distinct stores: sensory register, short-term memory (STM), and long-term memory (LTM).
> - **Domain**: other
> - **Status**: 🌱 budding | Confidence: speculative

## Core Explanation

> [!analytical-insight] Core Explanation
> This model suggests that information first enters the sensory register briefly before being filtered into STM if it is attended to. Information in STM can be further encoded and stored in LTM with repetition or elaboration.

> [!analytical-insight] Explanation 2
> The model emphasizes the limited capacity of STM, which typically holds about 7±2 items for a few seconds, and the more permanent storage capabilities of LTM.

> [!analytical-insight] Explanation 3
> Key nuances include the idea that information must be actively rehearsed to move from STM to LTM.

## Practical Implications

> [!example] Application
> In education, this model suggests that teachers should help students encode information effectively by providing meaningful context and encouraging rehearsal.

> [!example] Application
> In cognitive load theory, understanding the limited capacity of STM helps in designing instructional materials that avoid overwhelming learners with too much information at once.
