# The Schema-Construction Loop (formal structure)

> [!definition] The Schema-Construction Loop (formal structure)
> The Schema-Construction Loop is a cognitive process where existing schemas from long-term memory are accessed by working memory, leading to schema construction or modification based on current task performance, which then feeds back into long-term memory, reducing effective element interactivity in subsequent tasks.
