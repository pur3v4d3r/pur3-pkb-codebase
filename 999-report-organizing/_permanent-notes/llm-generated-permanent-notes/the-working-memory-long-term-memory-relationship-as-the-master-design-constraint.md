# The Working Memory–Long-Term Memory Relationship as the Master Design Constraint

> [!definition] The Working Memory–Long-Term Memory Relationship as the Master Design Constraint
> The Working Memory–Long-Term Memory Relationship as the Master Design Constraint refers to the principle that cognitive strategies for learning and knowledge base architecture should optimize the interaction between limited working memory capacity and the need for rich long-term memory schemas.

## Core Explanation

> [!evidence] The Working Memory–Long-Term Memory Relationship as the Master Design Constraint
> Every effective cognitive strategy for learning, and every architectural decision in PKB design, can be understood as an attempt to manage the bottleneck between working memory's severe capacity limitations and long-term memory's need for richly structured, interconnected schemas. Strategies that succeed are those that either reduce unnecessary working memory load (freeing capacity for genuine learning) or direct available working memory resources toward schema construction and integration rather than rote maintenance of surface-level information.
