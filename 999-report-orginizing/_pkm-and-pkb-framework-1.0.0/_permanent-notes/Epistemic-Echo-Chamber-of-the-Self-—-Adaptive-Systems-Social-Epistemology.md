# Epistemic Echo Chamber of the Self — Adaptive Systems / Social Epistemology

> [!definition] **Epistemic Echo Chamber of the Self — Adaptive Systems / Social Epistemology**
> A structural risk in adaptive AI systems that learn user interests and competencies: the system progressively presents content consistent with existing knowledge and interests, systematically underexposing the user to challenging, contradictory, or unfamiliar territory. Unlike social echo chambers (requiring like-minded others), this risk emerges from personalization algorithms operating on a single user's own behavioral patterns.
