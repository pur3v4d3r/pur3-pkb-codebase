# Memory Durability

> [!definition] **Memory Durability**
> The persistence of a memory trace over time, understood within the levels of processing framework as a direct function of the depth of processing applied during encoding — not of storage location, rehearsal frequency, or conscious intention to remember. A durably encoded memory is one produced by elaborative, semantic, or otherwise meaningful cognitive engagement with the target material.
> 
> **Boundary:** Memory durability in this framework is specifically about the encoding determinants of trace strength. It does not directly address retrieval-context effects, which became the focus of the [[Encoding-Specificity-Principle]] (Tulving & Thomson, 1973) — a related but importantly distinct account. The framework also does not imply that all deeply processed information will be remembered, only that deep processing is necessary for durable encoding under most conditions.
> 
> **Report-Specific Significance:** This concept is the central explanandum of the theory — the phenomenon to be explained — and the explanatory lever by which Craik & Lockhart distinguish their framework from stage-model alternatives.
>
