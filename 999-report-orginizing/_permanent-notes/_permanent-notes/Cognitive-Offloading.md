# Cognitive Offloading

> [!definition] **Cognitive Offloading**
> The use of the environment to reduce the cognitive demands placed on internal biological cognitive systems. Offloading encompasses strategies ranging from writing things down to arranging physical objects spatially to using digital reminders. Importantly, offloading is not the same as cognitive extension in Clark and Chalmers's sense: offloading is a strategy for reducing cognitive load, while extension is a claim about the actual constitution of the cognitive system. The distinction is subtle but theoretically important: a person can offload extensively without any of the offloaded processes qualifying as part of their extended cognitive system.
