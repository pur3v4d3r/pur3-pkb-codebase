# Slot / Default Value

> [!definition] **Slot / Default Value**
> A variable component within a schema that accepts specific values when the schema is instantiated in a particular context. Slots carry *default values* — the most probable or typical values in the absence of specific information. Default values drive schema-based inference, filling in unstated information during comprehension and reconstruction.

## Core Explanation

> [!analytical-insight] Key Insight
> Bartlett's most radical and enduring claim is that memory is not reproductive but *reconstructive*. When we recall a past experience or a text we have read, we do not simply replay a stored recording. We reconstruct it — building a plausible account from schema-consistent fragments, filling gaps with schema-generated defaults, and unconsciously editing anomalies toward what our schemas lead us to expect.
