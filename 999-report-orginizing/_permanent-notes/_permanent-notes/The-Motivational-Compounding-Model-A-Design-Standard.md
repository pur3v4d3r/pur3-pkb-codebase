# The Motivational Compounding Model: A Design Standard

> [!definition] **The Motivational Compounding Model: A Design Standard**
> The Motivational Compounding Model proposes that PKB designs can be evaluated along a single meta-criterion that subsumes all five design principles: **does this design increase or decrease the motivational return on investment over time?** A PKB note that captures information but creates no connection generates a motivational flat line — no compounding. A PKB note that captures, connects to existing knowledge, raises a new question, and links to a valued project generates a small motivational return — the interest slightly deepens, the identity slightly consolidates. Multiplied across thousands of notes across years, this small return differential produces the compound effect that distinguishes the PKB that becomes more alive over years from the one that quietly dies. The practical standard: evaluate every structural PKB design decision — not just individual notes but folder architecture, review protocols, metadata systems, note types — by asking: "Does this generate motivational returns over time, or does it extract motivational cost?"
