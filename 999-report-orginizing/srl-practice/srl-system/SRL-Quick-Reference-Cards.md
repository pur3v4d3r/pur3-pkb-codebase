# 🃏 SRL Quick Reference Cards

> [!abstract] Purpose
> Rapid-access reference cards for use during [[Forethought-Phase|Forethought]] and [[Self-Reflection-Phase|Self-Reflection]] sessions. These cards operationalize the language design principles from [[Achievement-Goal-Theory]], [[Self-Determination-Theory]], [[Attribution-Theory]], and [[Formative-Assessment]] research. **Bookmark this note for quick access during sessions.**

---

## Card 1: 🎯 Goal-Setting Language Bank

> [!tip] Mastery-Framed Goal Formulations
> Use right-column language in Forethought Protocol goal-setting. The distinction in each pair is between **stable, global, ability-referenced** language (avoid) and **specific, process-referenced, controllable** language (use). See [[Achievement-Goal-Theory]] and [[Mastery-Goal-Orientation]].

### What to Avoid → What to Use

| Situation | ❌ Performance-Oriented (Avoid) | ✅ Mastery-Oriented (Use) |
|-----------|-------------------------------|--------------------------|
| Setting outcome goal | "Understand this report thoroughly" | "Explain the key mechanism in my own words" |
| Setting process goal | "Take good notes" | "Write a one-sentence summary at each section break" |
| Responding to difficulty | "This section is too hard" | "This section reveals a [[Prior-Knowledge|prior knowledge]] gap — I'll flag it for attribution analysis" |
| Post-session failure | "I didn't understand this well enough" | "Sections 2 and 4 were not fully reconstructed — here's why…" |
| Process failure | "I wasn't focused enough" | "I skipped the monitoring checkpoint at section 3 — specific fix: set a timer" |
| Success attribution | "I got lucky this was easy" | "My PKB reconnaissance activated relevant schemas that supported comprehension" |
| Failure attribution | "I'm not good at this material" | "I encountered this framework without adequate preparation — addressable by reviewing [[]] first" |

### Comprehension Criterion Templates

> [!example] Fill-in-the-blank formulas for specific, evaluable comprehension criteria. See [[The-Fluency-Illusion|why these must require cognitive production, not recognition]].

**Mechanism-level:**
> "Be able to explain the mechanism by which [X] produces [Y], including [the key variable/condition] that determines [when/how much/whether], without looking at the text."

**Implication-level:**
> "Be able to identify [N] non-obvious implications of [claim], at least one of which applies to [specific domain/practice]."

**Connection-level:**
> "Be able to articulate how [concept from this text] relates to [[specific PKB note]], including where they align and where they create tension."

**Example-generation level:**
> "Be able to generate [N] original examples of [concept], including at least one from a domain different from the text's primary application."

**Distinction-level:**
> "Be able to explain the difference between [X] and [Y], including the specific conditions under which the distinction matters."

## Card 2: 🔬 Attribution Retraining Protocol

> [!warning] Use this card whenever you notice a global attribution during Self-Reflection.
> Global attributions ("I'm not good at this," "this material is too hard") are the most consequential failure mode in the SRL cycle. They route to [[Defensive-Inference|defensive inferences]] that degrade the next [[Forethought-Phase]]. See [[Attribution-Theory]], [[Bernard-Weiner]], and [[Attribution-Retraining]].

### The Five Controllable-Attribution Candidates

When you notice a global attribution, **STOP** and systematically run through these five alternatives before accepting the global one:

> [!example] 1. Schema Gap
> "Was there [[Prior-Knowledge|prior knowledge]] that this text assumed I had, that I didn't have?"
> - **If yes:** What specific prerequisite reading would address this?
> - **Action:** Add to [[SRL-Living-Learning-Agenda]] reading queue

> [!example] 2. Goal Calibration
> "Was my comprehension criterion appropriately matched to my current schema level?"
> - **If too ambitious:** What more proximal criterion would have been achievable?
> - **Action:** Adjust goal scope in next Forethought

> [!example] 3. Strategy Mismatch
> "Did I use the most effective reading strategy for this text type and my schema level?"
> - **If no:** Which would have been better?
>   - [[Advance-Organizers|Advance organizer activation]]
>   - [[Elaborative-Interrogation|Elaborative interrogation]]
>   - Self-explanation at section breaks
>   - Structural reading before detail
> - **Action:** Select and implement alternative strategy

> [!example] 4. Attention Management
> "Was my attention available for the cognitive demands this text required?"
> - **If no:** What environmental or scheduling adjustment would address this?
> - **Action:** Modify session conditions

> [!example] 5. Time/Scope Pressure
> "Did I attempt too much in this session relative to the text's density?"
> - **If yes:** What is a more realistic scope for one session?
> - **Action:** Reduce scope in next session's Forethought

### The One-Sentence Attribution Protocol

> [!important] For any session where process goals were substantially unmet, complete this sentence:
> *"The strategy I used was [specific strategy]. It was insufficient because [specific mechanism]. A better approach for next time would be [specific alternative]."*
>
> This sentence structure makes it structurally difficult to make external or fixed-internal attributions. See [[Mastery-Oriented-Response-Pattern]].

### After Running All Five

**If you still believe the most accurate attribution is global:**
Make a note to return to this text after completing a lighter introduction to the domain (schema-building session). The attribution may be accurate — this material genuinely exceeds current schema — but the corrective action is still specific and controllable: **build the schema first.** See [[Scaffolding-Instructional-Design]].

## Card 3: 💬 Mastery Grammar vs. Performance Grammar

> [!tip] The language you use in self-talk during sessions shapes your [[Achievement-Goal-Theory|goal orientation]]. Performance grammar activates ego-threat; mastery grammar activates learning orientation. See [[Formative-Assessment]] and [[Self-Determination-Theory]].

### Self-Evaluation Language

| ❌ Performance Grammar | ✅ Mastery Grammar | Why |
|---|---|---|
| "How well did I do?" | "What did I understand better by the end?" | Shifts from judgment → growth |
| "Did I get it?" | "What can I now do with this that I couldn't before?" | Activates [[Transfer-of-Learning\|transfer]] as criterion |
| "Was this good enough?" | "Where is the growing edge of my current understanding?" | Positions incompleteness as directional, not deficient |
| "I should have done better" | "Here is what I understand about why this was difficult" | Replaces self-criticism with analysis |
| "I failed to meet my goals" | "I learned that these goals were [too ambitious / calibrated / too easy]" | Reframes performance data as [[Metacognitive-Calibration\|calibration]] information |
| "I'm struggling with this" | "This is an area of developing capability" | [[Entity-Theory\|Entity]] vs. [[Growth-Mindset\|incremental]] framing |

### Autonomy-Supportive vs. Controlling Self-Talk

> [!warning] Even self-directed controlling language undermines [[Intrinsic-Motivation]]. See [[Self-Determination-Theory]] and [[Autonomy-Support]].

| ❌ Controlling Language | ✅ Autonomy-Supportive Language |
|---|---|
| "I have to get through this" | "I'm choosing to engage with this because…" |
| "I must understand this section" | "I'm curious about what this section will add to my understanding of X" |
| "I should be further along" | "Where I am is the starting point for where I'm going" |
| "I can't skip this even though it's tedious" | "I notice resistance — what does that tell me about my current relationship with this content?" |
| "I need to try harder" | "I want to try a different approach to see what happens" |

### Attribution-Retraining Language

| ❌ Maladaptive Attribution | 🔄 Retraining Prompt | ✅ Adaptive Direction |
|---|---|---|
| "This material is just too dense" | "What specific aspect of my current schema made this density challenging?" | Underdeveloped background → specific reading strategy |
| "I didn't have enough time" | "What would I have done differently with better time management?" | Time allocation → adjustable |
| "I'm not a theory person" | "What specific processing does theoretical material require that I haven't developed yet?" | Missing strategy → developable |
| "I was too tired" | "What environmental conditions support my best engagement?" | Environmental design → controllable |

## Card 4: 📐 Adaptive Inference Quality Checklist

> [!tip] Use this checklist to validate that the adaptive inferences you generate in Self-Reflection are genuinely actionable. See [[Adaptive-Inference]].

A high-quality adaptive inference is:

- [ ] **Specific** — Names a particular strategy or behavior (not "try harder")
- [ ] **Actionable** — Can be entered directly into the next Forethought template
- [ ] **Testable** — You can tell whether it worked after the next session
- [ ] **Within control** — Depends on your actions, not circumstances
- [ ] **Strategy-based** — Addresses HOW you approach the material, not whether you're "capable"

### Examples of Good vs. Poor Adaptive Inferences

| ❌ Poor (vague, unactionable) | ✅ Good (specific, testable) |
|---|---|
| "Be more focused" | "Set a 25-minute timer and do a [[self-explanation]] at each section break" |
| "Read more carefully" | "Use [[Elaborative-Interrogation]] on mechanism sections by asking 'why does this work?'" |
| "Prepare better" | "Review [[specific PKB note]] before the session to activate relevant schema" |
| "Take more time" | "Reduce scope to sections 1-3 only, saving sections 4-5 for a separate session" |
| "Try harder" | "Add process goal: write one connection to existing PKB knowledge per section" |

## Card 5: ⚡ Early Implementation Survival Guide

> [!warning] The Early Implementation Dip Is Normal
> Research on [[Deliberate-Practice]] and metacognitive training consistently shows an initial performance dip when implementing explicit self-regulatory strategies. This is expected and temporary — the cognitive overhead of the new protocols competes with resources available for content processing. See [[Cognitive-Load-Theory]].

### What to Expect in the First 5-10 Sessions

1. **Sessions will feel longer** — The protocol adds 15-25 minutes to each session
2. **Comprehension may temporarily decrease** — This is normal, not evidence of failure
3. **The protocols will feel awkward** — Like any new skill, fluency develops through practice
4. **You will want to skip zones** — This is the precise moment to persist

### Three Protective Strategies

**1. Scaffold Progressively**
- Weeks 1-2: Implement Zone 1 (Prior Knowledge) and Zone 3 (Goal Setting) from Forethought only
- Weeks 3-4: Add Zone 1 (Cold Reconstruction) from Self-Reflection
- Weeks 5-6: Add remaining zones gradually
- **Do NOT implement the full protocol immediately**

**2. Use Process-Satisfaction Standards**
- Count a session as successful if you **executed the protocol with integrity** — regardless of comprehension outcome
- This maintains [[Self-Efficacy]] during the adaptation period

**3. Make Growth Visible**
- Track sessions completed in [[SRL-Calibration-Log]]
- Note when zones become easier to complete
- The visible record of practice IS the [[Self-Efficacy|mastery experience]]
