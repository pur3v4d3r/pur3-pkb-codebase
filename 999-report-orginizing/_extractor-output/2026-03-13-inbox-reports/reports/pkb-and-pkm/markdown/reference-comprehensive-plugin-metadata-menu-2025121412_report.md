## 📖 Definitions (10)

> [!tip] PKB Definitions
> These `[**Term**:: Definition]` fields define key concepts.
> They are queryable by Dataview.

### 1. Core-Philosophy

> [!definition] Core-Philosophy
> Metadata Menu treats your vault as a distributed database where each note is a record, fields are columns with schemas, and fileClasses are table definitions—enabling database-style operations while preserving Markdown flexibility.

*Source: Line 431 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 2. FileClass-Folder-Organization

> [!definition] FileClass-Folder-Organization
> Best practice is to create a dedicated folder outside your main content areas to store fileClass definition notes, preventing them from appearing in general searches while remaining accessible for schema management.

*Source: Line 542 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 3. Dataview-Query-Filtering

> [!definition] Dataview-Query-Filtering
> File-type fields support embedding dv.pages() queries that dynamically filter which files appear in the suggestion dropdown, enabling schema-enforced relationships like "only link to Person notes" or "only link to active Projects".

*Source: Line 658 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 4. Object-Nesting

> [!definition] Object-Nesting
> Object and ObjectList fields support infinite depth nesting—you can have ObjectLists containing Objects that themselves contain ObjectLists, enabling arbitrarily complex data hierarchies while maintaining full Metadata Menu editing capabilities at every level.

*Source: Line 717 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 5. Path-Mapping-Behavior

> [!definition] Path-Mapping-Behavior
> All notes within the specified folders (and subfolders) automatically inherit this fileClass. Supports relative paths from vault root and partial path matching.

*Source: Line 882 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 6. FileClass-Inheritance-Rules

> [!definition] FileClass-Inheritance-Rules
> Child fileClasses inherit ALL fields from parent classes. If a child redefines a field (same name), the child's definition overrides the parent's. The extends chain can be arbitrarily deep, enabling hierarchical schema taxonomies.

*Source: Line 969 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 7. Autocompletion-Trigger

> [!definition] Autocompletion-Trigger
> Metadata Menu's autocompletion activates when typing the field delimiter (: in frontmatter, :: for inline fields) and presents a filtered list of available fields based on current fileClass mappings plus global preset fields.

*Source: Line 1086 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 8. Note-Fields-Modal

> [!definition] Note-Fields-Modal
> The centralized metadata management interface that displays all fields defined by a note's fileClass(es) plus global preset fields, organized into existing (with current values) and missing (available for insertion) sections, with inline editing controls for each field type.

*Source: Line 1197 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 9. FieldModifier-Function-Signature

> [!definition] FieldModifier-Function-Signature
> `fieldModifier(dv, page, fieldName, options?)` where dv is the Dataview API instance, page is the current page object being processed, fieldName is the string identifier of the field to render, and options is an optional configuration object controlling display behavior.

*Source: Line 1304 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*

### 10. Table-Rendering-Performance

> [!definition] Table-Rendering-Performance
> DataviewJS tables with fieldModifier controls render more slowly than standard Dataview tables because each cell requires additional DOM manipulation. For large result sets (100+ rows), use .limit() to paginate and set alwaysOn: false to defer control rendering until user interaction.

*Source: Line 1565 in `reference-comprehensive-plugin-metadata-menu-2025121412.md`*
