> [!the-philosophy] Untitled
> **Underlying Philosophy: Logs and Versions as Cognitive Prosthetics**
> 
> Human memory is evolutionarily optimized for survival, not knowledge work. We remember threats and emotions vividly but forget technical details and reasoning chains within hours. Work logs and version management systems serve as **cognitive prosthetics**—external memory systems that compensate for biological memory limitations.
