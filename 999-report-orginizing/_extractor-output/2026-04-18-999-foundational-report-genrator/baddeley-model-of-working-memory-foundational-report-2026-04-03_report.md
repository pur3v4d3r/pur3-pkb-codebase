#### 3. [DEFINITION] Working Memory — The Cognitive Workspace *(Line 122)*

> [!definition] Working Memory — The Cognitive Workspace
> **Working memory** refers to the temporary storage and active manipulation of information necessary for complex cognitive tasks such as reasoning, comprehension, learning, and action. Unlike passive short-term memory stores in older models, working memory is fundamentally active: it is a workspace where information is not merely held but operated upon, transformed, combined with information from long-term memory, and used to guide ongoing cognition. [[Alan-Baddeley]] and [[Graham-Hitch]] proposed in 1974 that this workspace is not a unitary buffer but a multicomponent system with distinct subsystems serving different functional roles.

#### 4. [KEY-CLAIM] The Gateway Challenge to Modal Memory Theory *(Line 129)*

> [!key-claim] The Gateway Challenge to Modal Memory Theory
> The neuropsychological case of patient KF, reported by Shallice and Warrington, demonstrated that individuals with severely impaired short-term memory capacity could still consolidate new information into [[Long-Term-Memory]]. This was logically incompatible with the [[Multi-Store-Model]]'s claim that the short-term store served as a mandatory bottleneck through which all information had to pass before long-term encoding. The working memory model arose, in part, to resolve this theoretical crisis by replacing the single, passive STS with a multicomponent system in which individual components could be damaged while others were preserved.

#### 5. [SECTION-SUMMARY] Section 1 Summary *(Line 142)*

> [!section-summary] Section 1 Summary
> Working memory is a active cognitive workspace — not a passive buffer — where information is temporarily maintained and manipulated to support ongoing cognition. The construct emerged to resolve theoretical anomalies in the Atkinson-Shiffrin multi-store model, particularly the neuropsychological evidence that short-term memory damage does not prevent long-term learning. Working memory matters because (1) it is the immediate site of cognitive work during learning and reasoning, (2) individual differences in working memory capacity predict a wide range of complex cognitive outcomes, and (3) understanding its architecture provides actionable insight for instructional design, metacognitive strategy selection, and cognitive development.

#### 7. [DEFINITION] The Information-Processing Foundation *(Line 156)*

> [!definition] The Information-Processing Foundation
> The information-processing approach to cognition, which dominated [[cognitive-psychology]] from the late 1950s onward, treated the mind as a system that transforms, stores, and retrieves information according to computational principles. This framework imported concepts from communications engineering and computer science — channels, capacity limits, buffers, serial versus parallel processing — and applied them to the empirical study of human perception, attention, and memory. The first rigorous psychological application of these concepts to memory came from [[George-Miller]] (1956), who demonstrated that short-term memory had a fundamental capacity limit of approximately seven plus or minus two chunks, and from Peterson and Peterson (1959), who showed that unrehearsed verbal material decays from short-term memory within approximately 18-30 seconds in the absence of rehearsal.

#### 8. [EXAMPLE] The Working Memory in Arithmetic *(Line 165)*

> [!example] The Working Memory in Arithmetic
> Consider mental arithmetic: 37 × 8. To solve this, you must hold "37" and "8" in mind simultaneously, retrieve multiplication facts from [[Long-Term-Memory]], compute 30 × 8 = 240 while holding this partial result, then compute 7 × 8 = 56 while retaining 240, then add 240 + 56 = 296 while holding both results. This task demands not just passive storage but active coordination between temporary storage buffers and an attentional-executive controller that sequences operations, retrieves long-term knowledge, and integrates partial results. A single unitary buffer cannot explain the distinct functional demands of holding partial results versus executing retrieval and computation operations.

#### 9. [METHODOLOGY-AND-SOURCES] The Dual-Task Methodology *(Line 172)*

> [!methodology-and-sources] The Dual-Task Methodology
> The primary experimental tool for dissecting working memory components has been the **dual-task methodology**: requiring participants to perform two tasks simultaneously and examining how each tasks interferes with the other. If two tasks draw on the same component, they will interfere strongly (called **specific interference**); if they draw on different components, they will interfere little (called **resource independence**). For example, articulatory suppression (repeating a meaningless syllable like "the-the-the" aloud) interrupts the phonological loop's rehearsal mechanism while having minimal effect on visuospatial processing. This methodology allowed Baddeley and colleagues to map the functional boundaries between components over subsequent decades.

#### 10. [SECTION-SUMMARY] Section 2 Summary *(Line 179)*

> [!section-summary] Section 2 Summary
> Working memory as a theoretical construct emerged from the inadequacies of the Atkinson-Shiffrin multi-store model, which treated short-term memory as a single unitary buffer that was both the mandatory gateway for long-term learning and the general workspace for complex cognition. Evidence from neuropsychological dissociations, individual differences research, and Baddeley & Hitch's own dual-task experiments revealed that this single-buffer view was empirically inadequate. The 1974 multicomponent model proposed a central executive coordinating two specialized slave systems (phonological loop and visuospatial sketchpad), with a fourth component — the episodic buffer — added in 2000. The dual-task methodology became the primary empirical tool for dissecting component functions and establishing the independence and specialization of working memory subsystems.

#### 12. [DEFINITION] The Phonological Loop *(Line 191)*

> [!definition] The Phonological Loop
> The **phonological loop** is the component of working memory specialized for the temporary storage and rehearsal of phonological (sound-based) information. It consists of two subcomponents: (1) a **phonological store** — a passive buffer that can hold speech-based information for approximately 1-2 seconds before it decays, and (2) an **articulatory control process** (also called the inner voice or subvocal rehearsal mechanism) — an active process that refreshes decaying phonological representations by subvocally rehearsing them. The phonological loop evolved primarily to support language acquisition and processing, and it explains a family of well-replicated memory phenomena including the phonological similarity effect, the word-length effect, the irrelevant speech effect, and the articulatory suppression effect.

#### 13. [EXAMPLE] Phonological Loop in Language Learning *(Line 206)*

> [!example] Phonological Loop in Language Learning
> The phonological loop's role in foreign language acquisition illustrates its developmental importance. When learning a new word in a second language, the learner must temporarily hold the phonological form of the new word in the phonological store long enough to establish a stable long-term phonological representation. Research by Papagno, Valentine, and Baddeley demonstrated that patients with articulatory suppression showed dramatically impaired foreign vocabulary learning but relatively normal first-language associative learning. Children with good phonological working memory show superior foreign language acquisition. This suggests that the phonological loop is not merely a temporary storage mechanism but plays a critical role in establishing long-term [[Declarative-Memory]] representations for novel phonological forms — bridging the gap between temporary storage and permanent linguistic knowledge.

#### 14. [WARNING] Common Misconception About the Phonological Loop *(Line 209)*

> [!warning] Common Misconception About the Phonological Loop
> It is tempting to identify the phonological loop's articulatory control process straightforwardly with the subjective experience of "inner speech" or "the voice in your head." While there is overlap, the articulatory control process in the working memory model is a functional mechanism defined by its behavioral performance characteristics, not by introspective report. Moreover, not all inner speech is articulatory rehearsal — the inner monologue of planning, reasoning, and self-commentary draws on phonological working memory but also engages the [[Central-Executive]] and likely the [[Episodic-Buffer]]. The phonological loop is better understood as the dedicated storage-and-rehearsal sub-mechanism for verbal material rather than the seat of all inner speech.

#### 15. [SECTION-SUMMARY] Section 3 Summary *(Line 216)*

> [!section-summary] Section 3 Summary
> The phonological loop stores and rehearses sound-based information through a two-subcomponent architecture: a phonological store (approximately 2-second capacity) and an articulatory control process (subvocal rehearsal). Four key behavioral signatures — the phonological similarity effect, the word-length effect, the irrelevant speech effect, and articulatory suppression effects — converge to specify the loop's functional properties and constrain its architecture. The loop is specialized for verbal processing and plays critical roles in language comprehension, foreign vocabulary acquisition, reading, and following verbal instructions. Neuroimaging evidence associates the phonological store with left parietal cortex and the articulatory process with Broca's area, confirming the functional distinctions with neural specificity.

#### 17. [DEFINITION] The Visuospatial Sketchpad *(Line 228)*

> [!definition] The Visuospatial Sketchpad
> The **visuospatial sketchpad** is the component of working memory specialized for maintaining and manipulating visual and spatial information. It serves as the cognitive equivalent of a mental whiteboard — a temporary workspace for mental images, spatial layouts, visual sequences, and the manipulation of objects in imagined space. Like the phonological loop, the visuospatial sketchpad is a slave system subordinate to the [[Central-Executive]], but it operates on a distinct representational format (visual and spatial rather than phonological) and is largely independent of the phonological loop, as demonstrated by the relative absence of cross-interference between tasks that load each system.

#### 18. [EXAMPLE] The Visuospatial Sketchpad in Navigation and Design *(Line 241)*

> [!example] The Visuospatial Sketchpad in Navigation and Design
> Consider a familiar example: mentally navigating from your home to a local landmark without physically moving. To perform this task, you must maintain and update a spatial representation of your environment, tracking your simulated position relative to landmarks, turns, and distances. This task draws heavily on the inner scribe component of the visuospatial sketchpad. Now consider a different task: imaging what your friend's face looks like when she is laughing. This task invokes the visual object cache rather than the inner scribe. The fact that an experienced navigator can simultaneously recall a facial expression while planning a route (with some mutual cost) is consistent with the partial independence of the visual and spatial sub-components: they share the broader attentional resources of the [[Central-Executive]] but have some degree of independent storage capacity.

#### 19. [CLAUDE-INSIGHT] On the Sketchpad as Mental Workspace *(Line 248)*

> [!claude-insight] On the Sketchpad as Mental Workspace
> One of the most intellectually compelling aspects of the visuospatial sketchpad is the way it raises deep questions about the relationship between perception and cognition. When you mentally rotate an object, do you recruit the same neural machinery as when you actually perceive that object rotating? Neuroimaging evidence strongly suggests you do — mental imagery activates much of the same visual cortex as perceptual experience. This finding, pioneered by Stephen Kosslyn and Roger Shepard, blurs the boundary between memory and perception, suggesting that visual working memory is not a separate cognitive module but a kind of controlled re-activation of perceptual machinery — "perception from the inside." This has profound implications for how we understand visualization in learning: it suggests that vivid mental imagery is not just an elaboration strategy for encoding but a genuine perceptual re-enactment that recruits real perceptual resources. Mental models in reading comprehension, spatial diagrams in mathematics education, and physical simulation in science — all may be forms of controlled perceptual re-activation rather than abstract symbolic storage.

#### 20. [SECTION-SUMMARY] Section 4 Summary *(Line 253)*

> [!section-summary] Section 4 Summary
> The visuospatial sketchpad maintains temporary visual and spatial representations, with evidence suggesting internal differentiation into a visual cache (object features) and inner scribe (spatial/movement information) that parallels the phonological loop's architecture. Neuropsychological dissociations between visual and spatial working memory, combined with neuroimaging connecting visual working memory to perceptual cortex, support a model in which the sketchpad operates through the controlled re-activation of visual perceptual machinery. The sketchpad underpins navigation, imagery, spatial reasoning, reading comprehension (situation models), and mathematics learning. Its connection to Paivio's dual coding theory provides the working memory mechanism for Mayer's cognitive theory of multimedia learning.

#### 22. [DEFINITION] The Central Executive *(Line 265)*

> [!definition] The Central Executive
> The **central executive** is the attentional-executive component of working memory responsible for coordinating the activities of the slave systems, directing attention to relevant sources of information, inhibiting irrelevant information or prepotent responses, switching between tasks or mental sets, and integrating information across working memory subsystems. Unlike the phonological loop and visuospatial sketchpad, the central executive is a control system rather than a storage system — it has no dedicated storage capacity but operates by managing the limited attentional resources of the broader working memory system. Baddeley himself acknowledged that the central executive was initially the least-developed component of his model, describing it as a "ragbag" that captured all the executive cognitive functions not yet assigned to specific mechanisms.

#### 23. [KEY-CLAIM] The Central Executive and Individual Differences in Working Memory Capacity *(Line 276)*

> [!key-claim] The Central Executive and Individual Differences in Working Memory Capacity
> One of the most important theoretical contributions of the central executive is its role in explaining individual differences in working memory capacity. Research by Engle, Kane, and colleagues proposed that working memory capacity differences should be understood primarily as differences in **controlled attention** — the ability to maintain goal-relevant information in an active, accessible state in the face of interference and distraction — rather than as differences in the passive storage capacity of the slave systems. High-span individuals outperform low-span individuals specifically on tasks that require the maintenance of task-relevant representations against interference, while the two groups perform comparably on simple storage tasks that require no active maintenance against competing demands. This theoretical framing directly connects working memory capacity to [[Metacognitive-Self-Regulation]] and the ability to control one's own cognitive processing.

#### 24. [EXAMPLE] The Central Executive Under Cognitive Overload *(Line 281)*

> [!example] The Central Executive Under Cognitive Overload
> Consider the experience of attempting to follow a complex lecture while simultaneously taking detailed notes. Note-taking loads the phonological loop (processing the lecturer's speech) and the motor system (producing written output). The central executive must simultaneously monitor comprehension (flagging gaps or contradictions), decide which information is worth recording, coordinate the allocation of attention between listening and writing, and retrieve relevant prior knowledge to contextualize new information. When the lecture becomes too information-dense, the central executive cannot simultaneously manage all these demands. A common result is that note-taking degrades — the learner shifts to near-verbatim transcription (minimizing executive involvement) or comprehension monitoring fails as full attention is devoted to the act of writing. This experience of "losing the thread while writing furiously" is precisely the kind of central executive overload that the working memory model predicts from its architecture.

#### 25. [CLAUDE-INSIGHT] The Central Executive as Cognitive Identity *(Line 286)*

> [!claude-insight] The Central Executive as Cognitive Identity
> The central executive is, in a provocative but defensible sense, the seat of cognitive agency. The phonological loop and visuospatial sketchpad are specialized resources that operate largely automatically once activated; but the central executive is where voluntary cognitive control happens. When a skilled learner decides to stop reading passively and instead generate questions about the material — deliberately engaging [[Metacognitive-Regulation]] — that decision instantiates executive control over cognitive processing. When a deliberate practitioner of [[Deliberate-Practice]] forces their attention back to the challenging aspect of a task rather than falling back on comfortable automated responses, they are exercising central executive control. This suggests that much of what we value about disciplined, effortful cognitive work — sustained attention, self-monitoring, strategic switching, inhibition of cognitive shortcuts — is fundamentally working memory's executive control function in action. Strengthening this function, and using its limited capacity wisely, may be one of the most impactful cognitive interventions available to lifelong learners.

#### 26. [SECTION-SUMMARY] Section 5 Summary *(Line 289)*

> [!section-summary] Section 5 Summary
> The central executive is the attentional-control center of working memory, responsible for focusing, dividing, and switching attention and for interfacing with long-term memory. Drawing on Norman and Shallice's supervisory attentional system, it performs four cardinal functions: focusing, dividing, switching, and long-term memory activation. Individual differences in working memory capacity are best understood as differences in controlled attention — the ability to maintain goal-relevant representations against interference — rather than as passive storage capacity differences. The central executive is neuroanatomically associated with prefrontal cortex and connects theoretically to cognitive load theory (where central executive overload prevents schema formation) and to metacognitive self-regulation (where executive control is deployed to monitor and adjust one's own cognitive processing).

#### 28. [DEFINITION] The Episodic Buffer *(Line 301)*

> [!definition] The Episodic Buffer
> The **episodic buffer** is the fourth and most recently proposed component of Baddeley's working memory model, introduced in 2000 to address a significant theoretical gap in the original three-component architecture. It is defined as a limited-capacity temporary storage system that can hold integrated, multimodal "chunks" of information — calling on both the phonological loop and the visuospatial sketchpad, as well as information retrieved from [[Long-Term-Memory]], and integrating these into coherent, episodic representations. Unlike the slave systems, the episodic buffer does not specialize in a single representational format; instead, it serves as a multimodal integration workspace. It is accessed by the [[Central-Executive]] through conscious awareness, and it connects working memory to episodic long-term memory (in Tulving's sense) and to the phenomenal experience of the present moment.

#### 29. [EXAMPLE] The Episodic Buffer in Reading Comprehension *(Line 314)*

> [!example] The Episodic Buffer in Reading Comprehension
> Consider reading a complex passage describing a spatial scene: "The large oak table occupied the center of the room. To the left, three arched windows admitted afternoon light. Against the far wall, an oak bookcase reached the ceiling, its lower shelves crowded with thick volumes. A figure in a blue coat stood before it, reading." Comprehending this passage and holding its content in mind requires more than either the phonological loop (which stores the sounds of the words) or the visuospatial sketchpad (which maintains spatial images) can accomplish individually. The integrated scene — including spatial layout, lighting quality, the human figure, and the narrative implication of someone reading from the bookcase — requires the episodic buffer's ability to temporarily bind phonological, visual, spatial, and semantic information into a unified situational representation. This is the construct of the [[Mental-Model|situation model]] in text comprehension research, and the episodic buffer provides its working memory foundation.

#### 30. [CLAUDE-INSIGHT] The Episodic Buffer and Learning-Centered Assessment *(Line 319)*

> [!claude-insight] The Episodic Buffer and Learning-Centered Assessment
> The episodic buffer's role in integrating information from multiple sources has profound implications for how we should design learning experiences and assess understanding. A learner who cannot construct an integrated episodic representation of the material they are studying — who can recite isolated facts but cannot bind them into a coherent situational understanding — has not engaged the episodic buffer appropriately. This suggests that effective learning assessment should probe for integrative understanding rather than isolated recall: can the learner describe a scenario that combines multiple concepts? Can they mentally simulate how the material plays out in a context? Can they explain how different elements of a domain interact? These questions probe episodic-level integration in working memory, not just phonological storage. If the episodic buffer is the temporary site where deep understanding is first constructed before being consolidated into [[Long-Term-Memory]], then instructional strategies that promote multimodal, contextually integrated encoding — rather than isolated fact rehearsal — should systematically produce richer episodic buffer representations and, consequently, richer long-term learning.

#### 31. [SECTION-SUMMARY] Section 6 Summary *(Line 324)*

> [!section-summary] Section 6 Summary
> Introduced in 2000, the episodic buffer addresses the original model's inability to explain multimodal integration. It is a limited-capacity (~4 chunks) workspace that integrates information from the phonological loop, visuospatial sketchpad, and long-term memory into coherent multimodal episodic representations. Its theoretical connections to conscious awareness, to situation models in text comprehension, and to Tulving's episodic memory make it the philosophically richest component of the model. The buffer is accessed through the central executive via conscious attention and may be the primary site where deep, integrated understanding is first constructed before long-term consolidation. It remains the least empirically constrained component, but its importance for understanding reading comprehension, visual-verbal integration, and the temporary binding of complex multimodal representations is increasingly recognized.

#### 33. [WARNING] The Working Memory Training Controversy *(Line 344)*

> [!warning] The Working Memory Training Controversy
> The predictive relationships between working memory capacity and educational outcomes, combined with the promise of trainable cognitive skills, motivated significant commercial interest in working memory training programs (especially Cogmed, developed by Klingberg and colleagues). Early results appeared promising, and some neuroimaging studies reported changes in prefrontal activity following training. However, subsequent meta-analyses by Melby-Lervåg, Hulme, and colleagues (2013, 2016) found that working memory training produced robust near-transfer gains (participants improved on tasks similar to the trained tasks) but little to no far transfer to untrained cognitive functions, real-world academic performance, or intelligence. The current scientific consensus is cautious: training can improve performance on working memory tasks but does not reliably improve the broader cognitive capacities with which working memory correlates. This disconnection between near and far transfer remains a major theoretical puzzle and a practical caution for education policy.

#### 34. [CLAUDE-INSIGHT] What the Competition Between Models Reveals *(Line 353)*

> [!claude-insight] What the Competition Between Models Reveals
> The persistence of competing working memory models after more than fifty years of research might seem like a failure of the field to converge on a single correct framework. But a more generous and arguably more accurate interpretation is that the competition reveals the genuine multi-dimensional complexity of the construct. [[Cowan's-Embedded-Processes-Model]] emphasizes the continuity between long-term and working memory — challenging any sharp architectural boundary between the two. Baddeley's model emphasizes the modularity of verbal and visuospatial processing — capturing real neuroscientific dissociations. Ericsson and Kintsch's (1995) [[Long-Term-Working-Memory]] framework (not discussed in detail here) emphasizes the role of expert knowledge in massively expanding effective working memory capacity through retrieval cues in long-term memory. Together, these models triangulate the working memory construct from different theoretical vantage points, each capturing genuine phenomena that the others underemphasize. The student of cognition who internalizes all three frameworks — understanding why each was developed, what evidence supports it, where it struggles, and how it connects to the others — achieves a deeper and more practically useful understanding than one who commits to a single model as definitively correct.

#### 35. [SECTION-SUMMARY] Section 7 Summary *(Line 356)*

> [!section-summary] Section 7 Summary
> Individual differences in working memory capacity, measured through complex span tasks, predict a wide range of higher cognitive outcomes but do not straightforwardly translate into trainable skills — working memory training shows robust near-transfer but limited far-transfer effects. Cowan's embedded-processes model offers the most influential alternative to Baddeley's framework, locating working memory in activated long-term memory plus a limited focus of attention rather than specialized subsystems. The competition between models is theoretically productive, with each framework capturing genuine phenomena; future unified theories will likely need to account for both modality-specific processing (Baddeley) and modality-independent attentional limits (Cowan).

#### 37. [EXAMPLE] The Split-Attention Effect in Chemistry Instruction *(Line 378)*

> [!example] The Split-Attention Effect in Chemistry Instruction
> A chemistry textbook presents a diagram of a molecular structure on one page and its accompanying explanation on the facing page. A student must look back and forth between the diagram and the text, using working memory to maintain the partial diagram while reading the explanation, then reverting to the diagram to verify understanding. This split-attention configuration imposes extraneous cognitive load because the mental integration of diagram and text competes with the learning of the chemistry itself. CLT-based redesign would embed the explanatory text directly in the diagram, or present the labeled diagram as a single integrated source, eliminating the need for working-memory-intensive mental integration. The [[Split-Attention-Effect]] predicts that the integrated-format group will learn more from the same content because their working memory executive resources are freed for schema construction rather than format integration.

#### 38. [METHODOLOGY-AND-SOURCES] The Evidence Base of Cognitive Load Theory *(Line 387)*

> [!methodology-and-sources] The Evidence Base of Cognitive Load Theory
> CLT claims rest on three principal sources of evidence. First, behavioral comparisons of learning outcomes under different instructional conditions (worked example vs. problem-solving, integrated vs. split-attention formats, narration vs. on-screen text) have consistently shown effects in the predicted directions across hundreds of experiments and materials domains. Meta-analyses by Sweller, Mayer, and others report medium-to-large effect sizes for the key CLT effects under appropriate conditions. Second, online measures of cognitive load (secondary task performance, eye-tracking fixation patterns, physiological measures of mental effort) provide convergent validity — learners processing split-attention materials show higher extraneous load indices than learners processing integrated materials. Third, neuroimaging studies confirm that conditions predicted by CLT to impose high extraneous load do indeed show different prefrontal and parietal activation patterns, consistent with higher working memory executive demands. The primary limitation is the [[Expertise-Reversal-Effect]] constraint — predictions require knowledge of learner expertise level — and growing recognition that many CLT effects are smaller or absent in naturalistic, less controlled learning environments.

#### 39. [SECTION-SUMMARY] Section 8 Summary *(Line 390)*

> [!section-summary] Section 8 Summary
> Baddeley's working memory model is the explicit cognitive foundation of Cognitive Load Theory and Mayer's Cognitive Theory of Multimedia Learning, two of the most influential applied research programmes in educational psychology. CLT categorizes cognitive load into intrinsic (inherent complexity), extraneous (bad design), and germane (schema construction) types, with the central prescription being to reduce extraneous load to free working memory resources for germane processing. The split-attention effect, modality effect, and worked-example effect all follow from the working memory model's dual-channel, limited-capacity architecture. The expertise reversal effect qualifies all these principles: guidance that benefits novices can harm experts, because the expert's long-term schemas change the effective cognitive demands of the same material. Together, these applied frameworks demonstrate the direct practical power of the Baddeley-Hitch model as a foundation for evidence-based instructional design.

#### 41. [CLAUDE-INSIGHT] Working Memory Across the Lifespan as a Self-Development Framework *(Line 420)*

> [!claude-insight] Working Memory Across the Lifespan as a Self-Development Framework
> Understanding working memory's developmental trajectory — its rapid growth through childhood, peak in young adulthood, and gradual decline through middle and older age — provides a powerful framework for lifelong cognitive self-development. The trajectory suggests different optimal strategies at different life stages: in childhood, building phonological and visuospatial skills through language-rich and spatially engaging environments; in young adulthood, leveraging peak working memory capacity for the acquisition of complex, high-element-interactivity skills and knowledge domains; in middle age and beyond, increasingly relying on the compensatory power of [[Long-Term-Memory]] schemas to reduce intrinsic cognitive load and supplement declining working memory capacity. For the lifelong learner, this means that [[Spaced-Repetition]] and deliberate schema-building aren't merely memory techniques — they are strategic investments in long-term working memory compensation, building the long-term knowledge structures that will increasingly carry the cognitive weight as working memory capacity gradually declines. This reframes the relationship between [[Long-Term-Memory]] and working memory from a distinction between two separate systems into an adaptive partnership that shifts weight over the lifespan.

#### 42. [SECTION-SUMMARY] Section 9 Summary *(Line 423)*

> [!section-summary] Section 9 Summary
> The neural substrates of Baddeley's components are well-characterized: the phonological loop recruits left inferior parietal cortex (phonological store) and Broca's area (rehearsal); the visuospatial sketchpad recruits posterior visual and parietal regions; the central executive depends critically on DLPFC and anterior cingulate; the episodic buffer involves hippocampal-prefrontal interactions. Clinical disorders reveal the model's predictive architecture: ADHD selectively impairs central executive controlled attention; dyslexia selectively impairs phonological loop capacity; Alzheimer's disease preferentially disrupts central executive functions early in the disease; normal aging disproportionately affects prefrontal-dependent controlled attention. These clinical profiles provide converging validation for the model's component distinctions and suggest clinically relevant intervention targets.

#### 44. [METHODOLOGY-AND-SOURCES] Far Transfer Foundation *(Line 435)*

> [!methodology-and-sources] Far Transfer Foundation
> The following far-transfer analysis applies the structural principles of Baddeley's working memory model to domains outside cognitive psychology proper. Such transfers are warranted when the underlying principles — limited executive capacity, modality-specific processing channels, the compression of complexity through schema-formation — apply structurally to the target domain, even when the surface features differ entirely. Following Halpern's framework for critical thinking transfer, the analysis focuses on identifying the *deep structural principles* that make the transfer illuminating rather than merely analogical.

#### 45. [FAR-TRANSFER] Working Memory Principles in High-Stakes Performance Contexts *(Line 450)*

> [!far-transfer] Working Memory Principles in High-Stakes Performance Contexts
> In high-stakes performance contexts — surgery, air traffic control, elite sport decision-making, emergency medicine triage — the central executive's controlled attention function is directly implicated in performance quality and failure modes. The research on "choking under pressure" (Beilock et al.) reveals that performance decrements under high-stakes conditions often involve the central executive redirecting attention toward monitoring of automated skills — skills that are normally executed through automatic, working-memory-independent routines but are disrupted when executive attention monitors and interferes with their execution. This is the mechanism by which expert athletes sometimes "choke": their central executive, heightened by pressure, attends to components of movement that are best left to automated motor programs. The structural principle transferring here is: executive attention is powerful but also dangerous when directed toward overlearned, automatized skills. High-performance practitioners are advised by performance psychologists to maintain routines (reducing decision load on the central executive), control pre-performance arousal (preventing executive hyperactivation), and develop task-irrelevant focus strategies (directing the central executive away from the performance itself during execution).

#### 46. [DEFINITION] Working Memory *(Line 479)*

> [!definition] Working Memory
> **Working Memory** (Baddeley & Hitch, 1974): A limited-capacity cognitive system that temporarily maintains and manipulates information in an active, accessible state to support ongoing cognitive tasks. Distinct from both short-term memory (which it subsumes) and long-term memory (with which it interacts). Distinguished from passive short-term storage by its active, executive-controlled operations, its multicomponent architecture, and its functional role as an interface between perception, long-term memory, and current cognitive processing. See also: [[Short-Term-Memory]], [[Long-Term-Memory]], [[Memory-Systems]].

#### 47. [DEFINITION] Phonological Loop *(Line 482)*

> [!definition] Phonological Loop
> **Phonological Loop**: The verbal working memory subsystem, comprising a *phonological store* (passive temporary holding of phonological representations, susceptible to trace decay over approximately 2 seconds) and an *articulatory rehearsal process* (sub-vocal rehearsal that refreshes phonological store traces and converts visual items to phonological form). Demonstrated through four core phenomena: phonological similarity effect, word-length effect, irrelevant speech effect, articulatory suppression. Neuroanatomically: left inferior parietal cortex (store) and Broca's area / supplementary motor area (rehearsal). See: [[Phonological-Loop]], [[Phonological-Awareness]].

#### 48. [DEFINITION] Visuospatial Sketchpad *(Line 485)*

> [!definition] Visuospatial Sketchpad
> **Visuospatial Sketchpad**: The visual-spatial working memory subsystem, maintaining and manipulating visual and spatial information. Subdivided by Logie (1995) into the *visual cache* (temporary storage of visual features: color, shape, form) and the *inner scribe* (processing and rehearsing spatial sequences and movement). Doubly dissociable from the phonological loop through neuropsychological cases and secondary task interference paradigms. Neuroanatomically: posterior visual/parietal regions, right-lateralized for spatial processing. See: [[Visuospatial-Sketchpad]], [[Spatial-Cognition]].

#### 49. [DEFINITION] Central Executive *(Line 488)*

> [!definition] Central Executive
> **Central Executive**: The attentional-control component of working memory, a limited-capacity system responsible for directing attention, coordinating slave systems, switching between tasks, inhibiting irrelevant information, and interfacing with long-term memory. Theoretically based on Norman and Shallice's (1986) Supervisory Attentional System. Core functions: focusing attention, dividing attention, shifting attention, long-term memory activation. Neuroanatomically: dorsolateral prefrontal cortex (DLPFC) and anterior cingulate cortex. Different from but closely related to the broader construct of [[Executive-Function]]. See: [[Central-Executive]], [[Cognitive-Control]].

#### 50. [DEFINITION] Episodic Buffer *(Line 491)*

> [!definition] Episodic Buffer
> **Episodic Buffer** (Baddeley, 2000): The fourth component of the working memory model, added to account for multimodal integration. A limited-capacity (~4 chunks), conscious-access storage system that integrates information from the phonological loop, visuospatial sketchpad, and long-term memory into coherent, multimodal episodic representations. Connected to [[Episodic-Memory]], to conscious awareness, and to the temporary housing of situation models in reading comprehension. See: [[Episodic-Buffer]], [[Mental-Model]].

#### 51. [DEFINITION] Cognitive Load *(Line 494)*

> [!definition] Cognitive Load
> **Cognitive Load** (Sweller, 1988): The total demand placed on working memory by an instructional task, comprising intrinsic load (inherent material complexity × learner knowledge), extraneous load (poorly designed instructional format), and germane load (schema construction effort). Only germane load directly produces long-term learning. The central prescriptive claim of [[Cognitive-Load-Theory]]: reduce extraneous load to free working memory executive resources for germane processing. See: [[Intrinsic-Cognitive-Load]], [[Extraneous-Cognitive-Load]], [[Germane-Cognitive-Load]].

#### 52. [DEFINITION] Element Interactivity *(Line 497)*

> [!definition] Element Interactivity
> **Element Interactivity**: The degree to which elements of a learning task must be simultaneously held in working memory and processed together because of their mutual dependencies. High element interactivity (e.g., understanding a complex causal system) places higher intrinsic cognitive load demands than low element interactivity (e.g., isolated declarative facts). Element interactivity is reduced by expertise, because long-term schemas chunk multiple formerly separate elements into single higher-order units. See: [[Cognitive-Load-Theory]], [[Schema-Theory]].

#### 53. [DEFINITION] Phonological Similarity Effect *(Line 500)*

> [!definition] Phonological Similarity Effect
> **Phonological Similarity Effect**: The finding that sequences of phonologically similar items (letters B, C, D, G, P, T; words cat, bat, hat, mat) are recalled less accurately than sequences of phonologically distinct items, indicating that working memory stores phonological codes rather than semantic or orthographic representations. This demonstrates that the phonological loop operates on sound-based representations, and that confusability in that dimension directly degrades recall. See: [[Phonological-Loop]], [[Phonological-Awareness]].

#### 54. [DEFINITION] Word-Length Effect *(Line 503)*

> [!definition] Word-Length Effect
> **Word-Length Effect**: The finding that fewer long words are recalled from a list than short words in immediate serial recall, when word frequency and phonological distinctiveness are controlled. The explanation: the articulatory rehearsal loop can cycle more short words than long words within the ~2-second window before phonological traces decay. However, the effect is eliminated when articulatory suppression prevents rehearsal (showing its dependence on the rehearsal component), and recent research has found the effect to be smaller and less reliable than originally thought in some conditions.

#### 55. [DEFINITION] Articulatory Suppression *(Line 506)*

> [!definition] Articulatory Suppression
> **Articulatory Suppression**: The concurrent production of an irrelevant spoken utterance (e.g., "the, the, the" or "blah, blah, blah") that prevents articulatory rehearsal, thereby blocking the refreshment of phonological store traces and eliminating the acoustic coding advantage for verbal material presentation. Articulatory suppression is the primary behavioral manipulation used to isolate phonological store contributions from rehearsal contributions in working memory experiments.

#### 56. [DEFINITION] Supervisory Attentional System (SAS) *(Line 509)*

> [!definition] Supervisory Attentional System (SAS)
> **Supervisory Attentional System** (Norman & Shallice, 1986): A theoretical control system that intervenes in cognitive processing when tasks are novel, difficult, or require inhibition of habitual responses. Normal routine behavior is governed by contention scheduling (automatic schema activation); the SAS overrides contention scheduling when required, directing attention toward goal-relevant processing. Adopted by Baddeley as the provisional theoretical model for the central executive. See: [[Executive-Function]], [[Cognitive-Control]].

#### 57. [DEFINITION] Complex Span Tasks *(Line 512)*

> [!definition] Complex Span Tasks
> **Complex Span Tasks** (Daneman & Carpenter, 1980): Working memory capacity measures that interleave processing demands (verifying equations, judging sentence acceptability, counting items) with storage demands (remembering a set of items for later recall). Complex span scores predict higher cognitive abilities (reading comprehension, reasoning, fluid intelligence) substantially more powerfully than simple span tasks (digit span) because they require central executive engagement — the controlled maintenance of information against concurrent demand.

#### 58. [DEFINITION] Expertise Reversal Effect *(Line 515)*

> [!definition] Expertise Reversal Effect
> **Expertise Reversal Effect** (Kalyuga et al., 2003): The finding in [[Cognitive-Load-Theory]] research that instructional guidance beneficial for novices loses effectiveness and can become harmful for experts. As expertise develops, long-term schemas reduce intrinsic load, making scaffolding redundant and potentially imposing extraneous load by requiring experts to process instructional guidance they no longer need. This reversal limits the generalizability of any single instructional approach across learner expertise levels and motivates adaptive instruction. See: [[Expertise-Reversal-Effect]], [[Deliberate-Practice]].

#### 59. [DEFINITION] Situation Model *(Line 518)*

> [!definition] Situation Model
> **Situation Model** (van Dijk & Kintsch, 1983): A mental representation of the state of affairs described by a text, incorporating spatial layout, causal structure, agent intentions, and temporal sequence — beyond the surface text base or propositional structure. Situation models require the episodic buffer to integrate verbal information from the phonological loop with visuospatial imagery from the sketchpad and semantic knowledge from long-term memory into a coherent, temporarily accessible representation. Comprehension depth is assessed by probing situation model quality. See: [[Mental-Model]], [[Episodic-Buffer]].

#### 60. [PERSON] Alan D. Baddeley (1934– ) *(Line 525)*

> [!person] Alan D. Baddeley (1934– )
> **Alan Baddeley** is the founder and primary architect of the multicomponent working memory model. His 2000 review in *Nature Reviews Neuroscience* remains one of the most cited papers in cognitive psychology. Baddeley's work spans the entire developmental arc of the model from 1974 through the 2000 episodic buffer addition and subsequent empirical work. He served as Director of the Medical Research Council's Applied Psychology Unit (APU) in Cambridge, which produced many of the key empirical studies supporting the model. His broader research programme addresses amnesia, prospective memory, and the relationship between working memory and long-term memory consolidation.

#### 61. [PERSON] Graham Hitch (1945– ) *(Line 528)*

> [!person] Graham Hitch (1945– )
> **Graham Hitch** co-developed the multicomponent model with Baddeley in the landmark 1974 paper. His sustained contributions to the empirical investigation of working memory — particularly the phonological loop's role in cognitive development and mathematical cognition — extended the model's scope across the lifespan. His later work with Christopher Jarrold on working memory and developmental disability has influenced understanding of intellectual developmental disorders.

#### 62. [PERSON] Nelson Cowan (1951– ) *(Line 531)*

> [!person] Nelson Cowan (1951– )
> **Nelson Cowan** developed the embedded-processes model of working memory as the primary theoretical alternative to Baddeley's multicomponent framework. His 2001 capacity estimate of ~4 chunks in the focus of attention has become a widely cited marker of working memory's fundamental limit. His work on the development of working memory in childhood (alongside colleagues including Candice Morey and Christopher Jarrold) has been particularly influential on developmental cognitive psychology.

#### 63. [PERSON] John Sweller *(Line 534)*

> [!person] John Sweller
> **John Sweller** developed [[Cognitive-Load-Theory]] explicitly from Baddeley's working memory architecture, first articulating the theory in his 1988 paper on cognitive load during problem-solving. His programme of research identified the split-attention effect, the worked-example effect, the modality effect, and many other instructional phenomena predicted by CLT, and his collaborations with Fred Paas, Paul Chandler, and others produced the extensive meta-analytic evidence base that CLT now rests on.

#### 64. [PERSON] Richard Mayer (1947– ) *(Line 537)*

> [!person] Richard Mayer (1947– )
> **Richard Mayer** developed the [[Cognitive-Theory-of-Multimedia-Learning]] in parallel with CLT, drawing on Baddeley's dual-channel architecture to produce twelve multimedia design principles supported by a large body of controlled experimental evidence. His textbook *Multimedia Learning* (2001; 2nd ed. 2009) is one of the most widely used educational psychology references internationally. His research on the modality effect, coherence principle, and segmenting principle has directly informed e-learning design worldwide.

#### 65. [TENSION] Modular Architecture vs. Activated Long-Term Memory *(Line 570)*

> [!tension] Modular Architecture vs. Activated Long-Term Memory
> **The Central Tension**: Baddeley's model proposes specialized short-term storage systems (phonological loop, visuospatial sketchpad) as structurally distinct from long-term memory. Cowan's model (and to some extent Ericsson & Kintsch's long-term working memory) proposes that working memory is fundamentally activated long-term memory — there are no separate short-term stores, only different activation states of long-term memory representations. Each position captures real phenomena: the phonological similarity effect, word-length effect, and neuroanatomical dissociations strongly support specialized phonological processing (Baddeley). But the massive expansion of effective working memory in experts and the seamless integration of long-term knowledge into working memory operations support the activated-LTM view (Cowan, Ericsson). **Current Status**: Unresolved. Most working memory researchers accept elements of both positions without a unified framework.

#### 66. [OPEN-QUESTION] Is Working Memory Capacity Trainable? *(Line 573)*

> [!open-question] Is Working Memory Capacity Trainable?
> The stakes are high: if working memory capacity is trainable, it could be a target for educational and clinical intervention. The evidence says: near-transfer gains (improvements on trained and similar tasks) are robust from working memory training programs. Far-transfer gains to untrained cognitive functions (reading comprehension, mathematics, intelligence) are not reliably produced by current training protocols. The theoretical question is whether this near-transfer specificity reflects a fundamental architectural limit (capacity is fixed and cannot be expanded, only redistributed) or a training methodology problem (current protocols are not the right kind of training to produce transfer). **Current Status**: Majority of meta-analytic evidence suggests limited far-transfer; the question remains theoretically open and practically important.

#### 67. [DEBATE] The Central Executive: Unified System or Coordinated Processes? *(Line 576)*

> [!debate] The Central Executive: Unified System or Coordinated Processes?
> Baddeley's central executive is often critiqued as a "homunculus" — a theoretical entity that does whatever the rest of the model cannot explain. Its specification via Norman and Shallice's SAS has been productive but critics (including Baddeley himself) note that the central executive remains theoretically underspecified compared to the slave systems. Miyake et al.'s fractionation of executive functions into shifting, updating, and inhibition components represents one approach to replacing the unitary executive with a set of coordinated, separable processes. **Current Status**: The unity-and-diversity debate continues, with evidence that executive functions are partially correlated (consistent with a shared underlying resource) but empirically separable (inconsistent with a single unitary executive). The resolution likely lies in specifying both the shared resource and the distinct contributing processes.

#### 68. [TENSION] The Episodic Buffer: Genuine Component or Theoretical Convenience? *(Line 579)*

> [!tension] The Episodic Buffer: Genuine Component or Theoretical Convenience?
> Although the episodic buffer addresses real theoretical gaps (multimodal integration, the KC case, situation models), critics argue that it is less an independently motivated theoretical component than an ad hoc addition to fix the original model's shortcomings — essentially relocating all the model's unexplained processes into a new black box rather than explaining them. Supporters argue the buffer has generated genuine new predictions (cross-domain binding tasks, consciousness connections) that have been successfully tested. **Current Status**: The episodic buffer is accepted as a useful organizing construct, but its mechanistic specification and relationship to the central executive and to episodic long-term memory require further theoretical development.

#### 69. [OPEN-QUESTION] Working Memory and Consciousness *(Line 582)*

> [!open-question] Working Memory and Consciousness
> The episodic buffer's proposed connection to conscious awareness raises deep questions about the relationship between working memory and consciousness more broadly. Baars' Global Workspace Theory and Baddeley's working memory model share structural similarities — both involve a limited-capacity workspace that makes information globally available for cognitive processing, and both connect this availability to consciousness. Is working memory the cognitive architecture of consciousness? Or is working memory a functional architecture that sometimes, but not always, involves conscious awareness? **Current Status**: Philosophically alive, empirically difficult to resolve. The connection between working memory capacity and the stability of conscious representations (persistence of visual experience across eye movements, maintenance of auditory scenes) is an active research area.

#### 70. [TENSION] Developmental Working Memory — Capacity Growth or Strategy Development? *(Line 585)*

> [!tension] Developmental Working Memory — Capacity Growth or Strategy Development?
> Working memory capacity increases substantially across childhood from approximately age 4 through early adulthood. The developmental mechanism is contested: does working memory capacity grow because of increasing neural efficiency (faster processing speeds reduce decay, enabling more rehearsal), because of increasing knowledge (allowing chunking that compresses information), or because of the development of executive control strategies? The answer matters practically: if capacity growth is primarily strategy development and knowledge accumulation, educational interventions that build both might accelerate cognitive development more effectively than interventions targeting capacity directly. **Current Status**: All three mechanisms likely contribute, with relative weighting debated.

#### 85. [FLASHCARD] Definition: Working Memory *(Line 655)*

> [!flashcard] Definition: Working Memory
> **Q:** What is the difference between working memory and short-term memory, and why does the distinction matter?
> **A:** Short-term memory refers to any passive temporary storage of information; working memory additionally involves active manipulation as well as multiple specialized components (phonological loop, visuospatial sketchpad, central executive, episodic buffer). The distinction matters because simple digit-span measures of short-term memory fail to predict higher cognitive functioning, while complex span measures of working memory (which engage executive attention) strongly predict reasoning, comprehension, and learning outcomes.

#### 86. [FLASHCARD] Definition: Phonological Loop Phenomena *(Line 659)*

> [!flashcard] Definition: Phonological Loop Phenomena
> **Q:** Name and briefly explain the four core phenomena demonstrating the phonological loop's architecture.
> **A:** (1) *Phonological similarity effect*: phonologically similar sequences are harder to recall (shows phonological coding). (2) *Word-length effect*: fewer long words recalled than short words (shows rehearsal buffer time-limited). (3) *Irrelevant speech effect*: background speech impairs verbal recall even when ignored (shows automatic access to phonological store). (4) *Articulatory suppression*: speaking concurrently eliminates word-length effect and disrupts phonological coding (shows rehearsal's dependence on articulatory motor programming).

#### 87. [FLASHCARD] Distinction: Slave Systems vs. Central Executive *(Line 663)*

> [!flashcard] Distinction: Slave Systems vs. Central Executive
> **Q:** What is the fundamental distinction between the slave systems (phonological loop, visuospatial sketchpad) and the central executive in Baddeley's model?
> **A:** Slave systems are dedicated storage and maintenance buffers for specific representational formats (phonological/verbal; visuospatial). They operate with relative automaticity once activated. The central executive is a domain-general, limited-capacity attentional control system with no dedicated storage — it manages attention, coordinates slave systems, inhibits irrelevant information, and interfaces with long-term memory. It is the executive control that makes working memory "working."

#### 88. [FLASHCARD] Process: Cognitive Load Reduction *(Line 667)*

> [!flashcard] Process: Cognitive Load Reduction
> **Q:** According to Cognitive Load Theory, what is the primary goal of instructional design, and what is the mechanism linking it to learning?
> **A:** The primary goal is to reduce *extraneous cognitive load* (load imposed by poor instructional format) while preserving *germane cognitive load* (effort invested in schema construction). When extraneous load is reduced, working memory executive resources are freed for the active integration and elaboration of new information into long-term schemas — which is the mechanism of learning. Without freed executive capacity, the learner processes the material but cannot invest cognitive effort in schema formation.

#### 89. [FLASHCARD] Application: Split-Attention Effect *(Line 671)*

> [!flashcard] Application: Split-Attention Effect
> **Q:** What is the split-attention effect and what instructional design principle does it motivate?
> **A:** The split-attention effect is the finding that learners who must mentally integrate information from physically or temporally separated sources perform worse than those who process the same information in an integrated format. The mechanism is that mental integration itself consumes working memory executive resources, leaving less capacity for learning. The design principle is *spatial and temporal contiguity*: place related text and diagrams physically adjacent (spatial contiguity) and present complementary narration and animation simultaneously rather than sequentially (temporal contiguity).

#### 90. [FLASHCARD] Distinction: Near vs. Far Transfer in WM Training *(Line 675)*

> [!flashcard] Distinction: Near vs. Far Transfer in WM Training
> **Q:** What is the difference between near and far transfer in the context of working memory training, and what does the evidence show?
> **A:** *Near transfer*: improvement on tasks similar to the trained tasks (e.g., train on one working memory span task, improve on other span tasks). *Far transfer*: improvement on untrained, conceptually distinct cognitive abilities (reading comprehension, mathematics, fluid intelligence). Evidence: near transfer is consistently found in WM training studies; far transfer is generally *not* found in well-controlled conditions (Melby-Lervåg & Hulme, 2013). The implication: WM training improves WM task performance without expanding the broader cognitive capacity associated with WM.

#### 91. [FLASHCARD] Connection: Episodic Buffer and Reading Comprehension *(Line 679)*

> [!flashcard] Connection: Episodic Buffer and Reading Comprehension
> **Q:** How does the episodic buffer explain the comprehension of complex narratives that exceed the capacity of the phonological loop or visuospatial sketchpad alone?
> **A:** Complex narrative comprehension requires integrating verbal content (phonological loop), physical scene descriptions (visuospatial sketchpad), semantic knowledge (long-term memory), and temporal/causal structure into a unified situation model. The episodic buffer provides the temporary multimodal integration workspace where this binding occurs — it can hold approximately 4 chunks of integrated multimodal information, where each "chunk" is a rich episodic representation combining verbal, visual, spatial, and semantic features. Without the episodic buffer, the model cannot explain how working memory maintains complex situation models during reading.

#### 92. [FLASHCARD] Application: Working Memory in ADHD vs. Dyslexia *(Line 683)*

> [!flashcard] Application: Working Memory in ADHD vs. Dyslexia
> **Q:** How do the working memory profiles in ADHD and dyslexia differ, and what does this selectivity reveal about working memory architecture?
> **A:** ADHD: selective impairment in central executive functions (controlled attention, updating, inhibition, task-switching) with relatively preserved simple phonological span. Dyslexia: selective impairment in phonological loop capacity (reduced digit span, impaired non-word repetition, low phonological awareness) with relatively preserved visuospatial and executive functions. The selectivity demonstrates the independence of working memory components: ADHD implicates prefrontal executive systems; dyslexia implicates left inferior parietal/Broca's area phonological systems. Each disorder validates the model's architectural distinctions.

#### 93. [FLASHCARD] Definition: Expertise Reversal Effect *(Line 687)*

> [!flashcard] Definition: Expertise Reversal Effect
> **Q:** What is the expertise reversal effect and why does it challenge the universal application of CLT instructional principles?
> **A:** The expertise reversal effect: instructional guidance that helps novices learn can actually impair learning in more advanced learners. As expertise grows, long-term schemas reduce the intrinsic load of the material, and scaffolding becomes redundant and forces processing of information the expert already knows — imposing extraneous load without benefit. This challenges universal application of CLT principles because the optimal instructional format depends on learner expertise: worked examples for novices; problem-solving for experts; faded guidance for learners transitioning between these stages.

#### 94. [FLASHCARD] Distinction: Baddeley vs. Cowan Models *(Line 691)*

> [!flashcard] Distinction: Baddeley vs. Cowan Models
> **Q:** What is the fundamental architectural difference between Baddeley's multicomponent model and Cowan's embedded-processes model?
> **A:** Baddeley: proposes specialized short-term storage subsystems (phonological loop, visuospatial sketchpad) that are structurally distinct from long-term memory, with capacity determined by modality-specific mechanisms. Cowan: proposes working memory is simply activated long-term memory — a subset of activated representations held in a limited focus of attention (~3-4 chunks, modality-independent). No specialized short-term stores; just different activation levels of long-term memory. Key difference: Baddeley predicts modality-specific capacity limits; Cowan predicts a single modality-independent capacity limit for the focus of attention.

#### 95. [FLASHCARD] Process: Central Executive Functions *(Line 695)*

> [!flashcard] Process: Central Executive Functions
> **Q:** What are the four principal functions of the central executive in Baddeley's model?
> **A:** (1) *Focusing attention*: selecting relevant information from competing inputs and maintaining goal-relevant representations. (2) *Dividing attention*: distributing attentional resources across multiple concurrent tasks. (3) *Switching attention*: flexibly shifting between task sets, retrieval strategies, or mental representations (with associated switching costs). (4) *Interfacing with long-term memory*: selectively activating relevant long-term knowledge to support current working memory operations, enabling reasoning and comprehension tasks that require integration of stored knowledge with new information.

#### 96. [FLASHCARD] Application: Modality Effect in Multimedia Learning *(Line 699)*

> [!flashcard] Application: Modality Effect in Multimedia Learning
> **Q:** What is the modality effect in multimedia learning, how does Baddeley's model explain it, and what is its design implication?
> **A:** The modality effect: learning is better when complex visual material is accompanied by spoken narration rather than on-screen text. Baddeley's explanation: text and diagram compete for the same visuospatial processing channel, causing bottleneck. Narration and diagram use separate channels (phonological loop for narration; visuospatial sketchpad for diagram), allowing parallel processing and more total information capacity. Design implication: for complex animated or diagrammatic material, use spoken narration rather than on-screen explanatory text to exploit the dual-channel architecture of working memory.

### 1. Working-Memory-Definition

> [!definition] Working-Memory-Definition
> A multicomponent cognitive system responsible for the temporary maintenance and active manipulation of information during ongoing cognitive tasks such as reasoning, language comprehension, learning, and decision-making (Baddeley & Hitch, 1974; Baddeley, 2000, 2012).

### 2. Working-Memory-vs-Short-Term-Memory

> [!definition] Working-Memory-vs-Short-Term-Memory
> Short-term memory refers to passive temporary storage of information, typically measured by span tasks requiring simple retention; working memory adds the requirement of simultaneous processing or manipulation, making it a better predictor of complex cognitive performance including reading comprehension, reasoning, and academic achievement.

*Source: Line 136 in `baddeley-model-of-working-memory-foundational-report-2026-04-03.md`*

### 3. Multi-Store-Model-Limitations

> [!definition] Multi-Store-Model-Limitations
> The Atkinson-Shiffrin multi-store model's single short-term store could not account for: (1) neuropsychological dissociations showing STS damage with intact LTM learning; (2) the poor correlation between simple digit span and complex cognitive performance; (3) the functional inadequacy of a single passive buffer as a workspace for complex cognition; and (4) evidence for separate verbal and visuo-spatial short-term storage systems.

*Source: Line 161 in `baddeley-model-of-working-memory-foundational-report-2026-04-03.md`*

### 4. Working-Memory-Historical-Pivot

> [!definition] Working-Memory-Historical-Pivot
> The shift from Atkinson-Shiffrin's multi-store model to Baddeley-Hitch's multicomponent working memory model represented a transition from treating temporary memory as a passive storage buffer to treating it as an active, multicomponent workspace. This shift redirected memory research toward understanding how distinct specialized systems collaborate under central Executive control to support complex cognition.

*Source: Line 177 in `baddeley-model-of-working-memory-foundational-report-2026-04-03.md`*

### 5. Phonological-Loop-Architecture

> [!definition] Phonological-Loop-Architecture
> The phonological loop comprises a phonological store (passive, phonological, approximately 1-2 second decay) and an articulatory control process (active rehearsal mechanism, inner voice). The phonological similarity effect reveals the storage format (phonological); the word-length effect reveals the rehearsal mechanism's time-limited operation (words rehearsable within approximately 2 seconds determine span); articulatory suppression eliminates both effects, confirming that both depend on the articulatory process.

*Source: Line 200 in `baddeley-model-of-working-memory-foundational-report-2026-04-03.md`*

### 6. Visuospatial-Sketchpad-Architecture

> [!definition] Visuospatial-Sketchpad-Architecture
> The visuospatial sketchpad maintains temporary visual and spatial representations. Evidence from dual-task studies suggests a distinction between a visual cache (object features: color, form, texture) and an inner scribe (spatial/sequential information, responsible for image refreshal). This distinction mirrors the phonological loop's storage-rehearsal architecture. Neuropsychologically, visual working memory draws on occipital and temporal cortex, while spatial working memory draws more heavily on parietal cortex and supplementary motor areas.

### 9. Working-Memory-Capacity-Measurement

> [!definition] Working-Memory-Capacity-Measurement
> Complex span tasks (Reading Span, Operation Span, Counting Span) measure working memory capacity by requiring concurrent storage and processing. Simple span tasks measure only the capacity of the slave systems (particularly the phonological loop) without engaging executive attention. The predictive validity of complex span tasks for higher cognition is substantially higher than simple span, supporting Engle's view that working memory capacity is fundamentally a measure of controlled attention.

### 10. Cowan-vs-Baddeley

> [!definition] Cowan-vs-Baddeley
> Baddeley's model proposes specialized subsystems (phonological loop, visuospatial sketchpad) as dedicated short-term stores with their own specific capacities and mechanisms. Cowan's model proposes that working memory is activated long-term memory plus a limited attentional focus — no specialized stores, just degrees of activation. The key empirical dispute concerns whether phonological information receives specialized treatment (supporting Baddeley) or simply receives higher activation due to its salience (supporting Cowan).

*Source: Line 349 in `baddeley-model-of-working-memory-foundational-report-2026-04-03.md`*

### 11. Cognitive-Load-Types

> [!definition] Cognitive-Load-Types
> (1) *Intrinsic load*: arising from the inherent complexity of the material and the number of elements that must be simultaneously processed (element interactivity), reduced by prior knowledge and schema automation; (2) *Extraneous load*: arising from poorly designed instructional materials that direct cognitive resources toward processing irrelevant to learning (e.g., searching for information, resolving unnecessary split attention); (3) *Germane load*: cognitive effort invested in constructing, elaborating, and automating new schemas — the only cognitive load that directly contributes to long-term learning.

*Source: Line 372 in `baddeley-model-of-working-memory-foundational-report-2026-04-03.md`*

### 12. Working-Memory-Neural-Architecture

> [!definition] Working-Memory-Neural-Architecture
> Phonological store: left inferior parietal cortex (supramarginal gyrus). Articulatory rehearsal: Broca's area (left inferior frontal gyrus) + supplementary motor area. Visuospatial sketchpad: posterior visual/parietal regions, right-lateralized for spatial processing. Central executive: dorsolateral prefrontal cortex (DLPFC) + anterior cingulate cortex. Episodic buffer: less well-characterized but associated with hippocampal-prefrontal interactions, consistent with its role in binding and its connection to episodic long-term memory.
