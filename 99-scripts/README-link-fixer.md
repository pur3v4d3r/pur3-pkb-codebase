# 99-scripts — PKB Link Automation

Scripts for fixing and maintaining wiki-links across the Obsidian vault.

---

## The Problem

Reports and notes generated by LLMs often produce wiki-links with **spaces**:

```
[[Transfer of Learning]]
[[Cognitive Load Theory]]
```

But the permanent notes on disk use **kebab-case** filenames:

```
Transfer-of-Learning.md
Cognitive-Load-Theory.md
```

Obsidian treats these as different targets, creating **thousands** of ghost/broken links — even though the actual notes exist.

---

## Scripts

### `normalise_wikilinks.py` — Reusable Wiki-Link Fixer

The primary, reusable script.  Directly scans your source files for wiki-links, matches them against permanent notes by normalised name, and rewrites `[[Space Name]]` → `[[Kebab-Name]]`.

**No dependency on a broken-links output file** — just point it at your source files and your permanent notes folder.

#### Quick Start

```bash
# Activate venv
.venv\Scripts\activate     # Windows
source .venv/bin/activate   # macOS/Linux

# Dry run — scan a folder of new reports
python 99-scripts/normalise_wikilinks.py --scan "00-inbox/01-reports"

# Dry run — scan entire vault
python 99-scripts/normalise_wikilinks.py

# Apply changes
python 99-scripts/normalise_wikilinks.py --scan "00-inbox/01-reports" --execute

# Also add aliases to permanent notes (belt-and-suspenders)
python 99-scripts/normalise_wikilinks.py --scan "00-inbox/01-reports" --add-aliases --execute
```

#### Options

| Flag | Default | Description |
|------|---------|-------------|
| `--vault PATH` | `D:/10_pur3v4d3r's-vault` | Path to vault root |
| `--perm-dir PATH` | `999-report-orginizing/_permanent-notes/_permanent-notes` | Permanent notes folder (repeatable) |
| `--scan PATH` | entire vault | Relative path to file or folder to scan |
| `--add-aliases` | off | Also add space-based aliases to permanent note frontmatter |
| `--execute` | off (dry run) | Apply changes — without this flag, nothing is modified |

#### Typical Workflow for New Reports

1. Generate reports and place them in `00-inbox/01-reports/` (or any folder).
2. Run a dry-run to preview:
   ```bash
   python 99-scripts/normalise_wikilinks.py --scan "00-inbox/01-reports"
   ```
3. Review the output — confirm the rewrites look correct.
4. Execute:
   ```bash
   python 99-scripts/normalise_wikilinks.py --scan "00-inbox/01-reports" --execute
   ```
5. Open Obsidian — links should now resolve correctly.

### `fix_ghost_to_permanent.py` — Original Ghost-Link Fixer

The original script used during the initial mass-fix session.  Parses the `broken links output.md` file from Obsidian's broken-links plugin to identify ghost links, then cross-references against permanent notes.

**Use `normalise_wikilinks.py` instead for new work** — this script is kept for reference.

---

### `broken_link_fixer.py` — Multi-Phase Broken Link Fixer

Handles other categories of broken links beyond the space-vs-kebab mismatch:

- **Junk links**: Removes links pointing at `.obsidian`, `.smart-env`, `.git` internals
- **Path-based links**: Attempts to resolve broken folder paths
- **Date stubs**: Creates missing daily/weekly/monthly/quarterly note stubs
- **Concept stubs**: Creates placeholder notes for unresolved concept links

```bash
python 99-scripts/broken_link_fixer.py --vault "D:/10_pur3v4d3r's-vault" --clean-junk --fix-paths --create-dates
python 99-scripts/broken_link_fixer.py --vault "D:/10_pur3v4d3r's-vault" --clean-junk --fix-paths --create-dates --execute
```

## Safety

All scripts default to **dry-run mode**.  Nothing is modified until you pass `--execute`.

The batch frontmatter scripts create backups.  The link-rewriting scripts operate on text content only (no file moves/deletes).
