# Batch: Memory & Metacognitive Judgment Gaps

## Judgment of Learning JOL

- domain: cognitive-science
- secondary_domains: [metacognition, memory-research]
- aliases: [JOL, judgment of learning]
- broader: [metacognitive-monitoring]
- related: [feeling-of-knowing-fok, calibration, ease-of-learning-judgment, retrieval-practice]
- prerequisites: [metacognition, long-term-memory]
- confidence: high

**definition**: A Judgment of Learning JOL is a learner's prospective estimate, made shortly after study, of the probability that a recently encoded item will be retrievable on a later test, and it is the most widely studied class of metacognitive monitoring judgment in the Nelson-Narens framework.

**key_claim**: Judgment of Learning JOL accuracy improves dramatically when the judgment is made on a delay rather than immediately after study, because delayed Judgment of Learning JOL relies on retrieval cues that diagnose long-term retention rather than on momentary fluency in [[working-memory]].

**warning**: A Judgment of Learning JOL is systematically inflated by perceptual fluency cues such as font legibility, fluent re-reading, and massed repetition; conflating high Judgment of Learning JOL confidence with actual learning is the mechanism behind the [[illusion-of-fluency]] and overconfident exam preparation.

## Feeling of Knowing FOK

- domain: cognitive-science
- secondary_domains: [metacognition, memory-research]
- aliases: [FOK, feeling-of-knowing judgment]
- broader: [metacognitive-monitoring]
- related: [judgment-of-learning-jol, tip-of-the-tongue-phenomenon, cue-utilization-framework]
- prerequisites: [metacognition, semantic-memory]
- confidence: high

**definition**: A Feeling of Knowing FOK is a metacognitive judgment that an unrecalled item is nonetheless stored in memory and would be recognized if presented, distinguishing genuine retrieval failure from genuine non-encoding within the Nelson-Narens monitoring architecture.

**key_claim**: The Feeling of Knowing FOK is generated heuristically from cue familiarity and partial-information accessibility rather than from direct inspection of the memory trace, which explains why Feeling of Knowing FOK accuracy is reliably above chance but well below ceiling.

**warning**: A high Feeling of Knowing FOK does not guarantee that the item will be produced under retrieval conditions; treating Feeling of Knowing FOK as evidence of mastery — rather than as evidence of partial accessibility — is a common metacognitive error that suppresses corrective study behaviour.

## State Dependent Memory

- domain: cognitive-science
- secondary_domains: [memory-research]
- aliases: [state-dependent retrieval, mood-congruent recall]
- broader: [encoding-specificity-principle]
- related: [context-dependent-memory, transfer-appropriate-processing, encoding-variability]
- prerequisites: [encoding-specificity-principle, long-term-memory]
- confidence: high

**definition**: State Dependent Memory is the empirical phenomenon that material encoded while a learner is in a particular internal state — pharmacological, emotional, or physiological — is retrieved more effectively when the same internal state is reinstated at test, even when the external context is held constant.

**key_claim**: State Dependent Memory is a special case of the encoding-specificity principle in which the matching cue is internal rather than environmental, and the size of the State Dependent Memory effect scales with how distinctive the encoding state is from the learner's baseline.

**warning**: State Dependent Memory is sometimes invoked to explain everyday forgetting, but the effect is largest in pharmacological studies and substantially weaker for ordinary mood fluctuations; over-generalizing State Dependent Memory to "I learn better when I'm in a good mood" misrepresents the empirical scope.

## Blocked Practice

- domain: cognitive-science
- secondary_domains: [learning-science, instructional-design]
- aliases: [massed practice schedule]
- broader: [practice-schedule]
- related: [interleaving, desirable-difficulties, distributed-practice, spacing-effect]
- prerequisites: [long-term-memory, transfer-of-learning]
- confidence: high

**definition**: Blocked Practice is a training schedule in which all trials of a single skill, problem type, or concept are completed consecutively before moving to the next, contrasting with interleaved schedules that intermix categories within a session.

**key_claim**: Blocked Practice produces faster within-session performance gains and higher learner-perceived fluency than interleaved practice, but it consistently yields weaker long-term retention and weaker transfer to novel discrimination problems — a textbook case of performance-during-training diverging from learning.

**warning**: The superior in-session performance of Blocked Practice creates a metacognitive trap in which both learners and instructors prefer Blocked Practice because it feels productive, even though the comparative literature treats Blocked Practice as the inferior schedule for any goal that requires durable category discrimination.

## Mastery Experience

- domain: educational-psychology
- secondary_domains: [motivational-psychology]
- aliases: [enactive mastery, performance accomplishment]
- broader: [self-efficacy-theory]
- related: [enactive-mastery-experience, vicarious-experience, verbal-persuasion, self-efficacy]
- prerequisites: [self-efficacy, social-cognitive-theory]
- confidence: high

**definition**: A Mastery Experience is a first-person episode of successfully accomplishing a challenging task that, in Bandura's social-cognitive theory, serves as the most potent and durable source of self-efficacy beliefs about a given domain.

**key_claim**: A Mastery Experience raises self-efficacy more strongly than any other source — vicarious modelling, verbal persuasion, or physiological inference — because a Mastery Experience supplies direct, attribution-bearing evidence that effort and strategy produced the outcome.

**warning**: Not every successful performance functions as a Mastery Experience; a success attributed to luck, low difficulty, or external help fails to update efficacy beliefs, which is why instructional designers must scaffold both the success itself and the causal attribution that converts the success into a usable Mastery Experience.

## Cued Recall

- domain: cognitive-science
- secondary_domains: [memory-research]
- aliases: [prompted retrieval]
- broader: [retrieval-practice]
- related: [free-recall, recognition-memory, encoding-specificity-principle, transfer-appropriate-processing]
- prerequisites: [long-term-memory, retrieval-practice]
- confidence: high

**definition**: Cued Recall is a memory test in which the learner is given a partial cue — a category label, a paired-associate stem, a fill-in-the-blank context — and must produce the missing target, occupying the middle band of retrieval difficulty between recognition and free recall.

**key_claim**: Cued Recall reveals knowledge that free recall fails to surface because the cue diagnoses accessibility rather than availability, demonstrating the well-established distinction that memory traces can be stored but inaccessible without an appropriate Cued Recall prompt.

**warning**: A high Cued Recall score does not imply that the learner can use the same knowledge under uncued conditions; transfer to free production environments such as essays or open-ended problem solving requires explicit practice beyond Cued Recall drills.

## Free Recall

- domain: cognitive-science
- secondary_domains: [memory-research]
- aliases: [unaided recall]
- broader: [retrieval-practice]
- related: [cued-recall, recognition-memory, serial-position-effect, encoding-variability]
- prerequisites: [long-term-memory, retrieval-practice]
- confidence: high

**definition**: Free Recall is a memory test in which the learner is asked to produce as much of the studied material as possible in any order, with no external cues beyond the general retrieval instruction, making Free Recall the most stringent of the standard memory measures.

**key_claim**: Free Recall is a more diagnostic test of durable, transfer-ready knowledge than recognition or cued recall because the absence of external cues forces the learner to generate retrieval pathways internally, which is why Free Recall practice produces stronger long-term retention than re-reading or recognition study.

**warning**: Free Recall is also the most punishing test format for beginners; using Free Recall too early in the learning curve can produce repeated retrieval failure, which damages motivation without producing the testing-effect benefits that emerge once partial knowledge is in place.

## Proactive Interference

- domain: cognitive-science
- secondary_domains: [memory-research]
- aliases: [proactive inhibition, PI]
- broader: [memory-interference]
- related: [retroactive-interference, release-from-proactive-interference, similarity-based-confusion]
- prerequisites: [long-term-memory, working-memory]
- confidence: high

**definition**: Proactive Interference is the phenomenon in which previously learned material disrupts the encoding or retrieval of subsequently learned similar material, and it is one of the two principal interference mechanisms recognised in the classical memory literature.

**key_claim**: Proactive Interference scales with the semantic and structural similarity between old and new material, which is why Proactive Interference is the primary explanation for the difficulty of learning a second list of paired associates that overlaps with a recently learned first list.

**warning**: Proactive Interference is often confused with simple forgetting; it is specifically a competition effect, and reducing Proactive Interference requires distinctiveness manipulations or release procedures rather than additional study time on the interfering material.

## Retroactive Interference

- domain: cognitive-science
- secondary_domains: [memory-research]
- aliases: [retroactive inhibition, RI]
- broader: [memory-interference]
- related: [proactive-interference, consolidation, sleep-and-memory, similarity-based-confusion]
- prerequisites: [long-term-memory, memory-consolidation]
- confidence: high

**definition**: Retroactive Interference is the phenomenon in which newly learned material disrupts the retention of previously learned similar material, operating in the opposite temporal direction from proactive interference and providing a major theoretical account of forgetting.

**key_claim**: Retroactive Interference is greatest when the interpolated material is semantically similar to the original learning, which is why interleaving heterogeneous material reduces Retroactive Interference compared with stacking similar topics back-to-back in a single session.

**warning**: Retroactive Interference is sometimes mistaken for trace decay; the empirical signature of Retroactive Interference is that the original material is recoverable when the interpolated material is removed or reinstated, so attributing all forgetting to Retroactive Interference overstates a real but bounded mechanism.

## Recognition Memory

- domain: cognitive-science
- secondary_domains: [memory-research]
- aliases: [old-new recognition, recognition test]
- broader: [retrieval-practice]
- related: [cued-recall, free-recall, dual-process-theory-of-recognition, familiarity-recollection]
- prerequisites: [long-term-memory, retrieval-practice]
- confidence: high

**definition**: Recognition Memory is the ability to identify a previously encountered item as familiar when it is re-presented among distractors, and it is widely modelled as the joint output of a fast familiarity signal and a slower recollective retrieval process.

**key_claim**: Recognition Memory is preserved at far higher levels than free recall for the same studied material, which is why Recognition Memory tests systematically overestimate the depth of learning that has been achieved and why educators should not equate "recognising the right answer" with mastery.

**warning**: A strong Recognition Memory signal can be supported by familiarity alone with no recollection of source or context, so high Recognition Memory performance can coexist with an inability to use the information productively — the textbook gap between recognition and recall.

## Savings Paradigm

- domain: cognitive-science
- secondary_domains: [memory-research, learning-science]
- aliases: [savings method, relearning method]
- broader: [memory-research-methods]
- related: [forgetting-curve, ebbinghaus, long-term-memory, encoding-specificity-principle]
- prerequisites: [long-term-memory, forgetting-curve]
- confidence: high

**definition**: The Savings Paradigm is Ebbinghaus's experimental method in which retention is measured not by direct recall but by the reduction in trials required to relearn previously studied material to the original criterion, providing a sensitive index of residual memory below the recognition threshold.

**key_claim**: The Savings Paradigm reveals that material can appear completely forgotten by recall or recognition tests yet still leave a measurable trace, which is why the Savings Paradigm remains the most sensitive of the classical memory measures and why "forgotten" is not the same as "absent from memory".

**warning**: Modern study designs rarely use the Savings Paradigm because it is procedurally expensive and requires controlled relearning conditions; treating recall or recognition data as if they captured what the Savings Paradigm would have detected systematically underestimates long-term retention.
