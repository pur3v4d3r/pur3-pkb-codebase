# Recommended Obsidian Plugins for Visual Report Enhancement

## Plugin Tier System

### Tier 1: Essential (Install These First)
These plugins are directly referenced in the system prompt and enable core visual capabilities.

---

#### 1. Obsidian Charts
- **Plugin ID**: `obsidian-charts`
- **What it does**: Integrates Chart.js into Obsidian, enabling bar, line, pie, doughnut, radar, and polar area charts using simple YAML syntax inside code blocks.
- **Why essential**: Mermaid's native charting is limited. This plugin unlocks multi-series data comparison, radar charts for multi-dimensional analysis, and precise axis control — all critical for quantitative report enhancement.
- **Used for**: Bar charts, line charts, pie charts, doughnut charts, radar comparisons, polar area charts.

#### 2. Markmap
- **Plugin ID**: `obsidian-markmap`
- **What it does**: Renders markdown headings and lists as interactive, collapsible mind maps. You write standard markdown hierarchy and it becomes a visual mind map.
- **Why essential**: Mermaid's built-in mindmap is good for simple maps, but Markmap handles complex hierarchies (10+ branches) with interactivity — users can collapse and expand branches. This is the primary tool for report structure overviews and concept exploration maps.
- **Used for**: Report structure mind maps, concept exploration maps, taxonomy trees, knowledge hierarchies.

#### 3. Dataview
- **Plugin ID**: `dataview`
- **What it does**: Query and display metadata from your vault as tables, lists, and task views using a SQL-like query language or JavaScript.
- **Why essential**: When the system prompt generates structured metadata (inline fields, YAML frontmatter), Dataview makes that metadata queryable and displayable. Enables dynamic tables that update as your vault grows.
- **Used for**: Dynamic metadata tables, cross-note comparisons, aggregated views of tagged content.

---

### Tier 2: Highly Recommended (Significant Value Add)
These plugins substantially expand visual capabilities for specific report types.

---

#### 4. Excalidraw
- **Plugin ID**: `obsidian-excalidraw-plugin`
- **What it does**: Integrates the Excalidraw whiteboard/drawing tool directly into Obsidian. Creates hand-drawn style diagrams, concept sketches, and visual notes.
- **Why valuable**: When Mermaid's structured diagrams feel too rigid for conceptual or exploratory visuals, Excalidraw provides a freeform canvas. Particularly useful for architecture sketches, conceptual models, and visual summaries that benefit from a more organic, hand-drawn aesthetic.
- **Used for**: Conceptual diagrams, architecture sketches, freeform visual notes, annotated images.
- **Note**: Claude cannot directly generate Excalidraw drawings in the same way as Mermaid code, but it can generate Excalidraw JSON scene files or provide detailed instructions for manual creation.

#### 5. Obsidian Leaflet
- **Plugin ID**: `obsidian-leaflet-plugin`
- **What it does**: Renders interactive maps using Leaflet.js inside Obsidian notes. Supports markers, layers, and custom map tiles.
- **Why valuable**: When reports contain geographic data — regional comparisons, site locations, distribution patterns — this plugin enables actual interactive maps with markers and annotations.
- **Used for**: Geographic data visualization, location-based analysis, regional comparisons, site mapping.

#### 6. Kanban
- **Plugin ID**: `obsidian-kanban`
- **What it does**: Creates Kanban boards from markdown files with drag-and-drop card management.
- **Why valuable**: For reports that describe project phases, task distributions, or status tracking, Kanban boards provide an intuitive visual representation of work states and progress.
- **Used for**: Project status visualization, task categorization, workflow stage tracking.

---

### Tier 3: Specialized (Install as Needed)
These plugins serve specific visual needs depending on the types of reports you work with.

---

#### 7. Obsidian Tabs (or similar tabbed view plugin)
- **Why useful**: Allows viewing the report and generated visuals side by side in tabs, making it easy to cross-reference.

#### 8. Advanced Tables
- **Plugin ID**: `table-editor-obsidian`
- **What it does**: Adds spreadsheet-like table editing with tab navigation, formula support, and auto-formatting.
- **Why useful**: When the system prompt generates complex comparison tables, this plugin makes them much easier to edit and maintain.

#### 9. Obsidian Mermaid Tools
- **Plugin ID**: `mermaid-tools`
- **What it does**: Adds a toolbar and shortcuts for creating Mermaid diagrams, plus a visual editor.
- **Why useful**: Makes it easier to tweak and customize the Mermaid diagrams generated by the system prompt.

#### 10. Style Settings
- **Plugin ID**: `obsidian-style-settings`
- **What it does**: Exposes CSS customization options from your theme, enabling fine-tuned control over visual appearance.
- **Why useful**: Allows you to customize how Mermaid diagrams, charts, and other visual elements render in your vault — matching your preferred color schemes and typography.

#### 11. Obsidian Footnotes
- **Plugin ID**: `obsidian-footnotes`
- **What it does**: Streamlined footnote creation and navigation.
- **Why useful**: When the system prompt generates visuals with source references back to report sections, footnotes provide clean cross-referencing.

## Quick Install Checklist

For immediate setup, install in this order:

1. ✅ **Verify Mermaid works** — Built-in, just create a mermaid code block and confirm it renders
2. 📦 **Install Charts plugin** — Settings → Community Plugins → Browse → "Charts"
3. 📦 **Install Markmap** — Settings → Community Plugins → Browse → "Markmap"
4. 📦 **Install Dataview** — Settings → Community Plugins → Browse → "Dataview"
5. 📦 *(Optional)* **Install Excalidraw** — For freeform visual creation
6. 📦 *(Optional)* **Install Leaflet** — Only if working with geographic data
7. 📦 *(Optional)* **Install Advanced Tables** — For easier table editing

Total install time: approximately 5-10 minutes.
